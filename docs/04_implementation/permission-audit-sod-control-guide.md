这篇用于补齐权限上线后的审计闭环。基础权限实施解决“用户能不能做事”，权限审计解决“谁有高危权限、哪些岗位冲突、临时权限有没有收回、越权操作能不能追溯、审计来了能不能拿出证据”。

金蝶项目里权限问题往往不是上线当天才暴露，而是在月结、付款、发货、成本调整、反审核、接口推单、报表导出和审计抽查时暴露。权限矩阵如果只停留在菜单授权，后续很难解释为什么某个人能看到成本价、为什么能反审核已入账单据、为什么能修改供应商银行账号。

## 一、适用范围

- 多组织、多账簿、多仓库、多事业部项目。
- 财务、供应链、制造、资金、成本、总账、报表、接口共同使用同一套系统。
- 上线验收需要提交权限矩阵、用户角色清单和高危权限复核记录。
- 已经出现过越权审批、误删单据、反审核失控、敏感报表外泄、接口账号权限过大等问题。
- 每月、每季度或审计前需要定期复核权限。

如果项目只有少量用户，也建议保留最小审计清单：管理员账号、离职账号、临时授权、高危按钮、导出权限、反审核反结账权限。

## 二、审计目标

| 目标 | 要回答的问题 | 证据 |
| --- | --- | --- |
| 权限最小化 | 用户是否只拥有岗位所需权限 | 用户角色清单、岗位权限矩阵 |
| 职责分离 | 是否存在一人完成申请、审批、执行、记账全链路 | 冲突权限检查表 |
| 高危可控 | 反审核、反结账、删除、导出、改价、改银行账号是否受控 | 高危权限清单、审批记录 |
| 临时授权可收回 | 临时开放的权限是否有有效期和关闭记录 | 权限申请单、回收记录 |
| 操作可追溯 | 关键操作能否追到用户、时间、单据和原因 | 操作日志、业务监控、审计记录 |
| 账号安全 | 管理员、接口账号、离职账号是否被规范管理 | 账号台账、禁用记录、接口账号清单 |

## 三、权限审计对象

| 对象 | 审计重点 |
| --- | --- |
| 用户 | 是否启用、是否绑定真实人员、是否离职、是否共享账号 |
| 角色 | 是否按岗位设计、是否过宽、是否长期无人维护 |
| 用户角色关系 | 是否一人多岗、是否有冲突角色、是否有临时角色 |
| 组织范围 | 是否能跨公司、跨工厂、跨仓库看数据或做业务 |
| 功能权限 | 菜单、按钮、新增、保存、提交、审核、反审核、删除 |
| 数据权限 | 客户、供应商、仓库、部门、项目、物料、组织范围 |
| 字段权限 | 成本、价格、毛利、信用额度、银行账号、工资等敏感字段 |
| 报表权限 | 利润、成本、库存金额、资金、应收账龄、导出权限 |
| 审批流权限 | 是否能自审、自批、跳级、替别人处理审批 |
| 接口账号 | 是否拥有过大的组织、单据、基础资料和查询权限 |
| 管理员账号 | 是否用于日常业务，是否有双人复核和使用记录 |

## 四、高危权限清单

| 权限 | 风险 | 控制建议 |
| --- | --- | --- |
| 系统管理员 | 可改用户、角色、参数、流程和基础资料 | 只给少数管理员，日常业务禁用管理员账号 |
| 用户和角色维护 | 可给自己或他人扩权 | 权限变更必须审批，定期导出复核 |
| 反审核/反提交 | 可修改已流转单据 | 限制岗位和单据类型，记录原因 |
| 反过账/反结账 | 影响总账和月结结果 | 财务负责人审批，限定期间和时间窗口 |
| 删除单据 | 破坏业务追溯 | 尽量禁用，使用作废或关闭代替 |
| 修改供应商银行账号 | 可能导致付款风险 | 供应商主数据变更审批，付款前复核 |
| 修改客户信用额度 | 可能绕过信用控制发货 | 信用变更走审批，销售不能直接改 |
| 修改价格和折扣 | 影响收入和毛利 | 价格审批，销售价格和采购价格分权 |
| 查看成本价和毛利 | 泄露敏感经营数据 | 字段、列表、报表、导出同步控制 |
| 报表导出 | 数据外泄风险 | 导出权限最小化，敏感报表留痕 |
| 批量导入 | 可批量改变主数据或单据 | 模板审批、测试环境演练、导入日志 |
| 接口推单 | 可绕过前台录入限制 | 接口账号最小权限、幂等和日志 |
| 凭证模板维护 | 影响会计分录 | 财务主管审批，发布前回归 |
| 工作流维护 | 可改变审批链 | 变更记录、测试用例、上线审批 |
| 插件发布 | 可改变业务规则 | 发布审批、版本记录、回滚方案 |

高危权限不等于不能给，但必须满足三个条件：确实需要、有人审批、能追溯。

## 五、职责分离矩阵

### 采购到付款

| 冲突组合 | 风险 | 控制 |
| --- | --- | --- |
| 供应商新增 + 供应商银行账号维护 + 付款申请 | 虚假供应商或错误付款 | 主数据和付款岗位分离 |
| 采购订单新增 + 采购订单审核 | 自采自审 | 采购员和采购经理分离 |
| 采购入库 + 应付确认 | 虚增入库和应付 | 仓库和应付会计分离 |
| 应付确认 + 付款审核 + 付款执行 | 无人复核付款 | 应付、财务经理、出纳分离 |
| 采购价目表维护 + 采购订单审批 | 价格失控 | 价格维护和订单审批分离 |

### 销售到收款

| 冲突组合 | 风险 | 控制 |
| --- | --- | --- |
| 客户新增 + 信用额度维护 + 销售订单审核 | 绕过信用发货 | 客户主数据、信用、销售审批分离 |
| 销售订单新增 + 价格折扣审批 | 低价销售无人复核 | 销售员和价格审批人分离 |
| 发货出库 + 应收确认 | 虚假发货或提前确认应收 | 仓库和应收会计分离 |
| 收款登记 + 核销 + 反核销 | 挪用或错误核销 | 出纳和应收会计分离 |
| 退货申请 + 红字应收 + 退款审批 | 虚假退货退款 | 销售、财务、审批分离 |

### 库存和成本

| 冲突组合 | 风险 | 控制 |
| --- | --- | --- |
| 盘点录入 + 盘点审核 | 账实调整无人复核 | 仓管录入，主管审核 |
| 其他出库 + 成本调整 | 隐藏成本异常 | 库存和成本会计分离 |
| 物料成本价查看 + 销售报价 | 毛利泄露或低价销售 | 成本字段权限受控 |
| 负库存允许 + 出库审核 | 成本异常 | 负库存权限严格限制 |
| 成本计算 + 凭证生成 + 反结账 | 月结结果被单人控制 | 成本、总账、财务负责人分离 |

### 总账和资金

| 冲突组合 | 风险 | 控制 |
| --- | --- | --- |
| 凭证制单 + 凭证审核 | 自制自审 | 制单人和审核人分离 |
| 凭证过账 + 反过账 + 反结账 | 财务期间失控 | 高危权限审批和留痕 |
| 银行账号维护 + 付款执行 | 付款风险 | 银行账号变更和付款执行分离 |
| 付款单制单 + 银企支付 + 银行回单确认 | 付款闭环无人复核 | 出纳、资金负责人、会计分离 |
| 报表公式维护 + 报表确认 | 管理报表口径被单人控制 | 报表维护和确认分离 |

## 六、审计证据包

上线验收或定期审计建议至少留这些文件：

| 证据 | 内容 |
| --- | --- |
| 岗位清单 | 岗位、人员、部门、组织、职责 |
| 角色清单 | 角色编码、名称、适用岗位、维护人 |
| 用户角色清单 | 用户、角色、组织范围、授权日期 |
| 高危权限清单 | 高危按钮、菜单、报表、字段、拥有者 |
| 冲突权限检查表 | 职责分离冲突、处理建议、批准人 |
| 临时权限台账 | 申请人、权限、原因、开始结束时间、回收记录 |
| 离职调岗复核 | 离职禁用、调岗收回、共享账号检查 |
| 管理员账号台账 | 管理员清单、用途、使用记录 |
| 接口账号清单 | 接口名称、账号、权限范围、最近调用时间 |
| 敏感操作日志 | 反审核、反结账、删除、导出、改价、改银行账号 |
| 审计问题整改表 | 问题、风险、责任人、截止日期、复核结果 |

## 七、审计流程

```text
确定审计范围
  -> 导出用户角色和权限清单
  -> 标识高危权限
  -> 检查职责分离冲突
  -> 抽样验证真实账号
  -> 查敏感操作日志
  -> 形成问题清单
  -> 整改和回收权限
  -> 复核并归档证据
```

审计不要只看配置截图。必须做抽样验证：用真实岗位账号登录，确认它能做应该做的事，也不能做不该做的事。

## 八、抽样测试场景

| 岗位 | 应能完成 | 不应能完成 |
| --- | --- | --- |
| 采购员 | 新增采购订单、查看本人采购订单 | 审核付款、维护供应商银行账号 |
| 仓管员 | 收料、入库、出库、盘点录入 | 修改采购价格、查看成本价 |
| 销售员 | 新增销售订单、查询本人客户 | 修改信用额度、查看全公司毛利 |
| 应收会计 | 应收确认、收款核销 | 修改销售订单数量、维护客户信用 |
| 应付会计 | 应付确认、付款核销 | 新增供应商银行账号、银企支付 |
| 成本会计 | 成本计算、成本报表 | 反结账、删除库存单据 |
| 总账会计 | 凭证、过账、结账 | 自己审核自己制的凭证 |
| 系统管理员 | 用户角色维护、参数维护 | 日常采购、销售、付款、凭证制单 |

## 九、敏感操作追溯

重点追溯这些动作：

- 用户启用、禁用、重置密码。
- 角色新增、角色权限变更。
- 给用户增加管理员或高危角色。
- 修改供应商银行账号。
- 修改客户信用额度、价格政策、折扣。
- 单据反审核、反提交、作废、删除。
- 凭证反审核、反过账、反结账。
- 成本调整、库存调整、盘点差异审核。
- 报表导出、敏感字段导出。
- 接口账号调用失败、重复推单、批量导入。
- 工作流、凭证模板、插件发布变更。

追溯记录至少要包含：操作人、操作时间、菜单或对象、单据编号、变更前后、原因、审批记录、处理结果。

## 十、常见异常与处理

### 1. 离职用户仍然启用

处理：

1. 立即禁用账号。
2. 检查最近登录和操作记录。
3. 检查是否有共享账号或接口引用。
4. 收回角色和临时权限。
5. 把禁用记录归档到离职复核表。

### 2. 用户拥有多个冲突角色

处理：

1. 列出角色来源，是岗位常规授权还是临时授权。
2. 判断是否存在采购、仓库、财务、资金、管理员冲突。
3. 能拆岗位就拆岗位，不能拆则增加审批和日志复核。
4. 对保留冲突权限的用户形成书面批准。

### 3. 管理员账号被用于业务单据

处理：

1. 停止用管理员做日常业务。
2. 给用户建立普通岗位账号。
3. 追溯管理员账号近期业务操作。
4. 管理员账号只保留系统维护用途。
5. 管理员操作纳入月度审计。

### 4. 临时权限没有收回

处理：

1. 导出临时角色和临时授权用户清单。
2. 按申请单核对有效期。
3. 到期立即收回。
4. 抽样验证收回后是否仍能访问。
5. 后续临时权限必须带结束日期。

### 5. 反审核或反结账权限过宽

处理：

1. 导出拥有反审核、反过账、反结账权限的用户。
2. 分类为财务负责人、总账会计、管理员、其他人员。
3. 非必要人员立即收回。
4. 必要人员要求填写原因并保留操作日志。
5. 月结后冻结期间，反结账必须审批。

## 十一、周期性复核节奏

| 频率 | 动作 |
| --- | --- |
| 每周 | 检查新增用户、临时权限、接口失败和管理员操作 |
| 每月 | 导出用户角色清单，复核离职调岗、高危权限、反审核记录 |
| 每季度 | 做职责分离检查，抽样测试岗位账号，更新权限矩阵 |
| 每次发布前 | 检查新菜单、新按钮、新字段、新接口账号权限 |
| 每次审计前 | 准备审计证据包、敏感操作日志、整改闭环 |

| 反结账 | 总账反结账 | 财务主管 | 月结异常处理 | 财务负责人 | 每月 | 保留 |

## 十三、上线验收检查清单

- [ ] 岗位和角色已经一一对应。
- [ ] 用户角色清单已导出并由部门确认。
- [ ] 高危权限清单已形成并审批。
- [ ] 采购到付款职责分离已检查。
- [ ] 销售到收款职责分离已检查。
- [ ] 库存和成本职责分离已检查。
- [ ] 总账、资金、报表职责分离已检查。
- [ ] 管理员账号不用于日常业务。
- [ ] 接口账号权限范围明确。
- [ ] 临时权限有有效期。
- [ ] 离职和调岗处理流程明确。
- [ ] 敏感操作日志可查询。
- [ ] 用真实岗位账号完成正向和反向测试。
- [ ] 审计证据包已归档。
