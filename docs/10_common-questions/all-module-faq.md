这篇用于快速判断金蝶项目日常问题的方向。它不是替代详细排查，而是帮助你在 5-10 分钟内判断问题大概率属于权限、配置、数据、流程、接口、二开、环境还是业务口径。

## 一、通用判断顺序

遇到任何问题，先问：

1. 是单个用户还是所有用户。
2. 是单张单据还是同类单据。
3. 是生产环境还是测试环境也一样。
4. 是今天突然出现还是上线后一直存在。
5. 最近是否改过权限、参数、审批流、插件、接口、补丁或基础资料。
6. 是否有完整报错原文和单据编号。

## 二、快速定位表

| 现象 | 优先判断 | 常见方向 |
| --- | --- | --- |
| 看不到菜单 | 用户、角色、组织、许可 | 权限 |
| 能看菜单但不能保存 | 按钮权限、必填字段、插件校验 | 权限或配置 |
| 单据不能审核 | 审批流、必填、下游状态、插件 | 流程或二开 |
| 下推不了下游单据 | 单据状态、转换规则、未执行数量 | 单据转换 |
| 报表数字不对 | 查询条件、状态、期间、组织、口径 | 数据口径 |
| BI 看板、老板驾驶舱或 ChatBI 数字和标准报表不一致 | 指标字典、数据模型、权限、下钻口径 | BI 分析体系 |
| AI 管理助手或智能体回答不准、越权或不敢让它自动执行 | 知识库、权限、工具调用、人工确认、审计日志 | 金蝶 AI 应用 |
| 接口失败 | 认证、主数据、字段、业务规则 | 集成 |
| 税务平台、银企回单或批量补偿后和金蝶不一致 | 外部事实、回写状态、幂等键、补偿批次、月结证据 | 财务集成补偿 |
| 库存不对 | 单据审核、批号库位、盘点、核算 | 库存 |
| 成本不对 | 入库成本、出库核算、负库存、费用分配 | 存货或制造成本 |
| 凭证不对 | 凭证模板、科目映射、辅助核算 | 财务 |
| 预算还有但报销或采购申请提示超预算 | 预算维度、占用未释放、期间、预算版本 | 财务预算 |
| 新人看不懂财务和供应链怎么接起来 | 业务单据、凭证、库存、应收应付、成本 | 基础通俗入门 |
| 事业部利润、产品线毛利和法人口径利润对不上 | 管理维度、内部交易、费用分摊、转移定价 | 集团管理分析 |

| 经营月报很多表但管理层看不懂 | 摘要结构、指标口径、预算偏差、异常清单 | 经营分析月报 |
| 税务申报、销项、进项、红字和总账税金对不上 | 发票状态、认证期间、红字来源、未开票收入、凭证 | 财务和税务 |
| 商贸分销销售额不错但回款、库存、返利和毛利对不上 | 价格政策、信用占用、渠道库存、退货折让、返利口径 | 商贸分销 |
| 门店 POS 销售、收款、会员权益、库存和日结对不上 | 小票上传、收款方式、促销退货、储值积分、门店库存 | 连锁零售 |
| 客户退货后不知道进良品、返修还是报废 | 退货授权、库存状态、质检判定、红冲退款 | 供应链和质量 |
| 客户要求赔偿、免费备件或保外维修收费 | 售后申请、备件出库、保内保外、应收、索赔 | 供应链、质量和财务 |
| 服务站库存、经销商代修和旧件返还对不上 | 服务单、服务站仓、旧件状态、服务费结算 | 渠道售后 |
| 委外发料、入库、加工费和供应商材料对不上 | 委外订单、补退料、供应商处材料、委外入库核算 | 制造、采购和成本 |
| PLM 已发布新 BOM，但金蝶生产订单仍用旧版本 | 物料同步、BOM 版本、生效日期、工程变更影响分析 | PLM 集成和制造 |
| MES 显示已报工或已完工，但金蝶生产订单、报工单或看板进度不一致 | 回写日志、幂等键、工序映射、质量结果、完工入库 | 制造和集成 |
| WMS 已收发货但金蝶库存不一致 | WMS 作业单、回写日志、幂等键、批号库存状态 | WMS 集成和库存 |
| 集团合并报表抵不平 | 内部往来、内部交易、权益抵消、报表模板 | 集团财务 |
| 离职账号未禁用、临时权限未收回、反审核反结账权限过宽 | 用户角色、高危权限、职责分离、操作日志 | 权限审计和运维 |
| 保存校验、审核后处理、下推补字段或列表过滤异常 | 插件注册、事件时机、字段标识、幂等和日志 | BOS 插件案例 |
| 清理后查不到历史单据、附件、接口报文或操作日志 | 留存年限、归档位置、审计取证、清理审批 | 数据归档审计 |
| 系统突然变慢 | 发布、任务、数据库、接口、资源 | 环境或性能 |

## 三、权限类问题

### 1. 用户看不到菜单

快速判断：

- 新用户通常是角色未分配或组织范围未给。
- 老用户突然看不到，先查最近权限变更或角色调整。

排查顺序：

1. 用户是否启用。
2. 是否绑定人员。
3. 是否分配角色。
4. 角色是否有菜单权限。
5. 是否有组织范围。
6. 是否有模块许可。
7. 用同岗位用户对比。

处理建议：

- 按岗位模板授权。
- 不要直接给管理员权限。
- 记录权限变更原因。

### 2. 能打开单据但不能新增、保存或审核

快速判断：

- 能进菜单不代表有按钮权限。
- 保存失败不一定是权限，也可能是字段必填或插件校验。

排查顺序：

1. 查新增、保存、提交、审核按钮权限。
2. 查单据状态。
3. 查必填字段。
4. 查审批任务是否到当前用户。
5. 查插件报错或校验规则。
6. 查组织和数据范围。

### 3. 高危权限或临时权限怎么审计

快速判断：

- 不只看用户能不能进菜单，要看是否有反审核、反结账、删除、导出、改价、改银行账号、接口推单等高危权限。
- 临时权限必须有申请原因、有效期、审批人和回收记录。
- 离职调岗用户要检查是否禁用账号、收回角色、清理共享账号。

排查顺序：

1. 导出用户角色清单。
2. 标记管理员、高危按钮、敏感报表和导出权限。
3. 检查采购到付款、销售到收款、库存成本、总账资金的职责分离冲突。
4. 抽样登录真实岗位账号，做正向和反向测试。
5. 查询敏感操作日志，重点看反审核、反结账、删除、导出和主数据变更。
6. 形成整改清单并复核权限是否已经收回。

详细处理见 [权限审计、关键岗位内控与越权操作追溯专题](../04_implementation/permission-audit-sod-control-guide.md)。

## 四、供应链类问题

### 4. 采购订单为什么不能下推入库

常见原因：

- 采购订单未审核。
- 订单已关闭。
- 订单未入库数量为 0。
- 单据转换规则不适用。
- 当前用户无下推或入库权限。
- 供应商、物料、仓库状态异常。

排查顺序：

1. 看订单状态。
2. 看分录未入库数量。
3. 看是否已被下游单据占用。
4. 看转换路线。
5. 看用户权限。
6. 用另一张正常订单对比。

### 5. 销售出库后库存没有减少

常见原因：

- 出库单未审核。
- 出库仓库不是查询仓库。
- 批号、库位、库存状态查询条件不一致。
- 查询的是历史库存报表，不是即时库存。
- 出库单被反审核或作废。

处理建议：

- 先以前台即时库存和库存明细账交叉验证。
- 再查销售出库单状态和分录仓库。

### 6. 库存账实不符怎么办

排查顺序：

1. 固定物料、仓库、批号、库位。
2. 查即时库存。
3. 查库存明细账。
4. 查未审核出入库单。
5. 查盘点单和调整单。
6. 查是否有线下实物移动未入系统。

处理建议：

- 不能直接改库存余额。
- 通过盘点、调整、补录单据形成可追溯处理。

### 6.1 商贸分销销售额不错但回款、库存、返利和毛利对不上

常见原因：

- 订单销售额、出库收入、开票应收和回款不是同一个口径。
- 销售手工改价、促销价、协议价和最低限价没有版本和审批。
- 信用额度只看已开票应收，没有把已发货未开票、逾期和票据风险纳入。
- 返利、折让、赠品、平台佣金或市场费用没有进入毛利分析。
- 经销商只上报进货，不上报终端销售和渠道库存。

排查顺序：

1. 先分清订单额、出库额、开票额、应收额、回款额和收入额。
2. 按客户、商品、区域、销售员和期间重算价格偏离、毛利和返利。
3. 查信用占用口径：订单、出库未开票、已开票未收款、逾期和未核销收款。
4. 查渠道库存：经销商期初、进货、终端销售、退货和期末库存。
5. 把退货、折让、赠品、返利和费用放回同一张客户贡献表。

详细处理见 [商贸与分销行业场景包：价格、信用、发货、回款、返利和渠道对账](../02_supply-chain/trading-distribution-scenario-pack.md)。

### 6.2 门店 POS 销售、收款、会员权益、库存和日结对不上

常见原因：

- POS 小票未上传、重复上传或跨日上传。
- 现金、银行卡、微信、支付宝、储值、优惠券等收款方式没有分开对账。
- 满减、买赠、会员价、积分抵扣在退货时没有重算。
- POS 已销售但后台没有生成门店出库，库存虚高。
- 储值充值、赠送金额、消费扣减和退款没有区分。

排查顺序：

1. 固定门店、收银日期、班次、POS 机号和小票号。
2. 对 POS 小票、后台销售单、收款单、门店出库单。
3. 按收款方式拆现金、银行卡、移动支付、储值、券和平台账单。
4. 查会员权益流水：积分、储值、券核销、退货回滚。
5. 最后看日结是否锁定，长短款是否登记责任和处理结果。

详细处理见 [连锁零售行业场景包：门店、POS、会员、促销、补货和日结对账](../02_supply-chain/retail-chain-pos-store-scenario-pack.md)。

## 五、生产制造类问题

### 7. MRP 计划结果不符合预期

常见原因：

- 需求来源没纳入。
- BOM 未审核或版本不生效。
- 库存可用量口径不一致。
- 安全库存、提前期、批量规则设置不合理。
- 已下达订单没有正确抵扣需求。

排查顺序：

1. 确认计划范围。
2. 确认需求来源。
3. 检查 BOM 版本。
4. 检查物料计划属性。
5. 检查库存和在途。
6. 查看 MRP 运算日志或结果明细。

### 8. 生产领料数量不对

常见原因：

- BOM 用量或损耗设置错误。
- 生产订单数量变更。
- 替代料启用。
- 超领或补料规则。
- 已领料数量没有正确反写。

处理建议：

- 从生产订单用料清单开始查，不要直接查库存。
- 对比 BOM 标准用量、订单用量、已领数量、可领数量。

### 9. 完工入库后成本异常

常见原因：

- 材料未完整领用。
- 入库或出库成本未核算。
- 人工和制造费用未分配。
- 完工数量或在制品数量错误。
- 负库存影响出库成本。

处理建议：

- 按“领料 -> 完工 -> 存货核算 -> 成本计算 -> 凭证”顺序排查。

### 10. MES 报工回写或车间看板不一致

常见原因：

- MES 回写失败或只在 MES 成功，没有生成金蝶报工记录。
- 生产订单、工序、工作中心或物料编码映射不一致。
- 设备自动计数包含调机、空跑、不良或返工，和人工报工口径不同。
- 质量结果没有关联到报工、完工入库或返修报废状态。
- 看板取数包含未审核、已作废、失败重试或跨班次数据。

排查顺序：

1. 固定一张生产订单、一道工序和一条 MES 报工流水。
2. 查 MES 发送报文、接口响应、幂等键和重试记录。
3. 查金蝶生产订单、工序任务、报工单、检验单和完工入库单状态。
4. 对比设备计数、人工报工合格数、不良数和入库数。
5. 按班次、业务日期、组织、工序过滤条件重新核对看板。

详细处理见 [车间看板、MES 报工回写与设备数据采集专题](../03_manufacturing/mes-shop-floor-dashboard-data-collection-guide.md)。

## 六、财务类问题

### 11. 业务单据生成不了凭证

优先看：

- 单据是否审核。
- 期间是否开放。
- 凭证模板是否命中。
- 科目和辅助核算是否能取到。
- 金额是否为 0。
- 生成日志是否有明确报错。

详细处理见 [财务高频问题](finance-faq.md)。

### 12. 应收应付和总账不一致

常见原因：

- 单据未生成凭证。
- 凭证未过账。
- 手工凭证影响往来科目。
- 查询条件的期间、币别、组织不同。
- 核销状态不同。

处理建议：

- 按客户或供应商输出差异表。
- 分成未生成凭证、未过账、手工凭证、期初差异、查询口径五类。

### 13. 预算还有但单据提示超预算

常见原因：

- 费用申请、采购申请或报销单占用了预算，但后续作废、关闭、驳回后没有释放。
- 单据部门、项目、费用项目、期间和预算维度不一致。
- 预算调整已经审批，但没有发布到当前版本。
- 申请和报销重复扣预算。
- 费用预算和资金预算混在一起。

排查顺序：

1. 固定组织、部门、费用项目、项目和期间。
2. 查预算发布版本、预算调整和可用余额。
3. 查占用明细、消耗明细和释放明细。
4. 查关联的费用申请、报销单、采购申请和付款申请状态。
5. 判断是释放、调整、维度修正还是超预算审批。

详细处理见 [预算执行分析、占用释放与费用报销联动专题](../01_finance/budget-execution-control-analysis-guide.md)。

### 14. 事业部利润和法人口径利润对不上

常见原因：

- 管理口径引入了内部收入、内部成本、费用分摊或标准成本调整。
- 业务单据没有带事业部、产品线、项目或客户群维度。
- 内部交易没有区分对外收入和内部收入。
- 总部费用分摊规则每月变化，导致利润波动。

排查顺序：

1. 区分法人口径、合并口径和管理口径。
2. 列出管理调整项和费用分摊规则。
3. 查内部客户、内部供应商和组织间结算。
4. 查收入、成本、费用是否带管理维度。
5. 输出“法人口径 -> 管理口径”调节表。

详细处理见 [集团管理分析、事业部利润与内部转移定价专题](../01_finance/group-management-profit-transfer-pricing-guide.md)。

### 14.05 海外子公司、多币别、IFRS/US GAAP、VAT/GST 或预提税口径不清

常见原因：

- 海外法人、本位币、交易币别和集团列报币别没有分清。
- 当地准则、IFRS/US GAAP、集团会计政策和中国准则混在同一张报表里。
- VAT/GST/Sales Tax、Import VAT、预提税和银行手续费没有单独建税码、科目和付款证据。
- 关联交易价格、服务费、特许权使用费和转移定价文档没有和应收应付、合并抵消联动。

排查顺序：

1. 先确认海外主体的法定账簿、本位币、交易币别和集团报表包币别。
2. 列出当地税种、税码、税率来源、发票类型、申报周期和预提税规则。
3. 检查科目映射、汇率类型、汇兑损益、外币重估和报表折算规则。
4. 检查跨境付款证据包：合同、发票、预提税、完税凭证、手续费和实际到账金额。
5. 最后再进入合并报表，做报表包、准则调整、内部往来和内部交易抵消。

详细处理见 [国外财务与国际化核算专题：多币别、多准则、税务和合并](../01_finance/international-finance-accounting-guide.md) 和 [海外子公司建账与月结实操包](../01_finance/overseas-subsidiary-close-implementation-pack.md)。

### 14.1 经营分析月报很多表但管理层看不懂

常见原因：

- 只是把系统报表截图拼在一起，没有一页管理摘要。
- 法人口径、合并口径和管理口径没有区分。
- 事业部利润、产品毛利、客户贡献和预算执行没有放到同一套口径里。
- 只有结果，没有说明异常原因、责任人和处理动作。

处理建议：

1. 先写一页摘要：本月结论、利润变化、预算偏差、现金和库存风险。
2. 指标按“事业部 -> 产品线 -> 客户 -> 预算差异 -> 异常事项”展开。
3. 每个异常必须写清口径、影响金额、责任部门、处理动作和下月跟踪点。
4. 管理月报里不要混用未审核业务单据、未过账凭证和临时 SQL 结果。

详细处理见 [经营分析月报样例：事业部利润、产品毛利、客户贡献与预算执行](../01_finance/management-analysis-monthly-report-sample-guide.md)。

### 15. 税务申报和发票、总账对不上

常见原因：

- 销售发票已经开具，但收入确认、应收或凭证没有同步。
- 收入已经确认，但发票还没有开，形成未开票收入。
- 采购发票已经认证，但金蝶采购发票或进项凭证没有完成。
- 红字发票已经处理税额，但红字应收、红字应付、退货或折让没有处理。
- 发票平台作废、红冲、认证期间和金蝶单据期间不一致。

排查顺序：

1. 固定发票号码、客户或供应商、期间和税率。
2. 对比金蝶销售/采购发票清单和税务平台发票清单。
3. 对比应交税费明细账、收入明细、应收应付明细。
4. 单独列出红字、作废、未开票收入、已开票未收入。
5. 查凭证生成情况和税金科目。

详细处理见 [发票税务申报勾稽、红字和未开票收入专题](../01_finance/tax-declaration-invoice-reconciliation-guide.md)。

## 七、数据和报表类问题

### 16. 报表数字和用户认为的不一致

快速判断：

- 先不要说报表错，先问口径。

必须确认：

- 是业务日期还是记账期间。
- 是已审核还是全部单据。
- 是含税还是不含税。
- 是原币还是本位币。
- 是销售订单、销售出库、应收还是总账收入。

处理建议：

- 给报表标题加口径说明。
- 指标定义写到报表需求文档。

### 17. SQL 查出来和前台不一致

常见原因：

- SQL 过滤条件少了组织、期间、状态。
- 前台报表包含权限或业务口径。
- 后台查的是明细，前台看的是汇总或余额。
- 多语言名称、基础资料引用或历史版本影响展示。

处理建议：

- 用同一张单据编号抽样验证。
- SQL 结果必须回前台单据和标准报表核对。
- 常用单据状态、凭证生成、库存成本、接口日志和内部往来查询模板见 [核心表字典与常用 SQL 查询包](../06_data-model-sql/core-table-dictionary-and-sql-pack.md)。
- 要把查询沉淀成可复用记录时，按 [真实环境已验证 SQL 示例库](../06_data-model-sql/real-environment-verified-sql-library.md) 补齐状态、环境、样例单号、前台验证入口和风险说明。

### 17.1 BI 看板、老板驾驶舱或 ChatBI 数字和标准报表不一致

常见原因：

- BI 用销售出库、应收或订单口径，标准报表用总账或财务确认口径。
- 指标没有写清含税/不含税、本位币/原币、单据状态和日期字段。
- BI 模型过滤了组织、客户、仓库或权限，用户看到的数据范围不同。
- 看板做了汇总缓存，但底层单据或凭证已经变化。
- ChatBI 或自然语言查询理解的问题范围太宽，自动选择的数据主题和用户预期不一致。

处理顺序：

1. 先固定一个指标、一个期间、一个组织和一个样例单据。
2. 查指标字典：公式、数据源、过滤条件、金额口径、状态口径。
3. 从看板下钻到明细，再回前台标准报表和源单核对。
4. 检查用户权限、组织权限、维度权限和导出权限。
5. 如果是 ChatBI 问答，重新写成更明确的问题，例如“按已审核销售出库单、不含税、本位币，统计 2026 年 6 月华东区产品线毛利”。

详细处理见 [BI 分析体系详解：指标、模型、看板、权限和经营洞察](../06_data-model-sql/bi-analytics-system-guide.md) 和 [金蝶 ChatBI 实战专题：自然语言问数、口径解释与经营驾驶舱](../06_data-model-sql/kingdee-chatbi-practical-guide.md)。

### 17.2 AI 管理助手或智能体回答不准、越权或不敢让它自动执行

常见原因：

- 知识库资料过期、没有来源、没有 owner，AI 引用了旧制度或旧流程。
- 文档权限、数据权限和工具权限没有统一，问答能看到不该看的资料。
- 智能体调用工具时没有人工确认点，生成草稿和正式提交没有分清。
- 没有记录用户问题、检索来源、工具调用、返回结果和人工处理结果。
- 场景太大，例如“帮我管采购”，没有拆成供应商价格异常、采购订单逾期、到票暂估等可执行任务。

处理顺序：

1. 先判断场景类型：问答、生成、分析、审核、执行还是多智能体编排。
2. 核对知识库来源、版本、负责人、权限和引用结果。
3. 核对智能体能调用哪些 API、报表、流程或业务工具。
4. 对下单、付款、审批、驳回、数据补偿等高风险动作设置人工确认点。
5. 用不同角色账号测试同一问题，确认权限、脱敏和审计日志有效。

详细处理见 [金蝶 AI 应用专题：AI 管理助手、智能体与业务落地](../07_integrations/kingdee-ai-agent-application-guide.md)。

## 八、接口类问题

### 18. 外部系统推单失败

常见原因：

- 接口账号认证失败。
- 接口账号无组织或单据权限。
- 客户、供应商、物料、仓库不存在。
- 必填字段为空。
- 金额、税额、单位、币别格式错误。
- 业务规则不允许，例如库存不足或期间关闭。

排查顺序：

1. 查接口日志。
2. 查请求报文。
3. 查响应报错。
4. 查主数据映射。
5. 查接口账号权限。
6. 查金蝶前台是否能手工录入同样数据。

### 19. 接口重复生成单据

常见原因：

- 没有幂等键。
- 外部系统超时后重试。
- 金蝶已创建成功但响应失败。
- 接口没有先查后补偿。

处理建议：

- 用外部单号加业务类型加组织做幂等。
- 重试前先查询金蝶是否已存在。
- 建立重复数据处理流程。

### 19.1 税务平台、银企回单或批量补偿后和金蝶不一致

常见原因：

- 税务平台已经开票或红冲，但金蝶发票号码、状态或红冲关系没有回写。
- 银行已经扣款或退回，但金蝶付款单仍停留在已提交、处理中或未回单。
- 接口超时后直接重推，没有先查外部平台和金蝶是否已经成功。
- 补偿批次范围选错，导致重复单据、重复付款或重复入账。
- 发票、回单、接口报文和操作日志没有进入月结证据包。

处理顺序：

1. 固定外部单号、发票号码、银行流水号、金蝶单据编号和补偿批次号。
2. 先查外部事实：税务平台、银行流水、银行回单或第三方平台处理状态。
3. 再查金蝶事实：业务单据、财务单据、凭证、附件和接口日志。
4. 判断是回写失败、状态未同步、主数据错误、重复补偿还是凭证未生成。
5. 批量补偿前先小批量试跑，补偿后输出成功、失败、重复和人工关闭清单。

详细处理见 [税务平台、银企回单与接口批量补偿专题](../07_integrations/financial-integration-tax-bank-compensation-guide.md)。

### 20. WMS 已收发货但金蝶库存不一致

常见原因：

- WMS 已完成作业，但回写金蝶失败。
- 金蝶已经生成单据，但未审核或业务校验失败。
- 批号、序列号、库存状态、仓库或库位映射不一致。
- 接口超时后重复回写或人工补单，导致重复出入库。
- 月末只对总数量，没有按组织、仓库、物料、批号和库存状态展开。

排查顺序：

1. 固定 WMS 作业单号、金蝶源单号、目标出入库单号。
2. 查接口日志、幂等键、请求报文、响应报文和重试次数。
3. 查 WMS 实绩和金蝶单据状态。
4. 按物料、仓库、批号、序列号、库存状态对比库存。
5. 判断是重试、补偿、冲销、审核还是人工调整。

详细处理见 [WMS 出入库对账、接口补偿与库存一致性专题](../07_integrations/wms-inventory-reconciliation-compensation-guide.md)。

### 21. PLM 已发布新 BOM，但金蝶仍用旧版本

常见原因：

- PLM 物料已发布，但金蝶物料未同步或组织分配不完整。
- BOM 新版本同步失败、未审核或生效日期不正确。
- 生产订单下达时锁定了旧 BOM 版本。
- 工程变更没有做生产订单、采购订单、旧料库存和售后备件影响分析。
- MRP 仍按旧 BOM 或旧默认版本运算。

排查顺序：

1. 查 PLM 工程变更单号、BOM 版本和生效策略。
2. 查金蝶物料、BOM 版本、审核状态和有效期。
3. 查生产订单使用的 BOM 版本和下达时间。
4. 查是否已经领料、开工、委外或采购。
5. 判断是重试同步、切换版本、冻结旧单还是做补退料。

详细处理见 [PLM-BOM 变更同步、工程变更与生产版本追溯专题](../07_integrations/plm-bom-ecn-change-sync-guide.md)。

## 九、开发和配置类问题

### 22. 插件发布后没有生效

常见原因：

- 发布到错误环境。
- 插件注册对象不对。
- 事件时机不对。
- 缓存未刷新。
- 测试单据不满足触发条件。

处理建议：

- 在日志中打出插件版本和触发对象。
- 用最小测试单据验证。
- 检查发布包和环境版本。

### 23. 新增字段后报表或接口取不到

原因：

- 字段只加在表单，没有加入列表或数据源。
- 接口字段映射未更新。
- 报表数据集未更新。
- 权限或字段可见性限制。

处理建议：

- 新增字段要同步检查：表单、列表、接口、报表、权限、凭证模板。

### 23.1 保存校验、审核后处理、下推字段或列表过滤异常

常见原因：

- 插件绑定了错误单据、错误操作或错误事件时机。
- 字段标识和当前环境不一致，表头字段、分录字段混用。
- 审核后逻辑没有幂等，反审核再审核后重复写日志、重复推接口或重复生成下游。
- 单据转换没有保留源单、源分录关系，导致下推字段补错或补空。
- 列表过滤只考虑用户，没有考虑组织、角色、数据权限和管理员例外。

排查顺序：

1. 用最小单据复现，确认保存、提交、审核、下推或打开列表的准确触发点。
2. 查插件注册对象、类版本、事件时机和当前环境发布包。
3. 打印单据编号、内码、分录内码、字段标识、用户、组织和耗时。
4. 对审核后、接口、下游生成类逻辑先查幂等记录，再决定是否补偿重跑。
5. 对列表过滤用管理员、普通用户、多组织用户各测一次。

详细处理见 [BOS 插件源码级案例：保存校验、操作服务、单据转换与列表过滤](../05_development-bos/plugin-code-cases-save-operation-conversion-guide.md)。

## 十、环境和性能类问题

### 24. 系统突然变慢

快速判断：

- 是否所有用户都慢。
- 是否某个菜单慢。
- 是否刚发布补丁或二开。
- 是否有大报表、批量导入、成本计算、月结任务。

排查顺序：

1. 查服务器 CPU、内存、磁盘。
2. 查数据库连接和慢查询。
3. 查后台任务。
4. 查接口失败和重试积压。
5. 查最近发布。
6. 用测试环境对比。

### 25. 发布后出现异常

处理：

1. 先确认影响范围。
2. 查看发布内容和变更清单。
3. 用发布验证用例复测。
4. 查日志。
5. 判断是否回滚或热修复。
6. 记录发布问题和修复过程。

### 25.1 清理后查不到历史单据、附件、接口报文或操作日志

常见原因：

- 清理规则只按数据量和性能设计，没有按审计留存年限设计。
- 附件、接口报文和业务单据分开存放，清理时没有一起建索引。
- 生产清理前没有留报表快照、审批记录和可恢复方案。
- 接口日志只保留技术状态，缺少业务单号、幂等键、源系统和目标系统。

处理建议：

1. 先停继续清理，确认影响范围和最后一次清理批次。
2. 查归档库、附件归档目录、接口日志表和操作日志留存策略。
3. 对审计所需材料，优先恢复索引和查询入口，不要直接改生产底表。
4. 后续所有清理规则都要绑定审批、备份、抽样复核、恢复演练和归档报告。

详细处理见 [数据清理归档、接口报文留存与审计追溯专题](../08_environments-releases/data-archive-log-retention-audit-guide.md)。

## 十一、问题升级标准

满足以下条件要升级处理：

- 影响生产大面积使用。
- 阻塞月结、付款、发货、生产。
- 涉及数据错误或财务报表。
- 涉及重复付款、重复出库、重复入库。
- 涉及安全、权限、敏感数据泄露。
- 临时方案超过一天仍未根因修复。

- 高频短问题留在本页。
- 财务专项问题补到财务高频问题。
- 完整处理过程补到运维与问题库。
- 可复用 SQL 补到数据模型与 SQL。
- 涉及配置或实施风险的，反补到实施交付模块。
