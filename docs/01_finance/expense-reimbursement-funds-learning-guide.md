费用报销是财务新人最容易接触、也最容易出错的业务。它看起来只是员工填单、领导审批、财务付款，但实际会牵涉预算、费用项目、部门、项目、发票、附件、付款、核销、凭证和电子档案。

可以用一句话理解：

```text
费用报销不是“给员工打钱”，而是把一笔业务支出变成可审批、可付款、可入账、可审计的闭环。
```

## 一、费用业务总图

常见费用链路有三类：

| 类型 | 通俗解释 | 常见单据 |
| --- | --- | --- |
| 直接报销 | 员工先垫钱，再报销 | 费用报销单、付款单 |
| 借款后报销 | 员工先借备用金，回来冲账 | 借款单、费用报销单、还款单 |
| 对公费用付款 | 公司直接付供应商或服务商 | 费用申请、付款申请、付款单、发票 |

最完整的链路：

```text
费用申请/借款申请
  -> 预算控制
  -> 审批
  -> 报销单
  -> 发票和附件校验
  -> 财务审核
  -> 付款单
  -> 凭证生成
  -> 归档和对账
```

## 二、费用报销和采购付款的区别

很多新手会把“付款”都看成一样，其实费用报销和采购付款不同。

| 对比 | 费用报销 | 采购付款 |
| --- | --- | --- |
| 业务来源 | 员工差旅、招待、办公、项目费用 | 采购订单、入库、应付 |
| 主要对象 | 员工、部门、项目、费用项目 | 供应商、物料、采购合同 |
| 财务确认 | 费用或其他应付款 | 应付账款、存货、进项税 |
| 核销重点 | 借款和报销冲销、员工往来 | 应付单和付款单核销 |
| 附件重点 | 发票、行程、审批、合同、验收 | 发票、入库、合同、对账单 |

采购付款通常从应付单来；费用报销可能从报销单、借款单或付款申请来。

## 三、直接报销流程

### 1. 通俗流程

```text
员工花钱
  -> 整理发票和附件
  -> 填报销单
  -> 部门和财务审批
  -> 出纳付款
  -> 生成凭证
```

### 2. 系统重点字段

| 字段 | 为什么重要 |
| --- | --- |
| 报销人 | 决定员工往来和付款对象 |
| 费用承担部门 | 决定费用归属 |
| 费用项目 | 决定预算和科目 |
| 项目/客户/订单 | 决定项目核算和利润分析 |
| 发票类型和税额 | 决定是否能抵扣、怎么入账 |
| 收款账户 | 决定付款给谁 |
| 预算期间 | 决定预算是否充足 |

### 3. 常见分录理解

员工报销差旅费 1000 元，公司尚未付款：

```text
借：管理费用/销售费用-差旅费    1000
贷：其他应付款-员工             1000
```

实际付款：

```text
借：其他应付款-员工             1000
贷：银行存款                   1000
```

如果企业报销单审核后直接付款，也可能合并成：

```text
借：管理费用/销售费用-差旅费    1000
贷：银行存款                   1000
```

项目上要先确认企业凭证模板：是先挂其他应付款，还是付款时直接进费用。

## 四、借款、报销和还款

### 1. 为什么要借款

借款适合出差、项目现场、采购小额材料等需要员工先拿备用金的场景。

```text
借款
  -> 员工拿到备用金
  -> 发生费用
  -> 报销冲借款
  -> 多退少补
```

### 2. 三种结果

| 结果 | 示例 | 处理 |
| --- | --- | --- |
| 报销金额等于借款 | 借 3000，报销 3000 | 借款全额冲销 |
| 报销金额大于借款 | 借 3000，报销 3500 | 冲借款后补付 500 |
| 报销金额小于借款 | 借 3000，报销 2600 | 员工还款 400 |

### 3. 借款常见分录

公司借备用金给员工：

```text
借：其他应收款-员工借款    3000
贷：银行存款              3000
```

员工报销冲借款：

```text
借：管理费用/销售费用      2600
贷：其他应收款-员工借款    2600
```

员工退回剩余借款：

```text
借：银行存款               400
贷：其他应收款-员工借款     400
```

学习重点：借款不是费用，只有报销确认后才进入费用。

## 五、预算控制怎么介入

费用报销常见控制方式：

```text
事前申请
  -> 占用预算
  -> 报销冲减预算
  -> 超预算审批
  -> 月末预算执行分析
```

### 控制维度

| 维度 | 示例 |
| --- | --- |
| 组织 | A 公司 |
| 部门 | 销售部 |
| 期间 | 2026-06 |
| 费用项目 | 差旅费、招待费、办公费 |
| 项目 | ERP 项目、客户实施项目 |
| 员工 | 销售人员、项目经理 |

维度越细，控制越精确，但维护越复杂。对新项目，建议先从“组织 + 部门 + 期间 + 费用项目”开始。

### 预算常见问题

| 现象 | 通俗解释 | 先查什么 |
| --- | --- | --- |
| 报销提示预算不足 | 当前维度余额不够 | 部门、期间、费用项目、预算版本 |
| 明明有预算却过不了 | 单据取的维度和预算维度不一致 | 费用承担部门、项目、组织 |
| 预算占用不释放 | 申请单关闭或报销冲销没处理 | 申请状态、占用释放规则 |
| 超预算没人审批 | 流程条件没覆盖 | 审批流、金额条件、预算控制等级 |

## 六、发票和附件

费用报销要能经得起审计，附件不是摆设。

### 常见附件

| 费用类型 | 建议附件 |
| --- | --- |
| 差旅费 | 发票、行程单、出差申请、住宿清单 |
| 招待费 | 发票、招待事由、参与人员、审批记录 |
| 办公费 | 发票、采购明细、验收记录 |
| 培训费 | 发票、培训通知、签到或证书 |
| 项目费用 | 合同、验收、项目编号、客户确认 |

### 发票检查

- 发票抬头是否正确。
- 税号是否正确。
- 发票日期是否在可报销范围内。
- 金额和报销金额是否一致。
- 是否重复报销。
- 是否需要进项税认证或转出。

## 七、付款和银行对账

报销审核通过不等于钱已经付出。

```text
报销单审核
  -> 付款计划或付款单
  -> 出纳付款
  -> 银行流水
  -> 银行对账
  -> 生成付款凭证
```

### 付款检查点

| 检查点 | 说明 |
| --- | --- |
| 收款人 | 员工本人、供应商、第三方收款人 |
| 银行账号 | 是否和员工或供应商档案一致 |
| 付款账户 | 公司哪个银行账号付款 |
| 付款用途 | 差旅费、报销款、备用金等 |
| 付款状态 | 已制单、已提交银行、银行成功、银行失败 |
| 凭证状态 | 是否生成付款凭证 |

### 银企直连失败常见原因

| 现象 | 排查 |
| --- | --- |
| 银行退回 | 户名、账号、开户行错误 |
| 付款未到账 | 银行处理中、限额、复核未完成 |
| 金蝶已付款但银行无流水 | 银企接口失败或未回写 |
| 重复付款风险 | 重复提交、没有付款状态控制 |

## 八、费用凭证模板设计

费用凭证模板通常要解决三件事：

1. 费用进哪个科目。
2. 费用带哪个部门、项目、员工维度。
3. 付款或应付款怎么入账。

### 常见取数

| 单据字段 | 凭证用途 |
| --- | --- |
| 费用项目 | 决定费用科目 |
| 费用承担部门 | 决定部门维度 |
| 项目 | 决定项目维度 |
| 报销人 | 决定员工往来 |
| 税额 | 决定进项税或费用税额处理 |
| 付款账户 | 决定银行科目和银行账号维度 |

### 常见错误

| 错误 | 后果 |
| --- | --- |
| 费用项目没映射科目 | 生成凭证失败 |
| 费用科目要求部门维度但单据没带部门 | 维度为空 |
| 员工借款和员工报销维度不一致 | 借款冲不掉 |
| 报销单和付款单都进费用 | 费用重复入账 |
| 付款凭证没有银行账号维度 | 银行明细账不好对账 |

## 九、月末检查

费用报销月末要查：

- 报销单是否还有未审核。
- 借款是否长期未报销。
- 付款单是否已付款未生成凭证。
- 费用凭证是否全部过账。
- 预算占用是否释放。
- 发票和附件是否完整。
- 费用科目是否按部门、项目归集。
- 银行对账是否完成。

### 常用清单

| 清单 | 用途 |
| --- | --- |
| 未审核报销单 | 防止费用跨期 |
| 员工借款余额表 | 跟踪备用金和长期挂账 |
| 已付款未生成凭证 | 防止银行和总账不一致 |
| 费用预算执行表 | 看部门费用是否超支 |
| 发票缺失清单 | 审计和税务风险 |

## 十、学习练习

### 练习 1：直接报销

1. 建一个费用项目“差旅费”。
2. 做一张员工差旅报销单。
3. 让报销单走审批。
4. 审核后生成凭证。
5. 做付款单并生成付款凭证。
6. 查部门费用明细和银行日记账。

### 练习 2：借款后报销

1. 员工借款 3000 元。
2. 实际报销 2600 元。
3. 报销冲借款。
4. 员工退回 400 元。
5. 查员工借款余额是否为 0。

### 练习 3：预算控制

1. 给销售部差旅费设置月度预算 5000 元。
2. 做一张 3000 元报销单。
3. 再做一张 2500 元报销单。
4. 观察超预算控制和审批。
5. 查预算执行表。

## 十一、问题排查速查

| 问题 | 优先排查 |
| --- | --- |
| 报销单不能提交 | 必填字段、附件、预算、审批流 |
| 预算控制不对 | 组织、部门、期间、费用项目、预算版本 |
| 不能生成凭证 | 费用项目科目映射、部门维度、员工维度 |
| 付款失败 | 收款账号、银行限额、银企状态、复核状态 |
| 借款冲不掉 | 借款人、币别、组织、核销关系 |
| 费用重复入账 | 报销单和付款单凭证模板是否重复确认费用 |
| 月末费用漏记 | 未审核报销、未生成凭证、跨期单据 |
