预算、费用与控制教程讲的是预算基础。这篇继续深耕预算执行：预算怎么被申请占用，审批退回后怎么释放，报销和付款怎么消耗预算，预算调整怎么留痕，月末怎么解释“预算还有，但单据过不了”或“预算超了但财务报表没超”的问题。

预算执行最常见的混乱是：

- 预算编制完成了，但业务申请、费用报销、采购订单、付款申请没有真正受控。
- 预算占用后，单据作废、驳回、关闭，没有释放预算。
- 费用报销和付款都扣预算，导致重复占用或重复消耗。
- 财务看总账费用没有超，系统预算却显示超支，因为预算口径和总账科目口径不同。

## 一、预算执行主线

```text
预算编制
  -> 审批发布
  -> 业务申请占用预算
  -> 采购 / 报销 / 合同 / 付款继续流转
  -> 实际发生消耗预算
  -> 单据变更、关闭、作废释放预算
  -> 预算调整和追加
  -> 执行分析和差异复盘
```

预算控制要先定义“占用”和“消耗”。占用是预计要花，消耗是已经形成费用、成本或付款责任。

## 二、预算余额公式

```text
可用预算 = 已发布预算 + 预算追加 - 已占用预算 - 已消耗预算 + 已释放预算
```

但不同公司会有不同口径。

| 口径 | 说明 | 适合场景 |
| --- | --- | --- |
| 申请占用 | 费用申请或采购申请阶段先占预算 | 事前控制强 |
| 订单占用 | 采购订单、合同或报销单阶段占预算 | 控制承诺支出 |
| 报销消耗 | 报销审核后消耗预算 | 费用管理 |
| 付款消耗 | 付款审核或支付成功后消耗预算 | 资金预算 |
| 凭证消耗 | 凭证生成或过账后消耗预算 | 总账口径分析 |

项目实施时必须写清楚哪一类单据占用，哪一类单据消耗，避免一个业务链路重复扣预算。

## 三、费用报销预算链路

```text
费用申请
  -> 预算占用
  -> 审批通过
  -> 借款 / 预付款
  -> 费用报销
  -> 发票和附件校验
  -> 应付或付款
  -> 凭证
  -> 预算消耗
  -> 占用释放或冲销
```

| 环节 | 预算动作 | 常见风险 |
| --- | --- | --- |
| 费用申请 | 占用预算 | 申请长期未报销，占用不释放 |
| 申请驳回 | 释放预算 | 工作流只退回，预算状态未回滚 |
| 申请关闭 | 释放剩余额度 | 关闭不释放，导致可用预算偏低 |
| 报销引用申请 | 消耗预算或转占用为消耗 | 申请和报销重复扣预算 |
| 报销小于申请 | 释放差额 | 差额长期占用 |
| 报销大于申请 | 追加占用或走超预算审批 | 绕过申请控制 |
| 付款 | 资金预算消耗 | 和费用预算混在一起 |

## 四、采购预算链路

采购预算和费用预算不同。采购可能先形成库存和应付，不一定马上形成费用。

```text
采购申请
  -> 预算占用
  -> 采购订单
  -> 收料 / 入库
  -> 采购发票
  -> 应付确认
  -> 付款
  -> 存货 / 费用 / 固定资产 / 项目成本
```

| 采购类型 | 预算关注点 |
| --- | --- |
| 费用类采购 | 费用科目、部门、项目、预算项目 |
| 存货采购 | 采购预算、库存资金占用、采购价格 |
| 固定资产采购 | 资本预算、资产类别、项目 |
| 项目采购 | 项目预算、合同、进度、成本归集 |
| 服务采购 | 费用期间、合同履约、付款节点 |

不要把所有采购都直接扣费用预算。存货采购、资产采购、项目采购和费用采购要先分清预算类型。

## 五、预算维度和总账科目映射

预算维度通常比总账科目更接近管理语言。

| 预算维度 | 总账对象 | 风险 |
| --- | --- | --- |
| 费用项目 | 管理费用、销售费用、研发费用科目 | 一个费用项目对应多个科目 |
| 部门 | 核算维度或成本中心 | 部门调整影响历史对比 |
| 项目 | 项目核算维度 | 项目关闭后仍有费用 |
| 期间 | 会计期间或业务日期 | 申请期间和报销期间不一致 |
| 组织 | 核算组织或预算组织 | 预算组织和法人组织不一致 |
| 员工 | 报销人或申请人 | 员工调岗影响归属 |

建议建立一张预算项目和科目映射表。

| 预算项目 | 对应科目 | 控制单据 | 是否强控 |
| --- | --- | --- | --- |
| 差旅费 | 销售费用-差旅费、管理费用-差旅费 | 费用申请、报销单 | 是 |
| 招待费 | 销售费用-业务招待费、管理费用-业务招待费 | 费用申请、报销单 | 是 |
| 办公费 | 管理费用-办公费 | 报销单、采购订单 | 提醒 |
| IT 服务费 | 管理费用-信息服务费 | 合同、付款申请 | 审批 |

## 六、预算调整和追加

预算调整不是改数字这么简单。它要说明为什么改、谁批准、从哪里调入、调到哪里、是否影响考核。

| 调整类型 | 示例 | 控制点 |
| --- | --- | --- |
| 预算追加 | 新项目、新活动、新政策 | 需要审批和资金来源说明 |
| 预算调剂 | A 部门调给 B 部门 | 双方确认和管理层审批 |
| 期间滚动 | 上月未用额度滚到下月 | 是否允许结转 |
| 项目转移 | 项目 A 剩余额度转给项目 B | 项目责任人确认 |
| 冻结预算 | 暂停某项支出 | 冻结原因和解冻条件 |

调整记录至少要有：

- 调整单号。
- 调整前预算。
- 调整金额。
- 调整后预算。
- 调入调出组织、部门、项目和费用项目。
- 调整原因。
- 审批人和审批时间。

## 七、预算执行分析

预算执行分析不只是看执行率。

| 指标 | 公式 | 解释 |
| --- | --- | --- |
| 执行率 | 实际消耗 / 已发布预算 | 花了多少 |
| 占用率 | 已占用 / 已发布预算 | 已经承诺要花多少 |
| 可用率 | 可用预算 / 已发布预算 | 还能花多少 |
| 超支金额 | 实际消耗 - 预算 | 是否超出 |
| 占用未发生 | 已占用 - 已消耗 | 是否有长期挂起申请 |
| 预算释放率 | 已释放 / 已占用 | 作废、关闭、差额释放是否正常 |
| 预算调整率 | 调整金额 / 原预算 | 编制是否准确 |

### 月度分析表

| 维度 | 预算 | 占用 | 实际 | 可用 | 执行率 | 主要原因 |
| --- | --- | --- | --- | --- | --- | --- |
| 销售部-差旅费 | 100,000 | 20,000 | 65,000 | 15,000 | 65% | 大客户拜访增加 |
| 研发部-测试费 | 80,000 | 50,000 | 20,000 | 10,000 | 25% | 采购申请已下单未验收 |
| 市场部-活动费 | 200,000 | 30,000 | 210,000 | -40,000 | 105% | 临时活动追加未审批 |

## 八、常见异常排查

| 现象 | 可能原因 | 排查路径 | 处理 |
| --- | --- | --- | --- |
| 明明还有预算，单据提示超预算 | 维度不一致、期间不一致、占用未释放 | 查预算维度、申请单、占用明细 | 释放无效占用或修正维度 |
| 总账费用没超，预算显示超支 | 预算按申请或报销占用，总账按凭证实际 | 对比占用、报销、凭证 | 给报表加口径说明 |
| 单据作废后预算没释放 | 作废没有触发释放逻辑 | 查单据状态和预算占用流水 | 补释放或修配置 |
| 报销重复扣预算 | 申请和报销都按全额扣 | 查引用关系和预算规则 | 改成申请占用、报销转消耗 |
| 部门调岗后费用归属错 | 员工部门取当前部门，不取业务发生部门 | 查员工历史部门和单据部门 | 单据显式带部门 |
| 预算调整后报表不变 | 调整未发布或报表取原预算 | 查调整单状态和预算版本 | 发布调整并刷新报表 |

## 九、实施测试用例

| 用例 | 验证目标 |
| --- | --- |
| 正常费用申请 1000，报销 1000 | 占用转消耗 |
| 申请 1000，报销 800 | 消耗 800，释放 200 |
| 申请 1000，驳回 | 占用释放 |
| 申请 1000，作废 | 占用释放 |
| 报销 1200 引用申请 1000 | 超额 200 是否走审批 |
| 无申请直接报销 | 是否允许，是否扣预算 |
| 部门预算不足 | 提醒、强控或超预算审批 |
| 预算调剂 | 调出减少、调入增加 |
| 跨月报销 | 占用期间和消耗期间是否正确 |
| 付款申请 | 是否影响资金预算而不是费用预算 |

## 十、审批和权限控制

| 操作 | 风险 | 控制 |
| --- | --- | --- |
| 新增预算 | 虚增额度 | 预算负责人审批 |
| 调整预算 | 转移责任 | 调入调出双方确认 |
| 超预算审批 | 绕过控制 | 审批原因必填，金额分级 |
| 手工释放占用 | 释放真实业务预算 | 需要单据依据 |
| 修改预算维度 | 改变责任归属 | 审计日志和权限控制 |
| 导出预算明细 | 泄露经营计划 | 限制敏感报表权限 |

## 十一、预算证据包

月末建议保留：

- 已发布预算版本。
- 本期预算调整清单。
- 预算占用明细。
- 预算消耗明细。
- 预算释放明细。
- 超预算审批清单。
- 费用报销和采购申请抽样。
- 总账费用明细。
- 执行分析报告。
- 异常处理记录。

## 十二、三个典型案例

### 案例 1：预算被旧申请占住

现象：销售部差旅费预算还有 3 万，但新报销提示超预算。

排查：

1. 查预算占用明细。
2. 找到三个月前已审批但未报销的差旅申请。
3. 查申请是否已经过期或业务取消。

处理：

- 关闭无效申请并释放预算。
- 设置申请有效期，超期自动提醒。
- 月末输出长期占用清单。

### 案例 2：报销和付款重复扣预算

现象：费用报销审核时扣一次预算，付款申请又扣一次预算。

排查：

1. 查预算规则绑定的单据类型。
2. 查付款申请是否引用报销单。
3. 查预算类型是费用预算还是资金预算。

处理：

- 费用预算在报销阶段消耗。
- 资金预算在付款阶段消耗。
- 报销和付款之间建立引用关系，避免重复扣同一预算。

### 案例 3：预算执行率低，但资金已经紧张

现象：预算执行率只有 50%，资金计划却显示下月付款压力大。

排查：

1. 查已占用未消耗的采购订单、合同和报销申请。
2. 查应付账款和付款计划。
3. 查预算是否按费用确认，资金按付款日期。

处理：

- 同时看费用预算和资金预算。
- 增加承诺支出报表。
- 对大额采购和项目合同做付款节奏分析。
