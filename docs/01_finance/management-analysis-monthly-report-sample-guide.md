集团管理分析专题讲了口径和方法。这篇给一个可以直接照着搭的经营分析月报样例，把事业部利润、产品线毛利、客户贡献、预算执行、库存应收和异常事项放到同一套月报里。

月报不应该只是截图堆砌。好的经营分析月报要能回答：

- 本月赚钱还是亏钱，和预算、上月、去年同期比怎么样。
- 哪个事业部、产品线、客户、渠道贡献最大。
- 毛利下降是价格、成本、结构、折扣、返利还是售后导致。
- 预算超支在哪，是真超支还是占用未释放。
- 资金被库存、应收还是项目占住。
- 下月必须处理哪些异常。

## 一、月报结构

```text
1. 管理摘要
2. 集团经营总览
3. 事业部利润
4. 产品线毛利
5. 客户贡献
6. 渠道和区域
7. 预算执行
8. 库存、应收和资金占用
9. 内部交易和分摊
10. 异常清单和行动项
```

摘要页只写 3-5 条结论，不要写流水账。

示例：

```text
本月收入达成预算 96%，毛利率低于预算 2.3 个百分点，主要来自 A 产品线降价和 B 工厂材料成本上升。
销售一部收入增长，但客户 X 回款延迟导致应收增加 180 万。
市场部活动费超预算 12%，其中 8% 来自已审批追加，4% 为未释放占用。
```

### 分析口径

| 项目 | 说明 |
| --- | --- |
| 对外收入 | 排除内部客户和内部交易 |
| 内部收入 | 只用于管理考核，不进入对外合并收入 |
| 直接费用 | 单据或凭证直接带事业部维度 |
| 分摊费用 | 按人数、收入、工时、面积等规则分摊 |
| 管理利润 | 不等于法人口径利润，需保留调节表 |

### 差异拆解

| 差异 | 排查方向 |
| --- | --- |
| 价格下降 | 订单折扣、促销、渠道返利、客户议价 |
| 成本上升 | 采购价差、材料替代、制造费用、委外加工费 |
| 产品结构变化 | 高毛利产品占比下降 |
| 退货增加 | 红字应收、红字发票、成本冲回 |
| 售后成本增加 | 免费备件、维修、索赔、服务费 |

### 必须拆出三类异常

| 异常 | 说明 | 处理 |
| --- | --- | --- |
| 真超支 | 已消耗超过预算 | 追加、调剂或费用控制 |
| 占用未释放 | 申请或采购长期占用预算 | 关闭、释放或继续跟进 |
| 口径差异 | 总账没超但预算超 | 解释占用口径和消耗口径 |

检查：

- 内部收入和内部成本是否成对。
- 内部价是否按有效价格执行。
- 是否有一方入账，另一方未入账。

## 十一、月报编制流程

```text
D+1 固定期间和组织范围
D+2 导出收入、成本、费用、预算、应收、库存
D+3 处理口径差异和维度缺失
D+4 形成事业部、产品线、客户和预算页
D+5 业务负责人确认异常原因
D+6 管理层会议
D+7 行动项跟踪
```

## 十二、常见问题

| 问题 | 处理 |
| --- | --- |
| 报表太多没人看 | 摘要页只保留关键指标和异常 |
| 业务不认可分摊 | 分摊动因提前确认并固定周期 |
| 毛利和财务利润对不上 | 做法人口径到管理口径调节表 |
| 产品线缺失 | 从物料主数据或订单分录补维度 |
| 客户贡献低但销售额高 | 增加应收、售后和资金占用指标 |
