税务发票管理解决的是发票怎么开、怎么收、怎么红冲、怎么归档。这篇继续补月末税务申报勾稽：系统里的销售发票、采购发票、红字发票、应收应付、收入确认、总账税金科目和税务平台申报数据到底怎么对上。

税务申报最怕三类情况：

- 业务已经发生，但发票还没开或还没收到，形成未开票收入、暂估应付、待认证进项。
- 发票已经开具或收到，但收入、成本、应收应付或总账凭证不在同一期间。
- 红字、折让、退货、作废、冲销发生在跨期，税务口径和管理口径都说得通，但没有勾稽证据。

这篇的目标不是替代税法判断，而是给金蝶项目落地一个可查、可复核的税务月结工作台。

## 一、税务申报勾稽主线

```text
业务单据
  -> 应收 / 应付 / 收付款 / 暂估
  -> 销售发票 / 采购发票 / 红字发票
  -> 发票平台或税务系统
  -> 凭证和总账税金科目
  -> 纳税申报表
  -> 电子档案和月结证据包
```

不要只拿发票平台数据直接申报，也不要只拿总账科目余额申报。项目里更稳的做法是把“业务事实、发票事实、账务事实、申报事实”四条线对齐。

| 事实线 | 代表数据 | 主要问题 |
| --- | --- | --- |
| 业务事实 | 销售出库、采购入库、退货、服务交付、合同履约 | 是否已经形成收入、成本、应收应付 |
| 发票事实 | 蓝字发票、红字发票、作废发票、认证抵扣状态 | 发票期间、税率、税额、购销方、状态是否正确 |
| 账务事实 | 应交税费科目、收入、成本、往来、暂估 | 凭证期间、科目、核算维度是否正确 |
| 申报事实 | 销项税、进项税、进项转出、留抵、附表数据 | 申报口径是否和发票及账务一致 |

## 二、先明确月末需要对哪些数

| 勾稽对象 | 来源 | 对账目标 |
| --- | --- | --- |
| 销售发票销项税额 | 金蝶销售发票、税控或电子发票平台 | 和申报销项税额一致 |
| 销售发票不含税金额 | 销售发票、收入明细、合同履约台账 | 判断开票收入和会计收入差异 |
| 红字销售发票 | 销售退货、折让、红冲申请、红字发票 | 判断是否冲应收、冲收入、冲税额 |
| 未开票收入 | 出库、验收、服务完成、收入确认单 | 判断收入确认但未开票的余额 |
| 已开票未确认收入 | 预收、先开票后交付、分期履约 | 判断是否挂合同负债或递延收入 |
| 采购发票进项税额 | 采购发票、税务平台勾选认证 | 和可抵扣进项税额一致 |
| 暂估和到票差异 | 采购入库、暂估应付、采购发票、采购结算 | 判断暂估冲回和价差是否完整 |
| 进项税额转出 | 非应税项目、福利、损失、用途变化 | 判断凭证、税务调整和附件是否齐全 |

## 三、销售侧勾稽

销售侧要把五个金额分清楚：订单金额、出库金额、应收金额、发票金额、收入金额。它们不一定在同一期间相等。

```text
销售订单
  -> 发货通知 / 销售出库
  -> 应收单
  -> 销售发票
  -> 收入确认
  -> 总账凭证
  -> 申报销项税
```

| 场景 | 常见差异 | 处理口径 |
| --- | --- | --- |
| 出库已完成但未开票 | 管理报表有收入，发票平台没有销项 | 根据收入政策确认未开票收入和销项税风险 |
| 已开票但未发货 | 发票平台有销项，业务未履约 | 判断是否预收、合同负债或税务提前纳税 |
| 分批出库分批开票 | 本月出库和本月开票不一致 | 建立订单、出库、应收、发票的分批明细 |
| 销售退货跨期红冲 | 本期红字发票冲以前期间蓝字 | 对应退货入库、红字应收、收入冲减和税额冲减 |
| 折扣折让 | 发票金额小于订单或应收 | 检查折让审批、价税拆分和收入净额 |

### 销售侧月末检查

| 检查项 | 看什么 | 异常信号 |
| --- | --- | --- |
| 本期开票清单 | 发票日期、客户、税率、金额、税额、状态 | 作废、红冲、税率为空、客户不一致 |
| 本期收入清单 | 收入确认日期、收入科目、客户、物料、合同 | 收入确认但没有发票或没有出库 |
| 未开票收入 | 已履约未开票、已出库未开票、服务完成未开票 | 长期挂账、客户拒绝开票、合同条款不清 |
| 已开票未收入 | 发票已开但未交付、预收性质业务 | 收入提前确认或合同负债未挂 |
| 红字发票 | 红字原因、对应蓝字、退货单、折让审批 | 红字没有业务原因或跨期无说明 |

## 四、采购侧勾稽

采购侧要把四个金额分清楚：入库暂估、采购发票、应付确认、进项税认证。采购到票不等于进项已经可抵扣，入库暂估也不等于最终采购成本。

```text
采购订单
  -> 采购入库
  -> 暂估应付
  -> 采购发票
  -> 采购结算 / 暂估冲回 / 价差处理
  -> 应付确认
  -> 进项认证
  -> 总账凭证
```

| 场景 | 常见差异 | 处理口径 |
| --- | --- | --- |
| 入库已暂估但发票未到 | 存货和暂估应付已有金额，进项税没有 | 暂估应付继续保留，跟踪到票计划 |
| 发票已到但未结算 | 进项已有，采购成本未最终确认 | 补采购结算和暂估冲回 |
| 发票税额和系统税额差几分钱 | 税额尾差、四舍五入、价税拆分方式不同 | 按公司税务口径调整尾差，不手改无依据字段 |
| 采购退货跨期 | 红字采购发票晚于退货 | 检查退货出库、红字应付、进项转出或冲减 |
| 费用发票未分摊 | 运费、保险、关税等未进成本 | 检查采购费用分配和存货成本 |

### 采购侧月末检查

| 检查项 | 看什么 | 异常信号 |
| --- | --- | --- |
| 到票清单 | 发票供应商、采购组织、税率、税额、认证状态 | 供应商和采购单不一致、税率异常 |
| 暂估余额 | 入库期间、暂估金额、供应商、物料 | 长账龄暂估、负数暂估、无采购订单 |
| 采购结算 | 入库单、发票、费用分配、价差 | 发票到但未结算、费用未分摊 |
| 进项认证 | 发票认证期间、抵扣状态 | 已入账未认证、已认证未入账 |
| 红字采购发票 | 退货、折让、供应商扣款 | 没有关联退货或扣款依据 |

## 五、红字发票和作废发票

红字和作废是税务对账里的高危点，因为它们经常被当成“发票平台处理完了”，但金蝶里的应收、应付、收入、成本和库存没有同步处理。

| 情况 | 应同步检查 |
| --- | --- |
| 本月蓝字本月作废 | 发票状态是否作废，业务应收应付是否也撤销或未生成 |
| 本月红冲以前期间蓝字 | 是否有关联原发票、退货、折让、客户确认和审批 |
| 销售退货红字发票 | 是否有退货入库、红字应收、成本冲回和库存恢复 |
| 采购退货红字发票 | 是否有退料、红字应付、进项转出或冲减 |
| 只红冲金额不退货 | 是否属于折让、赔偿、质量扣款或价格调整 |

红字发票要能回答三个问题：

1. 为什么红冲：退货、折让、价格错误、开票错误、质量赔偿还是合同变更。
2. 红冲哪张蓝字：原发票号、原业务单据、原凭证。
3. 红冲后业务余额是否正确：客户往来、供应商往来、库存、收入、成本、税金。

## 六、未开票收入和已开票未确认收入

这两个科目或台账最容易让销售、财务、税务三方吵起来。关键不是谁对谁错，而是要把业务状态和税务状态拆开。

| 类型 | 典型业务 | 应保留证据 |
| --- | --- | --- |
| 已出库未开票 | 货已发、客户未要求开票 | 出库单、签收单、合同、应收或收入确认依据 |
| 已验收未开票 | 项目或服务已验收，发票待开 | 验收单、项目节点、合同条款 |
| 已开票未发货 | 客户要求先票后货 | 发票、合同、预收或发货计划 |
| 已开票未履约 | 分期服务、延保、维护服务 | 合同期间、履约进度、递延收入台账 |
| 部分开票部分履约 | 长周期合同、分批交付 | 履约进度表、开票计划、收入分摊表 |

### 月末台账字段

| 字段 | 用途 |
| --- | --- |
| 客户、合同、订单 | 追溯责任人和业务来源 |
| 业务单号 | 追到出库、验收、服务完成或应收 |
| 发票号码 | 追到蓝字、红字和作废状态 |
| 收入期间 | 判断会计收入归属 |
| 开票期间 | 判断税务销项归属 |
| 不含税金额、税额 | 拆分收入和税金 |
| 差异原因 | 未开票、预开票、红冲、折让、跨期 |
| 预计处理期间 | 防止长期挂账 |

## 七、总账科目勾稽

税务申报不能只看发票列表，还要看总账。常见科目包括：

- 应交税费-应交增值税-销项税额。
- 应交税费-应交增值税-进项税额。
- 应交税费-应交增值税-进项税额转出。
- 应交税费-未交增值税。
- 主营业务收入、其他业务收入。
- 应收账款、合同负债、预收账款。
- 应付账款、暂估应付、材料采购或库存商品。

| 对账动作 | 目标 |
| --- | --- |
| 发票税额和应交税费明细账核对 | 判断凭证是否生成、科目是否正确 |
| 收入明细和销售发票核对 | 判断开票收入差异 |
| 采购发票进项和应交税费进项核对 | 判断进项凭证是否完整 |
| 进项认证清单和进项税科目核对 | 判断已认证未入账或已入账未认证 |
| 红字发票和冲销凭证核对 | 判断是否税务处理了但账务没处理 |

## 九、常见差异排查表

| 现象 | 可能原因 | 排查路径 | 处理建议 |
| --- | --- | --- | --- |
| 申报销项大于金蝶销项 | 发票平台有发票未同步金蝶、作废状态不同 | 对比发票号码和开票日期 | 补同步或确认线下开票原因 |
| 金蝶销项大于申报销项 | 金蝶发票未上传、发票状态错误、税务平台未取到 | 查发票状态、接口日志、税务平台 | 补传或更正状态 |
| 收入大于发票金额 | 未开票收入、不开票收入、跨期开票 | 对比收入确认单和发票清单 | 建未开票收入台账 |
| 发票金额大于收入 | 预开票、已开票未履约、合同负债 | 查合同、订单、发货和验收 | 挂合同负债或递延收入 |
| 进项税总账大于认证清单 | 已入账未认证、进项税科目误用 | 查采购发票认证状态和凭证 | 分清待认证和已认证 |
| 认证清单大于总账进项 | 已认证未入账、发票未同步 | 查采购发票和凭证生成 | 补发票或补凭证 |
| 红字发票冲了税但应收没冲 | 红字发票未关联红字应收 | 查红字发票来源单和应收余额 | 补红字应收或冲销单 |
| 税额差几分钱 | 价税拆分、税率尾差、系统精度 | 按发票号码逐张对比 | 统一尾差调整规则 |

## 十一、证据包模板

税务月结建议每期保留一份证据包，至少包括：

- 本期销售发票清单。
- 本期红字销售发票清单。
- 本期采购发票清单。
- 本期进项认证或勾选清单。
- 未开票收入台账。
- 已开票未确认收入台账。
- 暂估应付和本期到票冲回明细。
- 应交税费科目明细账。
- 申报表关键附表截图或导出。
- 差异处理记录和审批记录。

## 十二、三个典型案例

### 案例 1：销售收入已经确认，但本月没有开票

现象：利润表收入已经增加，税务平台没有对应发票，销售说客户要求下月开票。

排查：

1. 查销售出库、签收或验收日期。
2. 查收入确认单和凭证期间。
3. 查合同开票条款。
4. 查是否存在未开票收入台账。

处理：

- 如果会计收入确认成立，补充未开票收入台账和税务风险说明。
- 如果收入提前确认，冲回或调整收入确认期间。
- 后续开票时把发票和原收入确认单关联，避免重复确认收入。

### 案例 2：红字发票已开，但客户往来仍有余额

现象：税务平台红字发票已经开具，申报销项已冲减，但应收账款没有减少。

排查：

1. 查红字发票是否关联原蓝字发票。
2. 查是否生成红字应收或折让单。
3. 查是否发生退货入库、退款或核销。
4. 查凭证是否生成。

处理：

- 补红字应收或折让处理。
- 如果需要退款，补收款退款单或付款流程。
- 如果只是价格折让，保留客户确认和审批附件。

### 案例 3：采购发票已认证，但金蝶进项税没有增加

现象：税务平台显示发票已勾选认证，金蝶应交税费进项税额没有对应凭证。

排查：

1. 查采购发票是否已录入金蝶。
2. 查采购发票是否审核。
3. 查凭证生成情况。
4. 查凭证模板科目是否指向待认证或已认证进项。

处理：

- 补录或同步采购发票。
- 补审核和凭证生成。
- 如果科目错，按财务制度做调整凭证，并修正模板。
