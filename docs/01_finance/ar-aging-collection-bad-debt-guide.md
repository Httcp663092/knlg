应收账龄不是一张普通报表，它反映的是“客户欠款已经拖了多久、还能不能收回来、谁要负责跟进”。如果只看应收余额，只能知道客户欠多少钱；看账龄，才能知道哪些款已经到期、哪些款正在变成风险。

在金蝶里，应收账龄、催收和坏账准备通常串成一条管理链：

```text
销售业务形成应收
  -> 收款条件计算到期日
  -> 收款和应收核销
  -> 应收账龄分析
  -> 催收跟进和信用控制
  -> 坏账准备或坏账核销
  -> 总账、报表和审计证据
```

这篇手册重点讲“怎么看懂账龄、怎么排查账龄不准、怎么把催收和坏账准备落到系统动作”。

## 一、先理解几个对象

| 对象 | 通俗解释 | 为什么重要 |
| --- | --- | --- |
| 客户 | 买货或接受服务的一方 | 销售和对账的业务对象 |
| 结算客户 | 真正承担应收债权的一方 | 账龄、核销、对账通常看它 |
| 收款客户 | 实际付款的一方 | 集团客户、代付场景要特别注意 |
| 应收单 | 客户欠款的系统凭据 | 账龄和对账的基础 |
| 收款单 | 客户回款记录 | 只有核销后才真正冲减具体应收 |
| 核销 | 把收款匹配到应收 | 影响未收金额、账龄、客户对账单 |
| 收款条件 | 约定账期和到期日规则 | 决定账龄从哪天开始逾期 |
| 到期日 | 该收款的日期 | 逾期判断核心字段 |
| 账龄区间 | 欠款拖延时间段 | 例如未到期、1-30 天、31-60 天 |
| 坏账准备 | 对可能收不回的应收预先计提损失 | 影响利润和资产质量 |

一句话记忆：应收单告诉你“谁欠我钱”，收款条件告诉你“什么时候该还”，核销告诉你“哪笔钱还了哪笔账”，账龄告诉你“欠款拖了多久”，坏账准备告诉你“可能收不回多少”。

## 二、账龄到底怎么算

账龄的核心不是凭证日期，而是未收金额和账龄基准日之间的关系。常见口径有三类：

| 口径 | 计算基准 | 适用场景 |
| --- | --- | --- |
| 按业务日期 | 应收单业务日期到查询日期 | 看款项形成多久 |
| 按到期日 | 应收到期日到查询日期 | 看是否逾期，更适合催收 |
| 按发票日期 | 发票日期到查询日期 | 以开票作为回款起点的企业 |

项目上最常见、也最贴近催收的是“按到期日”。例如：

- 6 月 1 日发货并形成应收。
- 收款条件是 30 天。
- 到期日是 7 月 1 日。
- 7 月 15 日查询账龄。
- 这笔款逾期 14 天，进入 1-30 天逾期区间。

如果按业务日期算，则 7 月 15 日距离 6 月 1 日已经 44 天，可能落入 31-60 天区间。两个结果都可能“有道理”，但管理含义不同。上线前必须把企业采用的口径说清楚。

## 三、账龄区间怎么设计

常见区间：

| 区间 | 管理含义 | 建议动作 |
| --- | --- | --- |
| 未到期 | 正常账期内 | 正常跟踪，不要提前制造紧张 |
| 逾期 1-30 天 | 轻微逾期 | 销售提醒、财务发对账单 |
| 逾期 31-60 天 | 中度风险 | 销售主管介入，限制新增赊销 |
| 逾期 61-90 天 | 高风险 | 信用冻结、法务或管理层关注 |
| 逾期 91-180 天 | 严重风险 | 评估坏账准备、专项催收 |
| 逾期 180 天以上 | 重大风险 | 坏账准备、诉讼、核销审批 |

不同企业可以调整区间。例如快消行业账期短，30 天已经严重；工程项目回款周期长，90 天可能仍是正常节点款。区间设计要结合行业和合同，而不是照搬模板。

## 四、应收日常治理流程

```text
每日审核应收和收款
  -> 每周核销未核销收款
  -> 每周输出账龄和重点客户清单
  -> 销售确认回款承诺
  -> 财务跟踪到账和核销
  -> 逾期升级到信用控制
  -> 月末计提坏账准备或形成风险说明
```

### 每日动作

- 检查昨日新增应收是否审核。
- 检查银行到账是否已录入收款单。
- 检查收款单是否及时核销。
- 检查异常客户是否新增大额赊销。

### 每周动作

- 输出应收账龄分析表。
- 标记超过信用期限的客户。
- 给销售发送催收清单。
- 复核客户承诺付款日期。
- 清理“已收款但未核销”的单据。

### 月末动作

- 应收余额和总账应收科目核对。
- 账龄表和客户对账单归档。
- 长账龄客户形成风险清单。
- 按会计政策计提坏账准备。
- 对确实无法收回的款项准备坏账核销资料。

## 五、催收闭环怎么做

催收不是财务一个部门的事。财务负责提供准确账龄和对账依据，销售负责客户沟通，管理层负责信用政策和升级处理。

| 步骤 | 责任人 | 输出 |
| --- | --- | --- |
| 输出账龄清单 | 应收会计 | 客户、应收单、到期日、逾期天数、未收金额 |
| 确认争议 | 销售 / 客服 | 是否有质量、价格、发票、合同争议 |
| 发对账单 | 财务 | 客户确认的往来明细 |
| 承诺回款 | 销售 | 承诺日期、金额、付款方式 |
| 回款跟踪 | 财务 / 出纳 | 收款单、银行流水、核销记录 |
| 逾期升级 | 销售主管 / 财务经理 | 信用冻结、暂停发货、法务介入 |

催收清单建议至少包含这些字段：

| 字段 | 作用 |
| --- | --- |
| 销售组织 | 区分哪个公司或事业部 |
| 客户 / 结算客户 | 明确债权对象 |
| 销售员 | 明确催收责任 |
| 应收单号 | 能追到原业务 |
| 原销售订单 / 出库单 | 方便解释交易背景 |
| 应收金额 | 原始债权 |
| 已收金额 | 已回款部分 |
| 未收金额 | 需要催收金额 |
| 到期日 | 判断是否逾期 |
| 逾期天数 | 催收优先级 |
| 最近承诺付款日 | 跟进客户承诺 |
| 争议原因 | 质量、价格、发票、合同、资金困难等 |
| 当前动作 | 提醒、冻结、法务、坏账准备 |

## 六、坏账准备和坏账核销

坏账准备和坏账核销不是一回事。

| 项目 | 坏账准备 | 坏账核销 |
| --- | --- | --- |
| 含义 | 预计可能收不回，先确认损失风险 | 确认已经无法收回，把应收冲掉 |
| 应收是否还在 | 应收仍在，另有备抵科目 | 应收减少或转销 |
| 是否影响利润 | 计提时影响当期损益 | 已计提的核销通常先冲准备 |
| 证据要求 | 账龄、客户风险、历史损失率 | 法务、破产、长期催收无果、审批 |
| 管理意义 | 提前反映资产风险 | 清理无法收回的历史款 |

常见坏账准备方法：

| 方法 | 说明 | 适用 |
| --- | --- | --- |
| 账龄比例法 | 不同账龄按不同比例计提 | 最常见，便于系统化 |
| 个别认定法 | 对特定客户单独判断风险 | 大客户、诉讼、破产客户 |
| 余额百分比法 | 按应收余额统一比例 | 粗略管理，不够精细 |
| 组合模型 | 按客户类型、行业、信用等级和账龄组合 | 管理成熟企业 |

示例：账龄比例法

| 账龄 | 未收金额 | 计提比例 | 坏账准备 |
| --- | ---: | ---: | ---: |
| 未到期 | 100,000 | 0% | 0 |
| 1-30 天 | 80,000 | 1% | 800 |
| 31-60 天 | 50,000 | 3% | 1,500 |
| 61-90 天 | 30,000 | 10% | 3,000 |
| 91-180 天 | 20,000 | 30% | 6,000 |
| 180 天以上 | 10,000 | 80% | 8,000 |

合计应计提坏账准备 19,300 元。实际比例必须按企业会计政策、审计要求和税务口径确定。

### 常见分录

计提坏账准备：

```text
借：信用减值损失
  贷：坏账准备
```

转回多计提准备：

```text
借：坏账准备
  贷：信用减值损失
```

确认坏账核销：

```text
借：坏账准备
  贷：应收账款-客户
```

已核销坏账又收回：

```text
借：银行存款
  贷：坏账准备 / 信用减值损失
```

具体科目方向要按企业会计制度和审计意见执行，这里只用于理解系统逻辑。

## 七、金蝶里重点检查哪些字段

| 字段 / 设置 | 影响 |
| --- | --- |
| 客户 | 客户余额和销售分析 |
| 结算客户 | 应收、核销、账龄和对账 |
| 收款条件 | 到期日和账龄 |
| 应收单业务日期 | 应收形成日期 |
| 到期日 | 逾期判断 |
| 币别 | 外币账龄和汇兑处理 |
| 组织 | 多组织查询边界 |
| 核销状态 | 未收金额和账龄 |
| 单据状态 | 未审核单据是否纳入报表 |
| 凭证状态 | 总账是否已经反映 |
| 信用额度 | 逾期后是否控制发货 |

多组织环境尤其要小心：客户 A 在销售组织 1 的应收，不能随便用销售组织 2 的收款核销。集团客户、代收代付、统一结算客户也要在基础资料和核销方案里提前设计好。

## 八、账龄不准怎么排查

| 现象 | 常见原因 | 排查动作 |
| --- | --- | --- |
| 客户已付款，账龄仍逾期 | 收款单未核销到应收单 | 查收款核销记录 |
| 账龄金额大于客户余额 | 查询口径包含未审核或未过账单据 | 统一报表参数和单据状态 |
| 到期日明显不对 | 收款条件错误或单据日期错误 | 查客户收款条件和应收单到期日 |
| 客户账龄串户 | 客户、结算客户、收款客户混用 | 查应收单和收款单客户字段 |
| 外币账龄金额对不上 | 原币、本位币、汇率口径不同 | 分别按原币和本位币核对 |
| 总账应收和账龄不一致 | 手工凭证直接做应收科目 | 查总账辅助明细和业务单据凭证 |
| 红字应收仍显示异常 | 红字单据没有核销原应收 | 做红蓝应收核销或应收调整 |
| 期初账龄不准 | 期初只导余额，没有导明细和到期日 | 重新整理期初往来明细 |

排查顺序建议：

1. 先固定查询条件：组织、客户、币别、截止日期、是否含未审核。
2. 查应收明细，确认未收金额。
3. 查收款单，确认是否核销。
4. 查到期日，确认收款条件是否正确。
5. 查凭证，确认总账是否同步。
6. 查是否存在手工凭证或期初导入问题。

## 九、几个高频案例

### 案例 1：回款已经到账，但账龄仍显示逾期

现象：

- 银行流水有客户付款。
- 收款单已审核。
- 应收账龄表仍显示该客户逾期。

排查：

1. 收款单是否和具体应收单核销。
2. 收款客户和结算客户是否一致。
3. 收款单是否核销到了另一张应收单。
4. 是否存在预收款未转应收。

处理：

- 做收款核销，把收款单匹配到逾期应收单。
- 如果核销错对象，按权限反核销后重做。
- 重新输出应收账龄和客户对账单。

### 案例 2：销售说客户不欠钱，财务账龄还有余额

现象：

- 销售认为客户已经用后续折让或退货抵掉欠款。
- 财务账龄仍有未收金额。

排查：

1. 是否存在销售退货单。
2. 退货是否生成红字应收。
3. 红字应收是否和原应收核销。
4. 折让是否只在销售备忘中记录，没有进入应收。

处理：

- 补齐红字应收或折让应收调整。
- 做红蓝单据核销。
- 把客户争议原因写入催收记录。

### 案例 3：坏账准备金额和账龄表对不上

现象：

- 财务按账龄表计算坏账准备。
- 审计复核发现计提金额不一致。

排查：

1. 账龄表截止日期是否和计提日期一致。
2. 是否排除了关联方、保证金、押金等特殊款项。
3. 是否按原币还是本位币计提。
4. 账龄比例是否使用了最新会计政策。
5. 已单独认定的客户是否重复按账龄比例计提。

处理：

- 固定坏账准备计算底稿模板。
- 将排除项、特殊客户和个别认定客户单独列示。
- 保存账龄表、计算表、审批记录和凭证作为审计证据。

### 案例 4：客户长期欠款但系统仍允许继续发货

现象：

- 客户逾期超过 90 天。
- 销售订单仍能审核，仓库仍能出库。

排查：

1. 客户是否启用信用控制。
2. 信用额度是否包含逾期应收。
3. 信用控制点是在订单、出库还是发货通知。
4. 是否存在超信用审批绕过。
5. 逾期客户是否被放入特殊白名单。

处理：

- 按企业政策启用信用控制。
- 把账龄逾期清单纳入销售订单审核规则。
- 对例外放行保留审批记录。

## 十、月末证据包

月末应收风险治理建议归档这些材料：

- 应收款汇总表。
- 应收款明细表。
- 应收账龄分析表。
- 重点逾期客户清单。
- 销售催收反馈表。
- 客户对账单或客户确认记录。
- 坏账准备计算底稿。
- 坏账准备审批记录。
- 坏账准备凭证。
- 长账龄款项专项说明。

如果未来发生审计、诉讼、客户争议，证据包会非常有用。不要等客户不认账时才临时找单据。

## 十一、学习练习

建议在测试环境做四组练习：

1. 做一笔 30 天账期的销售应收，查看到期日前后的账龄变化。
2. 做一笔收款但不核销，观察账龄为什么仍然异常；再核销并复查。
3. 做一笔部分收款，观察未收金额如何进入账龄。
4. 做一笔 180 天以上逾期款，按账龄比例计算坏账准备并生成凭证。

学会的标准：

- 能解释账龄为什么不是简单按凭证日期算。
- 能判断一笔收款为什么没有减少账龄。
- 能把销售催收清单和财务应收明细对起来。
- 能说明坏账准备和坏账核销的区别。
