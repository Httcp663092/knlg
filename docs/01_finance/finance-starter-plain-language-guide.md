这篇给刚接触金蝶、也刚接触财务的人看。目标不是背会计教材，而是先把几件事想明白：

1. 企业每天发生业务。
2. 金蝶把业务记录成单据。
3. 财务把单据确认成应收、应付、成本、收入、费用和凭证。
4. 凭证汇总到总账。
5. 总账最后出报表。

可以先记住一句话：

```text
业务说发生了什么，单据留下证据，凭证把它翻译成财务语言，报表给管理层看结果。
```

## 一、财务到底在管什么

财务不是只负责“做凭证”。在金蝶项目里，财务通常管四件事。

| 财务关心的事 | 通俗解释 | 金蝶里常见对象 |
| --- | --- | --- |
| 钱从哪里来 | 客户欠我钱、银行收到钱、老板投入钱 | 应收单、收款单、银行流水、总账 |
| 钱花到哪里去 | 给供应商付款、员工报销、买固定资产 | 应付单、付款单、费用报销单、资产卡片 |
| 货值多少钱 | 仓库里的货、发出去的货、成本怎么算 | 采购入库、销售出库、存货核算、成本调整 |
| 最后赚没赚钱 | 收入、成本、费用、利润、现金流 | 凭证、科目余额表、利润表、现金流量表 |

所以财务模块不是孤立模块。采购、销售、库存、生产做错了，财务月底一定会看到差异。

## 二、先认识五个基础词

### 1. 资产

资产就是企业拥有或控制、未来能带来价值的东西。

| 例子 | 金蝶里怎么看 |
| --- | --- |
| 银行存款 | 出纳、资金、银行日记账、总账科目 |
| 客户欠款 | 应收款管理、应收账龄 |
| 仓库库存 | 库存管理、存货核算 |
| 机器设备 | 固定资产卡片 |

### 2. 负债

负债就是以后要还的钱或要承担的义务。

| 例子 | 金蝶里怎么看 |
| --- | --- |
| 欠供应商货款 | 应付款管理、应付账龄 |
| 已收客户预付款但还没发货 | 预收或合同负债 |
| 需要缴的税 | 应交税费、税务发票和申报勾稽 |

### 3. 所有者权益

所有者权益可以粗略理解为“老板投入的钱加上企业赚下来的钱”。新人阶段先知道它最终体现在资产负债表里，不必一开始陷进复杂权益抵消。

### 4. 收入

收入不是“收到钱”这么简单。很多企业先发货、后开票、再收款，也可能先收款、后发货。

| 场景 | 是否一定是收入 |
| --- | --- |
| 客户打钱了 | 不一定，可能只是预收 |
| 销售订单审核了 | 不一定，只是承诺交易 |
| 销售出库了 | 可能是收入确认依据之一 |
| 开票了 | 可能影响税务，不一定等于收入 |
| 已履约并满足收入政策 | 通常才是财务收入确认重点 |

### 5. 成本和费用

成本通常和商品或产品有关，费用通常和期间经营有关。

| 类型 | 通俗例子 | 常见金蝶来源 |
| --- | --- | --- |
| 销售成本 | 卖出去那批货本身的成本 | 销售出库、存货核算 |
| 采购成本 | 买入库存的价格和相关费用 | 采购入库、采购发票、费用分摊 |
| 制造成本 | 材料、人工、制造费用 | 生产领料、报工、费用分摊 |
| 管理费用 | 办公、差旅、折旧、工资等 | 费用报销、固定资产、总账 |

## 三、借贷记账先这样理解

新人最容易卡在“借”和“贷”。先不要把借贷理解成借钱和贷款，它更像财务系统里的左右两边。

```text
每一笔凭证至少有两边：
  借方记录一类变化
  贷方记录另一类变化
  借方金额合计必须等于贷方金额合计
```

常见感觉可以先这样记：

| 业务 | 通俗变化 | 常见分录方向 |
| --- | --- | --- |
| 客户欠我钱 | 应收增加，收入增加 | 借：应收账款；贷：主营业务收入 / 销项税 |
| 客户付款 | 银行增加，应收减少 | 借：银行存款；贷：应收账款 |
| 买材料入库但还没付款 | 存货增加，欠供应商钱增加 | 借：原材料 / 库存商品；贷：应付账款或暂估应付 |
| 给供应商付款 | 应付减少，银行减少 | 借：应付账款；贷：银行存款 |
| 发生费用报销 | 费用增加，银行或应付减少/增加 | 借：费用；贷：银行存款 / 其他应付款 |

这一阶段不要追求背完所有分录。更重要的是能回答：

- 这件事让资产、负债、收入、成本、费用哪个变化了？
- 金蝶里是哪张单据触发的？
- 凭证生成后能不能追回原始单据？

## 四、金蝶里财务常见对象

| 对象 | 通俗解释 | 如果配置错会怎样 |
| --- | --- | --- |
| 财务组织 | 哪个公司负责核算 | 凭证、账簿、报表组织错 |
| 账簿 | 一本账，记录会计政策、期间、币别 | 月结、报表和凭证口径混乱 |
| 会计期间 | 几月的账 | 跨期单据、跨期凭证、月结卡住 |
| 科目 | 财务分类，例如银行、应收、收入、成本 | 报表不平、余额看不懂 |
| 核算维度 | 科目的明细标签，例如客户、供应商、部门、项目 | 对账、经营分析、费用分摊困难 |
| 凭证模板 | 业务单据怎么自动变凭证的规则 | 凭证生成失败或科目维度错误 |
| 应收单 | 客户欠款确认 | 客户余额、收入、开票回款受影响 |
| 应付单 | 欠供应商款确认 | 供应商余额、付款计划受影响 |
| 收付款单 | 钱进出银行 | 银行日记账、核销受影响 |
| 存货核算 | 库存金额和出库成本计算 | 库存金额、成本、利润受影响 |
| 报表 | 按口径汇总结果 | 管理层看到的结果可能失真 |

## 五、采购业务怎么进财务

采购是最适合新人理解“业务到财务”的链路。

```text
采购订单
  -> 采购入库
  -> 暂估应付 / 存货增加
  -> 采购发票 / 采购结算
  -> 应付确认
  -> 付款
  -> 应付核销
  -> 总账凭证和报表
```

### 一个简单例子

企业买 100 个零件，每个 10 元，供应商还没开票。

| 阶段 | 业务说法 | 财务含义 |
| --- | --- | --- |
| 采购订单 | 我准备买 | 还不是财务结果 |
| 采购入库 | 货到了仓库 | 库存增加，可能形成暂估 |
| 采购发票 | 供应商开票 | 正式确认应付和税额 |
| 付款单 | 付钱了 | 银行减少，应付减少 |
| 核销 | 付款和应付配上 | 供应商欠款结清 |

常见问题：

| 现象 | 优先看 |
| --- | --- |
| 入库了但应付没有 | 是否做采购发票或暂估规则 |
| 付款了但供应商余额还在 | 是否核销 |
| 存货金额和发票金额不一致 | 采购结算、价差、费用分摊 |
| 总账和应付对不上 | 凭证模板、凭证状态、核算维度 |

## 六、销售业务怎么进财务

销售链路要同时看收入、应收、开票、收款、成本。

```text
销售订单
  -> 发货通知 / 销售出库
  -> 应收确认 / 收入确认
  -> 销售发票
  -> 收款
  -> 应收核销
  -> 成本结转
  -> 总账和报表
```

### 一个简单例子

企业卖出 1 台设备，售价 5000 元，成本 3000 元，客户下月付款。

| 阶段 | 业务说法 | 财务含义 |
| --- | --- | --- |
| 销售订单 | 客户下单 | 通常不是收入 |
| 销售出库 | 货发走 | 库存减少，可能触发成本 |
| 应收单 | 客户欠款确认 | 应收增加，收入可能确认 |
| 销售发票 | 税务开票 | 销项税和申报证据 |
| 收款单 | 客户付款 | 银行增加，应收减少 |

常见问题：

| 现象 | 优先看 |
| --- | --- |
| 销售报表有收入，利润表没有 | 销售报表和财务收入口径不同 |
| 发货了但没成本 | 存货核算、出库成本、成本计算 |
| 收款了但客户余额没减少 | 收款单是否核销 |
| 开票和收入期间不同 | 收入确认、未开票收入、跨期说明 |

## 七、为什么财务总说“先把单据做完整”

财务月底不是从零开始算账，而是把业务单据汇总成财务结果。业务单据如果缺状态、缺组织、缺价格、缺税率、缺客户供应商、缺部门项目，后面就会变成财务差异。

| 单据问题 | 月底后果 |
| --- | --- |
| 采购入库未审核 | 存货和暂估不完整 |
| 销售出库未审核 | 库存、成本、收入口径不完整 |
| 收付款未核销 | 往来余额不准确 |
| 费用没有部门或项目 | 费用分析和预算执行失真 |
| 物料没有存货属性或计价资料 | 存货核算失败 |
| 凭证模板缺科目或维度 | 凭证生成失败 |

## 八、月结通俗版

月结就是把一个月的业务关起来、算清楚、出报表。

```text
业务单据检查
  -> 应收应付核销
  -> 库存和存货核算
  -> 固定资产折旧
  -> 费用和税金检查
  -> 生成凭证
  -> 总账过账
  -> 结转损益
  -> 出报表
  -> 差异说明和归档
```

新人可以先记住：月结失败时，不一定是财务模块错。可能是业务单据没审核、库存成本没算、接口没回写、凭证模板没配、权限看不到数据。

## 九、看报表前先问口径

同一个“收入”可能有不同口径。

| 报表 | 可能的收入口径 |
| --- | --- |
| 销售订单报表 | 按订单金额 |
| 销售出库报表 | 按已发货金额 |
| 开票报表 | 按发票金额 |
| 应收报表 | 按应收确认金额 |
| 利润表 | 按会计收入确认金额 |
| 经营分析月报 | 可能按管理口径调整 |

所以不要一看到两个数字不一样就说系统错。先问：

1. 按哪个组织？
2. 按哪个期间？
3. 按单据日期、审核日期、业务日期还是凭证日期？
4. 是否只看已审核？
5. 是否含税？
6. 是否包含退货、红冲、折让？
7. 是否包含内部交易？

## 十、新人学习路线

| 第几步 | 学什么 | 练什么 |
| --- | --- | --- |
| 1 | 财务对象 | 组织、账簿、科目、维度、期间 |
| 2 | 采购到付款 | 入库、应付、付款、核销、凭证 |
| 3 | 销售到收款 | 出库、应收、开票、收款、成本 |
| 4 | 库存到成本 | 入库成本、出库成本、成本调整 |
| 5 | 月结 | 未审核单据、凭证生成、过账、报表 |
| 6 | 对账 | 总账和应收、应付、库存、资金对齐 |

建议每学一个概念，都找一张真实或测试单据追到底：

```text
原始业务
  -> 金蝶单据
  -> 下游单据
  -> 凭证
  -> 科目余额
  -> 报表
```

## 十一、常见误区

| 误区 | 正确理解 |
| --- | --- |
| 订单就是收入 | 订单通常只是业务承诺 |
| 收到钱就是收入 | 可能是预收，也可能还没履约 |
| 开票就是收入 | 发票影响税务，收入要看会计政策 |
| 库存数量对就行 | 数量对不代表成本金额对 |
| 凭证错就直接改凭证 | 先判断源单、模板、核算规则是否错 |
| 报表不一致就是系统错 | 先核对口径、期间、状态、权限 |
| 财务只管月底 | 财务结果从日常业务单据开始 |
