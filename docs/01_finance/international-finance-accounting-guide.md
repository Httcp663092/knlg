这篇用于补“国外财务”在金蝶项目里的基本框架。它不是某一个国家的税务申报手册，而是把海外法人、多币别、多会计准则、VAT/GST/Sales Tax、预提税、转移定价、跨境往来和集团合并这些高频问题整理成系统实施和日常财务能用的清单。

一句话理解：

```text
国内财务项目多半先问“凭证、月结、报表能不能跑通”；
国际化财务项目还要问“哪个国家、哪个准则、哪个币别、哪个税制、哪个集团口径”。
```

## 二、国外财务最常见的七个问题

| 问题 | 为什么麻烦 | 金蝶项目要落到哪里 |
| --- | --- | --- |
| 多币别 | 交易币别、本位币、集团报表币不同 | 币别、汇率类型、期末调汇、报表折算 |
| 多准则 | 中国准则、IFRS、US GAAP 或当地准则不同 | 多账簿、副账簿、调整分录、报表包 |
| 当地税制 | VAT、GST、Sales Tax、预提税、地方税各不相同 | 税码、税率、税务发票、申报台账 |
| 跨境收付款 | 银行账号、SWIFT/IBAN、手续费、预提税、外汇管制 | 收付款单、银行对账、付款审批 |
| 关联交易 | 关联采购、销售、服务费、特许权使用费、贷款 | 内部客户供应商、转移定价、合并抵消 |
| 海外合并 | 海外子公司报表要折算并并入集团 | 合并范围、汇率、报表项目映射 |
| 审计证据 | 海外发票、合同、报关、回单、税务申报语言和格式不同 | 电子档案、附件归档、月结证据包 |

## 三、系统设计主线

国际化财务先不要急着建科目，先画清这条线：

```text
国家 / 地区
  -> 法人主体
  -> 会计准则和当地税制
  -> 账簿和本位币
  -> 交易币别和汇率
  -> 税码和发票规则
  -> 跨境收付款和预提税
  -> 关联交易和转移定价
  -> 当地报表和集团合并报表
```

建议按“当地法定口径”和“集团管理口径”分别设计：

| 口径 | 目的 | 典型输出 |
| --- | --- | --- |
| 当地法定口径 | 满足当地会计、税务、审计和申报 | 当地总账、当地报表、税务申报、审计底稿 |
| 集团报告口径 | 满足母公司管理和合并 | 集团科目映射、报表包、调整分录、合并抵消 |
| 管理分析口径 | 看业务经营结果 | 区域利润、产品线毛利、客户贡献、预算执行 |

## 四、IFRS、US GAAP、当地准则和中国准则

国际化项目里不要简单说“国外财务按 IFRS”。实际情况可能是：

- 当地法定报表按当地 GAAP。
- 集团合并包按 IFRS。
- 美国上市或美国主体按 US GAAP。
- 中国母公司本部按中国企业会计准则。
- 管理报表按集团内部口径。

### 4.1 准则差异要落成调整清单

| 差异类型 | 常见影响 | 系统处理 |
| --- | --- | --- |
| 收入确认 | 履约义务、交付条件、退货、折扣 | 收入确认规则、合同履约台账、调整凭证 |
| 租赁 | 使用权资产、租赁负债、费用分类 | 租赁台账、副账簿或调整分录 |
| 金融工具 | 公允价值、减值、汇兑、套期 | 金融资产分类、估值调整 |
| 存货 | 成本方法、跌价准备、制造费用分摊 | 存货核算规则、减值调整 |
| 固定资产 | 折旧年限、残值、减值、重估 | 资产政策和副账簿 |
| 所得税 | 暂时性差异、递延所得税 | 税会差异台账 |
| 列报 | 报表项目、现金流分类、OCI | 报表项目映射 |

系统里不要把所有差异都塞进同一本账。更稳的做法是：

```text
当地法定账簿
  + 准则调整分录
  + 报表项目映射
  = 集团报告包
```

### 4.2 多账簿设计

| 方案 | 适合场景 | 风险 |
| --- | --- | --- |
| 单账簿 + 调整分录 | 差异少，集团只要报表包 | 调整分录容易散落在 Excel |
| 主账簿 + 副账簿 | 差异多，需要双口径凭证和报表 | 配置和月结复杂 |
| 当地系统 + 集团报表包 | 海外已有系统，金蝶做集团汇总 | 数据接口和口径对齐难 |
| 金蝶统一核算 | 海外主体也上金蝶 | 当地税务、语言、发票和银行适配要评估 |

## 五、多币别和汇率

IFRS 的 IAS 21 重点处理外币交易、境外经营财务报表折算，以及功能货币和列报货币问题。金蝶项目里可以拆成四个币别概念：

| 概念 | 说明 | 常见例子 |
| --- | --- | --- |
| 交易币别 | 单据发生的币别 | USD 销售订单、EUR 采购发票 |
| 本位币 / 功能货币 | 该主体主要经营环境的货币 | 美国子公司 USD，欧元区子公司 EUR |
| 记账币别 | 账簿核算币别 | 当地账簿 USD，集团账簿 CNY |
| 报表币别 | 最终列报货币 | 集团合并报表 CNY |

### 5.1 汇率类型

| 汇率类型 | 用途 |
| --- | --- |
| 业务发生日汇率 | 记录交易初始金额 |
| 月平均汇率 | 损益类报表折算或管理分析 |
| 期末汇率 | 期末外币余额调汇、资产负债表折算 |
| 集团指定汇率 | 集团统一上报和合并 |
| 银行实际汇率 | 实际收付款和手续费 |

### 5.2 外币月结检查

| 检查项 | 说明 |
| --- | --- |
| 汇率是否维护完整 | 交易日、月末、集团上报汇率 |
| 外币科目是否启用外币核算 | 银行、应收、应付、借款 |
| 原币和本位币是否同时保留 | 不能只留本位币 |
| 期末调汇范围是否完整 | 外币银行、应收、应付、借款 |
| 汇兑损益是否入正确科目 | 财务费用或集团指定科目 |
| 报表折算差额是否单独列示 | 境外经营报表折算差异 |

### 5.3 常见错误

| 错误 | 后果 | 处理 |
| --- | --- | --- |
| 外币期初只导本位币 | 后续无法正确调汇 | 补原币、汇率和本位币 |
| 业务汇率和银行汇率混用 | 应收应付和银行对账不平 | 区分交易汇率和结算汇率 |
| 月末汇率未维护 | 调汇失败或汇兑损益异常 | 建月末汇率复核清单 |
| 集团和当地汇率版本不同 | 合并报表差异 | 统一集团上报汇率版本 |

## 六、VAT、GST、Sales Tax 和发票

不同国家税制差异很大。项目里先按税制类型理解：

| 税制 | 常见地区 | 项目关注 |
| --- | --- | --- |
| VAT | 欧盟、英国等 | 销项税、进项税、反向计税、发票要求 |
| GST | 新加坡、澳大利亚、加拿大部分地区等 | 进销项抵扣、申报期间、跨境服务 |
| Sales Tax | 美国多数州 | 销售地、州和地方税率、免税证书、经济关联 |
| Withholding Tax | 跨境服务、利息、特许权使用费、股息 | 付款时扣缴、税收协定、完税凭证 |
| Customs Duty | 进口货物 | 报关单、关税、进口增值税、成本入账 |

### 6.1 VAT/GST 不是中国增值税的简单复制

欧盟官方资料把 VAT 描述为对在欧盟境内及进入欧盟的商品和服务征收的消费税。OECD 的 VAT/GST 指南强调跨境贸易特别是服务和无形资产的 VAT/GST 一致处理。项目里要注意：

- B2B 和 B2C 规则可能不同。
- 服务、软件、订阅、无形资产的纳税地点可能不同。
- 出口可能零税率，但必须有出口和运输证据。
- 进口可能有进口 VAT、关税和清关费用。
- 跨境服务可能有 reverse charge。
- 发票字段、语言、税号、税率、税额和保存期限要符合当地规则。

### 6.2 税码设计

| 税码 | 场景 |
| --- | --- |
| Domestic Standard VAT/GST | 当地标准税率销售或采购 |
| Domestic Reduced VAT/GST | 当地低税率商品或服务 |
| Zero-rated Export | 出口零税率 |
| Exempt | 免税项目 |
| Reverse Charge | B2B 跨境服务或特定交易反向计税 |
| Import VAT | 进口环节 VAT/GST |
| Sales Tax | 美国州/地方销售税 |
| Withholding Tax | 跨境付款预提税 |

税码不能只为了“算出税额”。它还要服务：

- 发票开具。
- 税务申报。
- 总账科目映射。
- 报表和审计抽样。
- 跨境交易证据链。

## 七、预提税和跨境付款

跨境付款常见对象：

- 服务费。
- 特许权使用费。
- 利息。
- 股息。
- 咨询费。
- 软件订阅和云服务。
- 关联公司管理费。

IRS 对 NRA withholding 的说明中提到，外国人取得美国来源收入通常可能涉及 30% 的预提税，税收协定或法规可能适用较低税率或豁免。其他国家也常有类似预提税规则。

项目里要落地为付款前检查：

| 检查项 | 说明 |
| --- | --- |
| 收款方国家和税务居民身份 | 判断是否适用协定 |
| 服务发生地和收入来源地 | 判断是否需要预提 |
| 合同条款 | 税负由谁承担，是否 gross-up |
| 付款类型 | 服务费、利息、股息、特许权使用费 |
| 预提税率和币别 | 按当地税法和协定确认 |
| 完税凭证 | 后续审计和对方抵免需要 |
| 凭证分录 | 费用、应付、预提税负债、银行付款 |

不要让出纳只按合同金额付款。跨境付款要把“合同金额、预提税、银行手续费、实际到账金额、完税凭证”放在同一张付款证据包里。

## 八、转移定价和关联交易

OECD 转移定价指南围绕独立交易原则，为关联企业跨境交易定价提供国际共识。OECD 转移定价专题页还提示，2024 年 Amount B 相关指引已作为基准营销和分销活动的简化方法纳入指南体系。金蝶项目里，转移定价不是税务部门的孤立文件，而是要落到基础资料、价格、单据、发票和合并抵消。

### 8.1 常见关联交易

| 交易 | 系统对象 |
| --- | --- |
| 集团内部销售 | 内部客户、内部供应商、销售订单、采购订单 |
| 集团内部服务费 | 服务合同、费用分摊、应收应付 |
| 特许权使用费 | 合同、发票、预提税 |
| 集团资金拆借 | 内部贷款、利息、汇兑 |
| 成本分摊 | 分摊规则、成本中心、事业部 |
| 代采代销 | 采购、销售、库存所有权、结算 |

### 8.2 转移定价要留痕

| 要素 | 系统沉淀 |
| --- | --- |
| 定价方法 | 成本加成、可比非受控价格、再销售价格等 |
| 关联方关系 | 客户/供应商是否集团内关联方 |
| 合同依据 | 合同、协议、服务清单 |
| 价格版本 | 生效日期、审批人、币别 |
| 税务证据 | 转移定价文档、发票、完税凭证 |
| 合并抵消 | 内部收入、内部成本、内部往来 |

如果系统里只看到“客户 A、供应商 B”，但看不出它们是集团内部关联方，后续合并抵消、转移定价审计和管理利润都会很痛苦。

## 九、海外应收应付和银行

### 9.1 海外客户和供应商主数据

| 字段 | 用途 |
| --- | --- |
| 国家 / 地区 | 税制、语言、币别、付款规则 |
| 税号 / VAT ID / GST No. | 发票和税务申报 |
| 注册地址 | 发票和合规 |
| 交易币别 | 默认币别和汇率 |
| 付款条款 | 账期、现金折扣、逾期 |
| 银行账号 | IBAN、SWIFT、ABA、Sort Code 等 |
| 关联方标识 | 转移定价和合并抵消 |
| 免税或税务证书 | Sales Tax exemption、WHT treaty form 等 |

### 9.2 海外应收

关注：

- 原币金额、本位币金额、汇率日期。
- VAT/GST/Sales Tax 是否正确。
- 出口证据、报关单、运输单据。
- 客户信用额度是否按原币还是集团币。
- 逾期账龄按原币和本位币分别看。
- 期末调汇和坏账准备。

### 9.3 海外应付

关注：

- 供应商发票格式和税号。
- 付款币别、银行手续费、汇率差异。
- 预提税和完税凭证。
- 进口关税、进口 VAT、清关费用是否入成本。
- 费用归属主体和关联交易标识。

## 十、国际化月结清单

### 10.1 当地月结

- 当地销售、采购、费用、资产单据已审核。
- 当地银行对账完成。
- VAT/GST/Sales Tax 台账和申报数据准备完成。
- 预提税台账和完税凭证准备完成。
- 外币应收、应付、银行、借款完成调汇。
- 当地法定报表生成并复核。

### 10.2 集团上报

- 集团报表币汇率版本已确认。
- 当地科目映射到集团科目。
- 准则调整分录完成。
- 内部往来和内部交易对账完成。
- 海外子公司报表折算完成。
- 合并抵消数据包完成。
- 报表差异说明、重大事项、税务风险事项已上传。

### 10.3 证据包

| 证据 | 说明 |
| --- | --- |
| 汇率表 | 业务汇率、期末汇率、集团折算汇率 |
| 发票清单 | VAT/GST/Sales Tax 发票和申报台账 |
| 银行对账 | 当地银行流水、回单、未达账项 |
| 外币调汇 | 调汇凭证和余额表 |
| 预提税 | 付款清单、税率依据、完税凭证 |
| 关联交易 | 内部往来、内部交易、转移定价依据 |
| 报表包 | 当地报表、集团调整、合并包 |

## 十一、金蝶配置检查表

| 配置 | 检查点 |
| --- | --- |
| 组织 | 海外法人、核算组织、业务组织、库存组织 |
| 账簿 | 当地账簿、集团账簿、副账簿、启用期间 |
| 科目表 | 当地科目、集团科目映射 |
| 币别 | 本位币、交易币别、报表币别 |
| 汇率 | 汇率类型、维护频率、审批和锁定 |
| 税码 | VAT/GST/Sales Tax/WHT/Import VAT |
| 主数据 | 海外客户、供应商、税号、银行信息、关联方 |
| 单据 | 多币别金额、税额、汇率、税码、付款条款 |
| 凭证模板 | 税金、汇兑损益、预提税、关税、手续费 |
| 报表 | 当地报表、集团报表包、管理报表 |
| 权限 | 海外主体数据权限、敏感银行信息权限 |
| 附件 | 海外发票、合同、报关、银行回单、税务凭证 |

## 十二、典型案例

### 12.1 USD 应收期末调汇

现象：美国客户应收 USD 100,000，发生时汇率 7.10，月末汇率 7.20。账龄表按原币看没有变化，但本位币金额增加。

处理：

1. 确认应收科目启用外币核算。
2. 确认期末汇率已维护。
3. 运行期末调汇。
4. 生成汇兑损益凭证。
5. 同时保留原币账龄和本位币账龄。

### 12.2 欧盟 B2B 服务 reverse charge

现象：海外子公司采购欧盟跨境服务，供应商发票没有收 VAT，但财务不知道是否要申报。

处理：

1. 确认交易双方 VAT ID。
2. 确认服务类型和纳税地点。
3. 使用 reverse charge 税码。
4. 在税务台账中同时体现应计销项和可抵扣进项。
5. 保留合同、发票和税务判断依据。

### 12.3 美国销售税和中国增值税混淆

现象：美国销售订单按中国增值税逻辑配置税码，导致发票、客户报价和税务申报都不对。

处理：

1. 区分美国 Sales Tax 和 VAT/GST。
2. 按州、地方、商品、客户免税证书判断税额。
3. 系统里不要把 Sales Tax 当作可抵扣进项税。
4. 报价、订单、发票和税务申报使用同一税码逻辑。

### 12.4 关联服务费预提税

现象：海外子公司向母公司支付管理服务费，合同金额 100,000，但当地要求预提税，实际付款和应付核销对不上。

处理：

1. 确认付款类型和税收协定。
2. 计算预提税和实际支付金额。
3. 凭证拆分费用、应付、预提税负债和银行付款。
4. 取得完税凭证。
5. 将该交易纳入关联交易和转移定价台账。

## 十三、常见问题

| 问题 | 常见原因 | 处理 |
| --- | --- | --- |
| 海外报表和集团报表对不上 | 科目映射、汇率、准则调整不同 | 建集团报表包和调整分录清单 |
| 外币账龄和总账不一致 | 原币、本位币、期末调汇口径不同 | 分原币和本位币分别核对 |
| VAT/GST 税额不对 | 税码、纳税地点、发票类型错误 | 重新梳理税码和发票规则 |
| 跨境付款金额对不上 | 预提税、银行手续费、汇率差异 | 做付款证据包和预提税台账 |
| 合并抵消不完整 | 关联方未标识，内部交易没对账 | 维护关联方和内部交易匹配规则 |
| 当地审计要资料找不到 | 发票、合同、回单、报关资料未归档 | 建海外附件归档清单 |
