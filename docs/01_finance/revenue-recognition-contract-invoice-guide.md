销售业务里最容易混淆的三件事是：货发了、票开了、钱收了。它们都很重要，但不一定等于收入已经可以确认。

收入确认要回答的是：企业是否已经完成合同约定的履约义务，是否有权确认收入。金蝶系统落地时，收入确认可能来自销售出库、签收、应收单、销售发票、收入确认单或项目节点。口径不同，月结、报表、税务和客户对账都会不同。

## 一、先分清四条线

| 线索 | 代表单据 | 管理含义 |
| --- | --- | --- |
| 物流线 | 发货通知、销售出库、签收、验收 | 货有没有交付 |
| 债权线 | 应收单、收款条件、核销 | 客户欠不欠钱 |
| 税票线 | 销售发票、红字发票 | 税务开票和销项税 |
| 资金线 | 收款单、预收、退款 | 钱有没有回来 |

收入确认不应该只看其中一条线。比如：

- 货已出库但客户未签收，可能不能确认收入。
- 发票已开但货未交付，可能只是税票先行。
- 钱已预收但服务未完成，通常不等于收入。
- 已完成履约但未开票，可能需要确认收入和未开票应收。

## 二、常见收入确认口径

| 口径 | 适用场景 | 风险 |
| --- | --- | --- |
| 按销售出库确认 | 标准商品销售，发货即交付 | 客户签收或验收要求被忽略 |
| 按客户签收确认 | 物流签收后风险转移 | 签收数据回传不及时 |
| 按销售发票确认 | 开票和收入强绑定 | 容易把税票当成收入唯一证据 |
| 按应收单确认 | 财务确认债权时确认收入 | 应收来源和履约证据要清楚 |
| 按项目节点确认 | 工程、服务、实施项目 | 节点验收和收入比例要有证据 |
| 按期间服务确认 | 订阅、租赁、维保 | 需要递延收入和按期摊销 |

项目调研时必须问清：企业现在是按出库、签收、验收、开票、应收还是合同节点确认收入。不要只问“销售流程怎么走”，要问“财务什么时候认收入”。

## 三、系统闭环

```text
销售合同 / 销售订单
  -> 发货通知
  -> 销售出库
  -> 签收 / 验收 / 履约节点
  -> 应收单或收入确认
  -> 销售发票
  -> 收款单
  -> 核销
  -> 收入、税额、成本凭证
  -> 报表和对账
```

完整闭环要能从一笔收入反查：

- 合同或订单依据。
- 发货和签收证据。
- 应收确认单据。
- 开票记录。
- 收款和核销记录。
- 销售成本结转。
- 凭证和报表影响。

## 四、跨期场景

| 场景 | 例子 | 关注点 |
| --- | --- | --- |
| 先发货后开票 | 6 月出库，7 月开票 | 6 月是否确认收入和销项税 |
| 先开票后发货 | 6 月开票，7 月出库 | 是否形成预收或合同负债 |
| 先收款后履约 | 客户预付 30% | 预收款不一定是收入 |
| 已履约未收款 | 客户账期 60 天 | 应收和账龄管理 |
| 已履约未开票 | 服务完成但月底未开票 | 未开票收入或应收口径 |
| 退货跨期 | 上月销售，本月退货 | 收入、税额、成本跨期冲回 |
| 分期履约 | 项目按阶段验收 | 按履约进度确认收入 |

跨期不是错误，但必须有固定口径。最怕每个月临时处理：这个月按开票，下个月按出库，再下个月按收款，报表就会失真。

## 五、预收、合同负债和应收

预收款和收入要分开。

```text
客户预付款
  -> 收款单
  -> 预收账款 / 合同负债
  -> 后续发货或履约
  -> 确认收入和应收
  -> 预收冲抵应收
```

常见分录方向：

收到预收：

```text
借：银行存款
  贷：预收账款 / 合同负债
```

履约并确认收入：

```text
借：应收账款 / 预收账款 / 合同负债
  贷：主营业务收入
  贷：应交税费-销项税额
```

如果预收长期不冲收入，要查是否确实未履约，还是业务单据没有及时下推。

## 六、收入和成本匹配

收入确认后，销售成本也要匹配。只确认收入不结转成本，会让毛利虚高；只结转成本不确认收入，会让利润虚低。

```text
销售出库
  -> 出库成本核算
  -> 主营业务成本凭证

收入确认
  -> 应收或收入凭证
```

检查点：

- 收入确认期间和成本结转期间是否一致。
- 销售退货是否同时冲收入和成本。
- 发票跨期是否导致税务和收入期间不同。
- 销售成本是否存在 0 成本或异常成本。
- 管理报表毛利口径是否和财务口径一致。

## 七、对账关系

| 对账对象 | 应该一致 |
| --- | --- |
| 销售出库 | 发货数量和履约证据 |
| 应收单 | 收入确认和客户债权 |
| 销售发票 | 税票和销项税 |
| 收款单 | 回款和核销 |
| 存货核算 | 销售成本 |
| 总账 | 收入、应收、销项税、成本 |
| 报表 | 利润表收入成本、资产负债表应收和合同负债 |

收入确认相关报表至少要能拆出：

- 已出库未开票。
- 已开票未出库。
- 已收款未履约。
- 已履约未收款。
- 已履约未开票。
- 本月跨期调整。

## 八、常见案例

### 案例 1：发票已开，但财务不认可收入

排查：

1. 货是否发出。
2. 客户是否签收或验收。
3. 合同是否约定验收后确认收入。
4. 发票是否只是预开票。
5. 是否已形成应收或合同负债。

处理：

- 如果未履约，收入不能只因开票而确认。
- 将开票金额和合同负债、预收或税务处理区分。
- 留存合同、发票和履约状态说明。

### 案例 2：货已发出，但应收和收入没有形成

排查：

1. 销售出库是否审核。
2. 出库是否下推应收或收入确认。
3. 是否缺少签收或验收节点。
4. 客户、结算客户、税率是否完整。
5. 凭证模板是否启用。

处理：

- 补齐履约证据。
- 补生成应收或收入确认单据。
- 补生成凭证并对总账。

### 案例 3：预收款长期挂账

排查：

1. 是否已经发货或完成服务。
2. 是否有销售订单或合同关联。
3. 预收是否核销到应收。
4. 是否存在客户取消订单、退款或长期未履约。

处理：

- 已履约的，确认收入并冲预收。
- 未履约的，保留合同负债或预收说明。
- 取消订单的，走退款或转其他处理。

### 案例 4：利润表收入和销售报表不一致

排查：

1. 销售报表按订单、出库、开票还是应收统计。
2. 财务收入按哪个单据确认。
3. 是否有未开票收入、预开票、退货红冲。
4. 是否有手工凭证调整收入。
5. 查询组织、期间、币别是否一致。

处理：

- 明确销售管理报表和财务报表不是天然同口径。
- 建立“销售出库到财务收入差异桥”。
- 大额差异按客户、订单、期间、发票状态列示。

## 九、月末检查清单

- [ ] 本月销售出库全部审核。
- [ ] 需要签收或验收的业务已有证据。
- [ ] 应收单或收入确认单据已生成。
- [ ] 销售发票和应收、收入口径已核对。
- [ ] 预收款和合同负债有明细清单。
- [ ] 已履约未开票业务有清单。
- [ ] 已开票未履约业务有清单。
- [ ] 收款单已核销，应收账龄正确。
- [ ] 销售成本已结转，收入成本期间匹配。
- [ ] 跨期收入、退货、红冲有说明。
- [ ] 总账收入、应收、销项税和报表一致。

## 十、学习练习

1. 做一笔先收款后发货，观察预收到收入的转换。
2. 做一笔先发货后开票，判断收入和税票跨期如何处理。
3. 做一笔先开票后发货，区分发票、预收、合同负债和收入。
4. 做一笔销售退货跨月，检查收入、应收、税额和成本冲回。
5. 输出销售出库、应收、发票、收款、凭证的差异桥表。

学会的标准：

- 能解释为什么开票不一定等于收入确认。
- 能区分预收、合同负债、应收和收入。
- 能从一笔收入反查合同、出库、签收、发票、收款和成本。
- 能解释销售报表和利润表收入为什么可能不一致。
