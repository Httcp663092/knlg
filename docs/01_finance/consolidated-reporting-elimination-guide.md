多组织、多账簿页面讲的是集团核算的基础设计。这篇继续补“合并报表怎么真正落地”：合并范围、个别报表上报、报表模板、内部往来对账、内部交易抵消、权益抵消、外币折算、调整分录、工作底稿和月末关账证据。

如果集团包含海外主体、IFRS/US GAAP 或当地准则、VAT/GST/Sales Tax、预提税和跨境付款，先读 [国外财务与国际化核算专题](international-finance-accounting-guide.md) 和 [海外子公司建账与月结实操包](overseas-subsidiary-close-implementation-pack.md)，再进入本页做合并抵消和报表包。

合并报表不是把几个公司的资产负债表和利润表简单相加。集团内部买卖、内部借款、内部往来、投资与权益、内部利润都要按合并口径抵消。系统能自动生成部分抵消，但前提是基础资料、组织关系、内部客户供应商、科目映射、报表项目、往来勾稽和抵消模板设计正确。

## 一、合并主线

```text
集团组织和合并范围
  -> 会计政策、币别、账簿和期间统一
  -> 报表项目和模板设计
  -> 子公司编制个别报表
  -> 个别报表检查、审核和上报
  -> 集团接收个别报表
  -> 内部往来核对
  -> 调整分录和抵消分录
  -> 工作底稿
  -> 合并报表
  -> 勾稽检查、分析和归档
```

系统实施时不要等到月末才考虑合并。采购、销售、组织间结算、内部往来、固定资产调拨、资金拆借、成本分摊等业务，在蓝图阶段就要预留合并口径。

## 二、合并前要先定的口径

| 口径 | 必须明确的问题 |
| --- | --- |
| 合并范围 | 哪些公司纳入合并，持股比例是多少，何时进入或退出合并 |
| 合并层级 | 一层合并、分集团合并、区域合并还是多管理口径并行 |
| 会计政策 | 折旧、收入、存货、坏账、租赁等政策是否一致 |
| 币别和汇率 | 本位币、外币报表折算方法、汇率来源 |
| 报表项目 | 科目如何映射到资产负债表、利润表、现金流量表和附表 |
| 内部往来 | 哪些科目和客商属于集团内部，如何对账和勾稽 |
| 内部交易 | 内部销售、采购、服务、资金、资产转让如何抵消 |
| 权益抵消 | 长投、实收资本、资本公积、留存收益、少数股东权益如何处理 |

如果这些口径不先定，系统里看似能出报表，但每月都会靠手工 Excel 修补。

## 三、基础资料和系统对象

| 对象 | 作用 |
| --- | --- |
| 组织信息 | 定义法人、核算组织和合并层级 |
| 会计核算体系 | 决定账簿、科目、会计政策和期间 |
| 报表项目 | 把科目数据归集到报表行项目 |
| 项目数据类型 | 区分本期数、期末数、累计数、调整数、抵消数 |
| 金额单位 | 元、千元、万元等口径统一 |
| 合并方案 | 定义合并范围、层级、报表模板和处理规则 |
| 股权关系 | 支持权益抵消和少数股东权益计算 |
| 调整分录模板 | 支持会计政策差异、集团统一调整 |
| 抵消分录模板 | 支持往来、交易、权益、投资收益等抵消 |
| 项目勾稽关系 | 检查资产负债表、利润表、现金流量表和附表逻辑 |

基础资料不要只由系统管理员维护。财务经理、合并报表负责人、实施顾问和顾问团队要一起确认，否则会出现“系统对象建好了，但财务不认这个口径”的情况。

## 四、个别报表上报

子公司上报个别报表前要完成：

- 本公司总账已结账或至少完成凭证过账。
- 应收、应付、存货、固定资产和总账已对平。
- 内部往来明细已按内部客商或内部组织标识清楚。
- 报表模板版本正确。
- 报表项目取数公式正确。
- 附表和主表勾稽通过。
- 重大调整和异常已备注。

上报检查表：

| 检查 | 异常信号 |
| --- | --- |
| 期间 | 子公司上报期间和集团合并期间不一致 |
| 币别 | 外币子公司未折算或汇率版本不一致 |
| 单位 | 有的报元，有的报万元 |
| 模板 | 子公司使用旧版模板 |
| 勾稽 | 主表和附表不平 |
| 内部往来 | 对方公司不认可余额 |

## 五、内部往来对账

内部往来是合并报表最常见卡点。它通常来自：

- 内部采购销售。
- 内部资金拆借。
- 代收代付。
- 费用分摊。
- 资产转让。
- 内部服务结算。
- 组织间调拨或结算。

对账公式：

```text
A 公司应收 B 公司
  应等于
B 公司应付 A 公司
```

但实际项目中经常不等，因为双方期间、币别、税额、凭证日期、客商映射和单据状态不同。

内部往来排查顺序：

1. 固定双方公司、期间、币别和科目。
2. 导出 A 公司内部应收明细。
3. 导出 B 公司内部应付明细。
4. 按内部客户、内部供应商、合同号、发票号、单据号匹配。
5. 区分时间差、未入账、重复入账、币别差、税额差和手工凭证。
6. 形成往来调节表，确认是否本期调整或下期处理。

## 六、内部交易抵消

内部交易抵消不是简单抵消应收应付，还要抵消收入、成本、未实现内部利润和税费影响。

### 1. 内部销售采购

```text
A 公司对 B 公司销售
  A 确认内部收入和应收
  B 确认采购、存货或成本和应付
集团合并时：
  抵消内部收入
  抵消内部成本或采购
  抵消内部应收应付
  处理期末存货中的未实现利润
```

检查：

- 内部客户和内部供应商是否成对。
- A 的收入期间是否等于 B 的采购或成本期间。
- B 期末是否仍有未售出的内部采购存货。
- 内部利润是否需要在存货里抵消。

### 2. 内部资金拆借

抵消对象：

- 其他应收和其他应付。
- 利息收入和利息费用。
- 应收利息和应付利息。
- 现金流量内部往来。

常见差异：

- 一方计提利息，另一方未计提。
- 一方按含税或不含税口径，另一方按净额。
- 一方凭证已过账，另一方仍在审批。

### 3. 内部资产转让

抵消对象：

- 内部处置收益。
- 资产原值和累计折旧中的未实现利润。
- 后续折旧差异。

这类业务要提前设计，不能等合并报表时才发现固定资产卡片已经按内部转让价入账。

## 七、权益抵消

权益抵消通常围绕：

- 长期股权投资。
- 实收资本或股本。
- 资本公积。
- 盈余公积。
- 未分配利润。
- 投资收益。
- 少数股东权益和少数股东损益。

实施时要准备：

| 资料 | 用途 |
| --- | --- |
| 股权结构表 | 确认持股比例和合并比例 |
| 投资成本 | 确认长投初始金额 |
| 子公司净资产 | 抵消权益项目 |
| 本期利润分配 | 处理投资收益和未分配利润 |
| 少数股东比例 | 计算少数股东权益和损益 |

权益抵消不能只靠模板。集团股权变动、增资、处置、少数股东变化、同一控制或非同一控制合并，都会影响抵消口径。

## 八、调整分录

调整分录用于把个别报表调整到集团统一口径。常见调整：

| 调整类型 | 示例 |
| --- | --- |
| 会计政策差异 | 折旧年限、坏账准备、收入确认口径不同 |
| 报表重分类 | 一年内到期长期负债、预收与合同负债重分类 |
| 期间差异 | 子公司关账延迟，需按集团期间调整 |
| 币别折算 | 外币报表折算差额 |
| 集团管理调整 | 内部考核口径、管理报表附表调整 |

调整分录要有摘要、依据、附件和审批。不要让调整分录变成“每月复制上月 Excel”的黑箱。

## 九、工作底稿和勾稽检查

合并工作底稿要能看清：

```text
个别报表数
  + 调整数
  - 抵消数
  = 合并报表数
```

勾稽检查至少包括：

- 资产负债表是否平。
- 利润表本年累计和本期数是否一致。
- 现金流量表与货币资金变动是否匹配。
- 所有者权益变动表与资产负债表权益项目是否一致。
- 内部往来抵消后余额是否为 0 或有合理说明。
- 报表项目与附表是否一致。

## 十、典型案例

### 案例 1：内部应收应付抵不平

现象：

- A 公司应收 B 公司 113 万。
- B 公司应付 A 公司 100 万。
- 合并报表内部往来抵消后仍有 13 万差异。

排查：

1. 查双方是否同一期间。
2. 查 A 是否含税、B 是否不含税。
3. 查 B 是否尚未收到发票或未暂估。
4. 查双方内部客商映射是否一致。
5. 查是否存在一方手工凭证。

处理：

- 属期间差，形成调节表，下期跟踪清零。
- 属未入账，补应付或暂估。
- 属税额口径差，统一往来和税额处理方式。
- 属客商映射错误，修正内部客户供应商。

### 案例 2：内部销售抵了收入，但利润仍虚高

现象：

- A 公司对 B 公司内部销售。
- 合并时抵消了内部收入和内部成本。
- 但 B 公司期末库存里仍包含内部加价利润。

排查：

1. 查 B 公司内部采购物料期末库存。
2. 查内部销售毛利率或加价金额。
3. 查是否已经销售给外部客户。
4. 查抵消模板是否包含未实现内部利润。

处理：

- 对期末未售内部存货计算未实现利润。
- 编制存货未实现利润抵消分录。
- 下期销售给外部客户时转回对应抵消。

### 案例 3：子公司报表上报后集团不断退回

现象：

- 子公司报表已提交。
- 集团多次退回，原因包括附表不平、项目为空、单位错误。

排查：

1. 查子公司使用的模板版本。
2. 查报表项目取数公式。
3. 查金额单位。
4. 查个别报表勾稽关系。
5. 查是否有手工改表未留说明。

处理：

- 集团统一分发模板版本。
- 上报前强制运行勾稽检查。
- 空项目要区分真实为 0、未取数、未填报。
- 建立退回原因台账，下月复用检查。

## 十一、月末合并报表作战清单

- [ ] 合并范围、股权关系和组织层级已确认。
- [ ] 所有子公司总账、应收、应付、存货、固定资产已完成对账。
- [ ] 内部客户、内部供应商和内部往来科目映射完整。
- [ ] 子公司使用同一版本报表模板。
- [ ] 个别报表已提交、审核、上报。
- [ ] 外币报表已按集团口径折算。
- [ ] 内部往来核对表已输出并处理差异。
- [ ] 内部交易、内部利润、内部资金、权益抵消已生成或手工补充。
- [ ] 调整分录有依据、附件和审批。
- [ ] 工作底稿能解释个别数、调整数、抵消数和合并数。
- [ ] 主表、附表、现金流和权益变动表勾稽通过。
- [ ] 合并报表归档时包含模板版本、抵消分录、调整说明和差异清单。
