合并报表解决的是“对外口径”：集团整体资产、负债、收入、利润是否真实反映。管理分析解决的是“对内口径”：哪个事业部赚钱，哪个产品线拖累利润，内部交易价格是否合理，区域、客户、渠道、项目和工厂的经营责任怎么拆。

很多集团项目的难点不是报表出不来，而是出了很多表却没人敢用。原因通常是：

- 法人口径和管理口径混在一起，事业部利润表里既有法人数据，又有手工 Excel 分摊。
- 内部交易只服务合并抵消，没有服务经营分析，导致内部收入、内部成本和转移利润说不清。
- 销售、供应链、制造、财务都能给出毛利，但口径不同，会议上互相打架。
- 总部想看区域、产品线、客户、渠道和项目利润，但基础单据没有沉淀这些维度。

这篇把集团管理分析拆成系统对象、核算维度、内部转移定价、事业部利润、经营指标和月度分析包。

## 一、管理分析主线

```text
管理架构和经营责任
  -> 组织、部门、事业部、产品线、项目、客户、渠道维度设计
  -> 内部交易和转移定价规则
  -> 业务单据沉淀管理维度
  -> 凭证和成本归集带出维度
  -> 管理报表和经营指标
  -> 差异分析、责任归因和经营复盘
```

不要等报表阶段再补维度。事业部利润、产品毛利、项目损益和客户贡献，必须从销售、采购、库存、制造、费用报销、固定资产、总账凭证等环节就开始沉淀。

## 二、先区分三种口径

| 口径 | 目标 | 典型报表 | 风险 |
| --- | --- | --- | --- |
| 法人口径 | 满足会计核算、税务、审计和法定报表 | 法人资产负债表、利润表、总账账簿 | 不能直接反映事业部责任 |
| 合并口径 | 反映集团对外整体经营结果 | 合并资产负债表、合并利润表 | 内部交易被抵消后看不到内部责任 |
| 管理口径 | 反映经营单元、产品线、区域和项目责任 | 事业部利润表、产品线毛利、客户贡献 | 口径设计不清会变成手工报表 |

一个金蝶项目可以同时支持三种口径，但必须把用途讲清楚。法人口径不能随便为了管理分析改科目；管理口径也不能用未经解释的手工分摊覆盖法定账。

## 三、管理维度设计

| 维度 | 常见用途 | 取数来源 | 设计提醒 |
| --- | --- | --- | --- |
| 管理组织 | 集团、区域、事业部、分公司 | 组织、部门、利润中心 | 和法人组织不一定一一对应 |
| 产品线 | 产品事业部、品牌、品类 | 物料、销售订单、BOM | 物料主数据要维护稳定分类 |
| 客户群 | 大客户、经销商、区域客户 | 客户档案、销售单据 | 客户归属可能随时间变化 |
| 渠道 | 直销、经销、电商、服务站 | 销售订单、店铺、渠道字段 | 影响收入、折扣和费用归集 |
| 项目 | 项目型交付、研发项目、工程项目 | 项目档案、合同、费用报销 | 项目生命周期要能关闭 |
| 成本中心 | 工厂、车间、部门、工作中心 | 费用、制造成本、固定资产 | 用于费用分摊和责任考核 |
| 区域 | 销售区域、服务区域、管理大区 | 客户、业务员、部门 | 区域变更要有历史口径 |

维度不是越多越好。真正要控制的是“每张关键单据必须带哪些维度，哪些维度可以从主数据继承，哪些维度允许人工改”。

## 四、内部转移定价

内部转移定价用于解决集团内部经营单元之间的交易计价。它既影响管理利润，也可能影响税务、合并抵消和绩效考核。

| 定价方式 | 适用场景 | 优点 | 风险 |
| --- | --- | --- | --- |
| 成本加成 | 工厂向销售公司供货、共享服务中心收费 | 简单、可解释 | 成本口径不清会转嫁低效 |
| 市场价 | 内部交易有外部可比价格 | 接近真实经营结果 | 市场价波动和取价来源要透明 |
| 标准价 | 产品线、服务、零部件内部结算 | 稳定、便于预算 | 标准价长期不更新会失真 |
| 协议价 | 特定项目、特殊客户、内部专项 | 灵活 | 需要审批和有效期 |
| 成本分摊 | 总部费用、共享服务、IT 服务 | 能归集公共成本 | 分摊动因容易被质疑 |

### 转移定价要落到系统字段

| 字段或对象 | 用途 |
| --- | --- |
| 内部客户和内部供应商 | 识别集团内部交易双方 |
| 组织间结算规则 | 定义跨组织交易是否生成内部应收应付 |
| 内部价目表 | 定义内部销售价格、服务价格和有效期 |
| 成本加成规则 | 定义成本来源、加成比例和取价期间 |
| 管理维度 | 带出事业部、产品线、项目或区域 |
| 抵消标识 | 区分对外收入和内部收入 |
| 价格审批 | 高风险内部价需要审批 |

## 五、事业部利润表

事业部利润表不是把总账科目按部门简单切开。它要把收入、成本、费用、内部交易、分摊和调整拆成能解释的层次。

```text
对外收入
  - 对外销售成本
  = 对外毛利
  + 内部收入
  - 内部成本
  = 管理毛利
  - 直接费用
  - 分摊费用
  - 资产折旧和占用成本
  = 事业部经营利润
```

| 项目 | 来源 | 关键口径 |
| --- | --- | --- |
| 对外收入 | 销售出库、应收、收入确认 | 是否含税、是否剔除内部客户 |
| 对外成本 | 出库成本、制造成本、采购成本 | 是否按实际成本、标准成本或管理成本 |
| 内部收入 | 内部销售、服务结算、组织间结算 | 是否参与考核，是否合并抵消 |
| 内部成本 | 内部采购、内部服务、内部加工费 | 是否和内部收入一一匹配 |
| 直接费用 | 费用报销、付款、总账凭证 | 是否带事业部或项目维度 |
| 分摊费用 | 总部费用、共享费用、公共资源 | 分摊动因和分摊周期 |
| 资产占用 | 固定资产、库存、应收账款 | 是否计算资本占用或周转指标 |

## 六、产品线毛利

产品线毛利比事业部利润更容易被使用，但也更容易口径混乱。

| 常见口径 | 说明 | 使用场景 |
| --- | --- | --- |
| 销售毛利 | 销售收入 - 销售出库成本 | 产品盈利能力 |
| 订单毛利 | 订单价格 - 预计成本 | 销售报价和接单评审 |
| 制造毛利 | 内部结算收入 - 制造成本 | 工厂或事业部考核 |
| 标准毛利 | 销售价 - 标准成本 | 预算、价格管理 |
| 实际毛利 | 收入 - 实际成本 | 月末复盘 |

产品线毛利必须写明：

- 收入取销售订单、应收、发票还是收入确认。
- 成本取标准成本、出库成本、完工成本还是管理成本。
- 退货、折让、返利、售后成本是否扣减。
- 内部交易是否剔除。
- 运费、佣金、平台费、渠道费是否归入产品线。

## 七、客户贡献分析

客户贡献不能只看销售额。大客户销售额高，但信用账期、折扣、售后和服务成本也可能高。

| 指标 | 说明 |
| --- | --- |
| 销售收入 | 按客户、期间、产品线统计 |
| 毛利额和毛利率 | 收入扣成本后的贡献 |
| 回款周期 | 应收周转和逾期风险 |
| 折扣折让 | 价格让利和促销成本 |
| 售后成本 | 免费备件、维修、赔偿、退货 |
| 资金占用 | 应收余额、未开票、信用额度 |
| 客户净贡献 | 毛利 - 销售费用 - 售后成本 - 资金占用成本 |

客户贡献分析最好和 [应收账龄、催收与坏账准备学习手册](ar-aging-collection-bad-debt-guide.md)、[客户索赔、售后备件、保内保外维修专题](../02_supply-chain/after-sales-claims-spare-parts-guide.md) 结合使用。

## 八、费用分摊设计

公共费用如果不分摊，事业部利润看起来都很好；如果分摊太粗，业务部门会觉得财务在“摊锅”。

| 费用类型 | 常见分摊动因 |
| --- | --- |
| 总部管理费用 | 人数、收入、费用预算、组织权重 |
| IT 系统费用 | 用户数、系统使用量、组织数量 |
| 共享财务费用 | 单据量、凭证量、组织数量 |
| 仓储费用 | 出入库行数、库存面积、库存金额 |
| 质量费用 | 检验批次、不良数量、质量责任 |
| 售后费用 | 服务单数、保内维修数、产品线责任 |

分摊规则要有三个约束：

1. 可解释：业务部门能理解。
2. 可复核：能从系统导出基础数据。
3. 可稳定：不要每月随意改。

## 九、管理报表包

月度经营分析建议形成一个固定报表包。

| 报表 | 主要问题 |
| --- | --- |
| 集团经营总览 | 收入、毛利、利润、现金、库存、应收是否达标 |
| 事业部利润表 | 哪个经营单元贡献或拖累利润 |
| 产品线毛利表 | 哪些产品赚钱，哪些产品需要调价或降本 |
| 客户贡献表 | 哪些客户占用资源但贡献低 |
| 内部交易分析 | 内部收入、内部成本、转移利润是否合理 |
| 费用执行分析 | 费用是否超预算，超支原因是什么 |
| 库存和应收周转 | 资金占用在哪里 |
| 异常清单 | 毛利异常、内部交易不匹配、维度缺失 |

## 十、数据质量检查

| 检查项 | 异常信号 | 处理 |
| --- | --- | --- |
| 管理维度缺失 | 销售、费用、成本没有事业部或产品线 | 从主数据继承或补录 |
| 内部客户未标识 | 内部交易混入对外收入 | 维护内部客商和交易标识 |
| 组织间结算不成对 | A 有内部收入，B 没有内部成本 | 查组织间结算和内部往来 |
| 成本期间不一致 | 收入本月确认，成本下月核算 | 按收入成本配比分析 |
| 手工凭证无维度 | 费用和调整无法归属 | 凭证模板或手工录入控制 |
| 分摊规则变化 | 本月利润异常波动 | 固化分摊方案和变更审批 |

## 十一、实施落地步骤

1. 访谈管理层，确认真正要看哪些经营单元和指标。
2. 画出法人组织、核算组织、管理组织和利润中心关系。
3. 设计产品线、客户群、渠道、项目、区域等管理维度。
4. 检查销售、采购、库存、制造、费用、总账是否能带出维度。
5. 定义内部转移定价规则和审批流程。
6. 定义费用分摊规则和责任人。
7. 搭建事业部利润表、产品线毛利、客户贡献和内部交易报表。
8. 用三个月历史数据回测。
9. 形成月度经营分析包。
10. 每月复盘指标异常和维度缺失。

## 十二、三个典型案例

### 案例 1：事业部收入很多，但利润很低

排查：

1. 分离对外收入和内部收入。
2. 查产品线毛利，确认是否低价销售。
3. 查售后成本、返利、佣金和渠道费用。
4. 查应收账期和资金占用。

处理：

- 如果是内部转移价偏低，调整内部价目表。
- 如果是费用归集缺失，补管理维度和费用分摊。
- 如果是客户贡献低，进入价格、信用和服务策略复盘。

### 案例 2：工厂利润很好，销售公司利润很差

排查：

1. 查工厂给销售公司的内部结算价。
2. 查销售公司对外折扣、运费、佣金和售后成本。
3. 查集团合并后整体毛利是否正常。

处理：

- 分清工厂制造绩效和销售渠道绩效。
- 内部价格可采用成本加成或市场价，但要稳定。
- 对外折扣和渠道费用要归到销售责任单元。

### 案例 3：管理报表和法定利润表差异很大

排查：

1. 列出管理调整项：内部收入、内部成本、分摊费用、标准成本调整。
2. 查是否把合并抵消数误用于管理利润。
3. 查手工 Excel 分摊是否未入系统。

处理：

- 固化管理口径差异桥。
- 每月输出“法人口径 -> 管理口径”调节表。
- 避免会议上只拿一张管理报表，不解释调整来源。
