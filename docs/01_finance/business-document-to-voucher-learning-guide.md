很多人学金蝶财务会卡在一个地方：凭证能看懂一点，业务单据也能看懂一点，但不知道它们中间怎么连起来。其实可以用一句话理解：

```text
业务单据记录“发生了什么”，财务凭证记录“这件事让钱、债权债务、成本、收入怎么变化”。
```

这篇按学习视角写，不追求一次讲完所有会计理论，而是把常见业务链路拆成几条主线：采购到付款、销售到收款、库存到成本、费用和资产到总账。学完以后，至少要能看懂一张凭证来自哪张单据，为什么借贷方向这样，出了差异应该先查哪里。

## 一、先建立一张总图

金蝶里的财务结果通常不是凭空录入的，而是从业务动作一步步沉淀出来。

```text
业务动作
  -> 业务单据
  -> 财务确认单据
  -> 凭证模板取数
  -> 会计凭证
  -> 过账
  -> 账表和报表
```

| 业务动作 | 业务单据 | 财务确认 | 常见凭证影响 |
| --- | --- | --- | --- |
| 买材料入库 | 采购订单、采购入库单 | 应付单、暂估应付 | 存货增加，应付增加 |
| 给供应商付款 | 付款申请、付款单 | 付款单、核销记录 | 银行减少，应付减少 |
| 卖货出库 | 销售订单、销售出库单 | 应收单、收入确认 | 应收增加，收入增加 |
| 客户回款 | 收款单、银行流水 | 收款单、核销记录 | 银行增加，应收减少 |
| 库存出入库 | 入库单、出库单、调拨单、盘点单 | 存货核算、成本调整 | 存货金额、成本变化 |
| 员工报销 | 费用报销单 | 其他应付、付款单 | 费用增加，应付或银行变化 |
| 买设备 | 采购单、资产卡片 | 固定资产卡片、折旧单 | 固定资产增加，折旧费用增加 |

### 新手最重要的三个问题

看任何一笔业务时，先问三个问题：

1. 这件事有没有让库存、资产、债权债务、收入、费用发生变化？
2. 变化是在业务单据审核时发生，还是到应收/应付/存货核算/凭证生成时才发生？
3. 系统有没有留下能追溯的来源：源单、下游单、凭证、核销记录、附件？

如果这三个问题回答不出来，先不要急着改凭证或改数据。

## 二、业务单据、财务单据、凭证的区别

### 业务单据：证明业务发生

业务单据回答的是“做了什么”。

| 单据 | 通俗理解 | 重点字段 |
| --- | --- | --- |
| 采购订单 | 我准备向谁买什么，多少钱，什么时候到 | 供应商、物料、数量、价格、税率、交期 |
| 采购入库单 | 货实际进仓库了 | 仓库、实收数量、批号、入库日期 |
| 销售订单 | 客户向我买什么，多少钱，什么时候交货 | 客户、物料、数量、价格、交期 |
| 销售出库单 | 货实际发出去了 | 仓库、出库数量、批号、出库日期 |
| 付款单 | 我给供应商付钱了 | 付款账户、供应商、金额、用途 |
| 收款单 | 客户给我钱了 | 收款账户、客户、金额、来源 |

### 财务单据：证明财务确认

财务单据回答的是“这件事在财务上确认了吗”。

| 单据 | 通俗理解 | 常见结果 |
| --- | --- | --- |
| 应付单 | 我确认欠供应商多少钱 | 形成供应商往来 |
| 应收单 | 我确认客户欠我多少钱 | 形成客户往来 |
| 付款单 | 我确认钱已经付出 | 银行减少，应付减少 |
| 收款单 | 我确认钱已经收到 | 银行增加，应收减少 |
| 存货核算单据 | 我确认库存价值和出库成本 | 存货金额、成本金额 |
| 折旧单 | 我确认本期资产折旧 | 折旧费用和累计折旧 |

### 凭证：证明会计入账

凭证回答的是“这件事最终进入哪几个会计科目，借贷金额是多少”。

凭证上最关键的是：

- 科目：这笔钱属于资产、负债、收入、成本还是费用。
- 借贷方向：金额增加还是减少，要按科目类型判断。
- 核算维度：客户、供应商、部门、项目、物料等辅助信息。
- 摘要：业务来源和用途。
- 来源单据：能不能从凭证反查业务单据。

## 三、采购到付款：从买东西到应付和付款

### 1. 采购链路通俗解释

```text
我想买
  -> 我下订单
  -> 供应商送货
  -> 仓库收货入库
  -> 财务确认应付
  -> 公司付款
  -> 应付核销
  -> 凭证入账
```

### 2. 系统链路

```text
采购申请
  -> 采购订单
  -> 采购入库单
  -> 应付单
  -> 付款单
  -> 付款核销
  -> 生成凭证
```

不同企业可能省略采购申请或到货环节，但采购入库、应付、付款、核销这几步要能理解。

### 3. 常见凭证逻辑

假设采购原材料 10000 元，不含税，税额 1300 元，暂不付款。

采购入库或应付确认后，常见理解：

```text
借：原材料/库存商品        10000
借：应交税费-进项税额       1300
贷：应付账款              11300
```

付款时：

```text
借：应付账款              11300
贷：银行存款              11300
```

注意：实际凭证以企业会计政策、税务口径、暂估口径、凭证模板为准。学习时先理解“货进来了、欠供应商钱了、付款后欠款减少了”。

### 4. 金蝶里要怎么查

| 想确认什么 | 去哪里看 | 看什么 |
| --- | --- | --- |
| 货有没有入库 | 采购入库单、即时库存 | 审核状态、仓库、数量、批号 |
| 应付有没有确认 | 应付单、供应商明细 | 应付单来源、金额、税额、供应商 |
| 款有没有付 | 付款单、银行日记账 | 付款账户、付款金额、审核状态 |
| 应付有没有核销 | 应付核销记录、供应商余额 | 应付余额是否减少 |
| 凭证有没有生成 | 凭证生成情况查询、总账凭证 | 来源单据、凭证状态、科目维度 |

### 5. 采购链路常见学习问题

| 现象 | 通俗理解 | 优先排查 |
| --- | --- | --- |
| 入库了但没有应付 | 财务还没确认欠款 | 应付生成规则、采购发票/入库来源、单据状态 |
| 应付有了但总账没有 | 财务单据还没入账 | 凭证模板、生成凭证、凭证审核/过账 |
| 付款了但供应商余额没少 | 付款没有和应付核销 | 付款单核销状态、核销对象 |
| 总账应付和应付模块不一致 | 子模块和总账断开了 | 未生成凭证、手工凭证、期间不一致、维度不一致 |
| 入库金额和发票金额不同 | 采购价格或税额有差异 | 暂估、发票匹配、价格调整、成本调整 |

### 6. 学习练习

在测试环境做一组最小数据：

1. 新建供应商 S001。
2. 新建物料 M001，采购价 100 元，税率 13%。
3. 做采购订单 10 件。
4. 下推采购入库，审核。
5. 生成应付单，审核。
6. 生成应付凭证。
7. 做付款单，核销应付。
8. 查询供应商余额和总账应付账款。

练习完成后写一张表：

| 步骤 | 单据编号 | 金额 | 凭证号 | 我理解发生了什么 |
| --- | --- | --- | --- | --- |
| 采购入库 | | | | 货进来了 |
| 应付确认 | | | | 欠供应商钱 |
| 付款 | | | | 银行减少，欠款减少 |

## 四、销售到收款：从卖货到应收和回款

### 1. 销售链路通俗解释

```text
客户下单
  -> 我确认订单
  -> 仓库发货
  -> 财务确认应收
  -> 客户付款
  -> 应收核销
  -> 凭证入账
```

### 2. 系统链路

```text
销售订单
  -> 销售出库单
  -> 应收单
  -> 收款单
  -> 收款核销
  -> 生成凭证
```

有些企业按发票确认应收，有些按出库确认应收，有些按签收或验收确认收入。项目上必须先问清企业口径。

### 3. 常见凭证逻辑

假设销售商品不含税 20000 元，销项税 2600 元，客户未付款。

确认收入和应收：

```text
借：应收账款              22600
贷：主营业务收入           20000
贷：应交税费-销项税额       2600
```

客户付款：

```text
借：银行存款              22600
贷：应收账款              22600
```

结转销售成本时，如果该批商品成本为 12000 元：

```text
借：主营业务成本           12000
贷：库存商品              12000
```

### 4. 收入和成本为什么可能不是同一张单据

新手容易以为“销售出库单审核就一定生成收入凭证”。实际项目里要看配置和业务口径。

| 结果 | 可能来源 |
| --- | --- |
| 收入和应收 | 应收单、发票、收入确认单 |
| 库存减少 | 销售出库单 |
| 销售成本 | 存货核算、出库成本核算、成本结转 |
| 回款 | 收款单、银行流水 |

所以销售链路要同时查三条线：

```text
货有没有发出去 -> 销售出库和库存
钱有没有形成债权 -> 应收单和客户余额
成本有没有结转 -> 存货核算和成本凭证
```

### 5. 销售链路常见学习问题

| 现象 | 通俗理解 | 优先排查 |
| --- | --- | --- |
| 出库了但没有应收 | 发货和财务确认不是同一步 | 应收生成口径、发票、出库单状态 |
| 应收有了但客户余额不对 | 维度或核销可能有问题 | 客户/结算客户、币别、期间、核销状态 |
| 收款了但账龄仍逾期 | 收款没有核销到具体应收 | 核销记录、预收款、收款用途 |
| 收入有了但成本没有 | 存货核算或成本结转没完成 | 出库核算、成本凭证、存货期间 |
| 退货后收入没冲回 | 退货和红字应收没串起来 | 退货单来源、红字应收、成本冲回 |

### 6. 学习练习

1. 新建客户 C001。
2. 新建商品 P001，设定销售价 200 元。
3. 做销售订单 5 件。
4. 下推销售出库并审核。
5. 生成应收单并审核。
6. 生成应收凭证。
7. 做收款单并核销。
8. 查询客户余额、应收明细账、总账应收科目。
9. 如果环境支持，做一次出库成本核算并生成成本凭证。

练习时重点记录：

- 销售出库单让库存数量发生了什么变化。
- 应收单让客户往来发生了什么变化。
- 收款单让银行和应收发生了什么变化。
- 成本凭证和收入凭证是不是同一时间生成。

## 五、库存到成本：为什么财务要关心仓库

财务不只是管钱，也要关心库存，因为库存既是实物，也是资产。

```text
仓库管数量
  -> 存货核算管金额
  -> 总账管最终入账
```

### 1. 库存数量和存货金额的区别

| 内容 | 关注点 | 常见查询 |
| --- | --- | --- |
| 库存数量 | 有多少件、在哪个仓库、哪个批次 | 即时库存、库存台账 |
| 存货金额 | 这些库存值多少钱、出库成本多少 | 存货收发存、存货核算报表 |
| 总账金额 | 会计报表上的存货余额是多少 | 科目余额表、明细账 |

库存数量对，不代表存货金额一定对；存货金额对，也不代表总账一定对。三者要对起来。

### 2. 常见库存凭证理解

采购入库：

```text
借：库存商品/原材料
贷：应付账款/暂估应付
```

销售出库结转成本：

```text
借：主营业务成本
贷：库存商品
```

盘盈：

```text
借：库存商品
贷：待处理财产损溢/其他收益等
```

盘亏：

```text
借：待处理财产损溢/管理费用等
贷：库存商品
```

实际科目要按企业会计政策确认，学习时重点理解“库存增加、减少、差异处理”。

### 3. 月末为什么供应链会卡住财务月结

财务月结经常卡在供应链，原因通常不是总账本身，而是业务单据还没关干净。

| 卡点 | 通俗解释 | 处理方向 |
| --- | --- | --- |
| 入库单未审核 | 货进来了但系统不承认正式入库 | 仓库补审核或作废错误单据 |
| 出库单未审核 | 货发了但库存未正式减少 | 销售/仓库确认发货 |
| 负库存 | 系统显示先发货后入库或库存不足 | 查出库顺序、批号、仓库、单据日期 |
| 未核算出库成本 | 成本还没算出来 | 做出库核算、检查入库成本 |
| 应收应付未生成 | 财务债权债务未确认 | 查生成规则、单据状态、发票口径 |
| 凭证未生成 | 业务账有了，总账还没有 | 查凭证模板和生成凭证情况 |

## 六、凭证生成：从配置到排查

金蝶通常通过凭证模板把业务单据变成凭证。可以把凭证模板理解成“自动制证规则”。

### 1. 凭证模板关心什么

| 模板要素 | 通俗解释 |
| --- | --- |
| 来源单据 | 从哪类单据生成凭证，例如应收单、应付单、付款单 |
| 科目来源 | 固定科目、按物料/客户/供应商/部门带出 |
| 金额来源 | 取价税合计、不含税金额、税额、成本金额 |
| 核算维度 | 客户、供应商、部门、项目、物料等 |
| 摘要规则 | 凭证摘要怎么写 |
| 生成条件 | 哪些状态、组织、期间的单据能生成 |

### 2. 凭证生成失败怎么学会排查

| 报错类型 | 通俗理解 | 排查 |
| --- | --- | --- |
| 科目为空 | 模板不知道用哪个科目 | 科目来源、物料/客户/供应商映射 |
| 维度为空 | 科目要求辅助核算但没带出 | 客户、供应商、部门、项目字段 |
| 金额为 0 | 单据没有可入账金额 | 金额字段、税额、成本核算 |
| 期间不合法 | 单据日期或会计期间不允许 | 业务日期、账簿期间、结账状态 |
| 单据状态不允许 | 单据还没审核或已生成 | 单据状态、重复生成控制 |
| 借贷不平 | 模板行金额或税额配置有问题 | 模板借贷行、取数公式、税率 |

### 3. 学习时不要直接改凭证

如果凭证来自业务单据，优先查来源单据和模板，不要直接改凭证把表面数字改平。

```text
凭证错
  -> 查来源单据
  -> 查凭证模板
  -> 查基础资料和维度
  -> 查业务期间和状态
  -> 必要时冲销重做
```

直接改凭证可能让总账看起来对了，但应收、应付、库存、存货核算仍然不对。

## 七、四条学习主线

### 主线 1：从凭证反查业务

练习：

1. 找一张应收凭证。
2. 看凭证上的客户维度、金额、摘要。
3. 反查应收单。
4. 继续反查销售出库或销售订单。
5. 写清楚每一步业务含义。

学会后，你就能判断“凭证为什么这么做”。

### 主线 2：从业务单据追到凭证

练习：

1. 找一张采购入库单。
2. 查是否生成应付单。
3. 查应付单是否生成凭证。
4. 查付款单是否核销。
5. 查总账科目余额是否反映。

学会后，你就能判断“业务已经做了，为什么总账没有”。

### 主线 3：从余额追到明细

练习：

1. 查应收账款科目余额。
2. 按客户维度展开。
3. 查应收模块客户余额。
4. 对比差异。
5. 逐笔追应收单、收款单、核销记录、凭证。

学会后，你就能处理“总账和业务账不一致”。

### 主线 4：从月结卡点追到责任模块

练习：

1. 月末列出所有未审核业务单据。
2. 查应收应付未生成清单。
3. 查存货核算未完成项目。
4. 查凭证生成失败清单。
5. 查总账未过账凭证。

学会后，你就能判断问题属于仓库、采购、销售、财务、系统配置还是二开。

## 八、给新人的 7 天学习安排

| 天数 | 主题 | 任务 | 成果 |
| --- | --- | --- | --- |
| 第 1 天 | 看懂凭证 | 学借贷、科目、维度、摘要、来源单据 | 解释 5 张凭证 |
| 第 2 天 | 采购到付款 | 跑采购订单、入库、应付、付款、核销 | 一张采购链路表 |
| 第 3 天 | 销售到收款 | 跑销售订单、出库、应收、收款、核销 | 一张销售链路表 |
| 第 4 天 | 库存和成本 | 查即时库存、存货收发存、成本凭证 | 一张库存金额对照表 |
| 第 5 天 | 凭证生成 | 看凭证模板、生成凭证、失败处理 | 一份失败排查记录 |
| 第 6 天 | 对账 | 对应收/应付/存货和总账 | 一份差异分析表 |
| 第 7 天 | 月结 | 模拟月结检查和报表取数 | 一份月结检查清单 |

## 九、最小练习数据包

为了学习，不要一开始用复杂真实数据。先建一个最小闭环：

| 数据 | 示例 |
| --- | --- |
| 供应商 | S001：测试供应商 |
| 客户 | C001：测试客户 |
| 物料 | M001：测试商品 |
| 仓库 | W001：成品仓 |
| 银行账户 | B001：测试银行 |
| 采购数量 | 10 件 |
| 采购单价 | 100 元 |
| 销售数量 | 5 件 |
| 销售单价 | 200 元 |

用这一套数据做完采购、销售、收付款、核销、凭证和报表查询。每一步都记录单据编号。

## 十、常见误区

| 误区 | 为什么错 | 正确理解 |
| --- | --- | --- |
| 业务单据审核了就一定有凭证 | 业务确认和会计入账可能分开 | 查财务单据和凭证生成 |
| 有凭证就说明业务账也对 | 可能手工凭证绕过子模块 | 要能从凭证追到来源单据 |
| 收付款做了就等于往来清了 | 没核销仍可能挂账 | 查核销记录和余额 |
| 库存数量对就说明成本对 | 数量和金额是两条线 | 查存货核算和成本凭证 |
| 总账余额不对就直接调凭证 | 会造成业务账和总账脱节 | 先查来源、模板、期间、维度 |
| 新增科目后只改科目表 | 报表和凭证模板可能漏配置 | 同步检查模板、公式和权限 |

## 十一、学习检查清单

- [ ] 能解释采购入库、应付单、付款单、凭证之间的关系。
- [ ] 能解释销售出库、应收单、收款单、成本凭证之间的关系。
- [ ] 能从一张凭证反查来源单据。
- [ ] 能从一张业务单据追到凭证。
- [ ] 能解释核销为什么影响账龄和往来余额。
- [ ] 能解释库存数量、存货金额、总账金额的区别。
- [ ] 能说出凭证生成失败的常见原因。
- [ ] 能做一份月结前业务单据检查表。
