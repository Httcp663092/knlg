数据清理服务解决的是“历史数据太多，系统变慢，存储压力大”。但真正的生产治理不能只清理：哪些数据可以删，哪些必须归档，哪些接口报文要留存，哪些日志要保留到审计完成，哪些附件要和凭证一起可追溯，都要先定规则。

这篇把数据清理、归档、接口报文留存、附件留存、操作日志和审计追溯放在一套治理框架里。

## 一、治理主线

```text
数据分类
  -> 保留期限
  -> 归档或清理策略
  -> 执行计划
  -> 备份和回滚
  -> 抽样验证
  -> 审计查询
  -> 周期复盘
```

清理不是目的，系统长期可用、数据可追溯、审计可说明才是目的。

## 二、先做数据分级

| 数据类型 | 示例 | 建议策略 |
| --- | --- | --- |
| 会计凭证和账簿 | 凭证、总账、明细账、报表 | 长期保留，谨慎归档，不直接清理 |
| 业务单据 | 采购、销售、库存、生产、应收应付 | 结清后可按年归档，保留查询入口 |
| 流程日志 | 审批流转、任务、消息 | 保留必要周期后清理或归档 |
| 接口报文 | 请求、响应、错误、重试日志 | 按业务风险分级留存，脱敏 |
| 附件档案 | 发票、合同、回单、照片、检测报告 | 按凭证、合同、质保和审计要求保留 |
| 操作日志 | 登录、导出、反审核、反结账、删除 | 高危日志长期留存 |
| 临时数据 | 临时导入表、缓存、中间表 | 确认无业务价值后清理 |

## 三、保留期限设计

| 数据 | 建议考虑因素 |
| --- | --- |
| 财务会计资料 | 法规、审计、税务、集团制度 |
| 采购销售合同 | 合同履约期、质保期、争议期 |
| 发票和税务资料 | 税务检查和电子档案要求 |
| 质量和售后资料 | 产品质保、召回、客户投诉 |
| 接口报文 | 对账周期、补偿周期、审计要求 |
| 系统日志 | 安全审计、问题追溯、存储成本 |

不要用一个统一期限覆盖所有数据。比如接口成功报文可以短期保留摘要，失败报文和补偿记录要留更久；财务凭证不能按普通业务日志清理。

## 四、清理和归档的区别

| 动作 | 含义 | 适用 |
| --- | --- | --- |
| 清理 | 从当前库删除或移除过期数据 | 临时日志、过期消息、无审计价值数据 |
| 归档 | 移到归档库或归档存储，保留可查路径 | 已结业务、历史单据、历史流程 |
| 脱敏 | 保留数据但隐藏敏感字段 | 接口报文、个人信息、银行账号 |
| 压缩 | 降低存储占用 | 附件、报文、历史日志 |
| 冻结 | 不允许修改，只允许查询 | 凭证、已审计资料、结账期间数据 |

## 五、接口报文留存

接口报文是生产问题排查和对账的重要证据，但也可能包含客户、银行账号、价格、地址等敏感信息。

### 留存字段

| 字段 | 说明 |
| --- | --- |
| 接口名称 | 哪个接口 |
| 调用方向 | 外部到金蝶或金蝶到外部 |
| 外部单号 | 幂等和对账 |
| 金蝶单号 | 追到业务单据 |
| 请求时间 | 调用时间 |
| 响应时间 | 响应时间 |
| 状态 | 成功、失败、处理中、已补偿 |
| 请求摘要 | 脱敏后关键字段 |
| 响应摘要 | 错误码、消息、目标单号 |
| 原始报文路径 | 如需要，指向归档文件 |
| 重试次数 | 补偿排查 |
| 处理人 | 人工干预 |

### 留存策略

| 报文类型 | 建议 |
| --- | --- |
| 成功且低风险 | 保留摘要，原文短期保留 |
| 失败报文 | 保留原文或脱敏原文直到问题关闭 |
| 涉及付款、发票、库存、成本 | 保留更长周期，支持审计 |
| 涉及个人敏感信息 | 脱敏或加密存储 |
| 大附件报文 | 存文件对象，库里只存路径和摘要 |

## 六、附件归档

附件不要只看“能不能上传”。要看能否和业务链路、凭证和审计问题关联。

| 附件类型 | 关联对象 | 风险 |
| --- | --- | --- |
| 发票 | 应收、应付、凭证、税务申报 | 发票和凭证断链 |
| 合同 | 销售订单、采购订单、收入确认 | 合同条款无法证明 |
| 银行回单 | 付款单、收款单、银行流水 | 付款事实无法追溯 |
| 质检报告 | 收料、退货、售后、质量问题 | 责任归属不清 |
| 客户确认 | 验收、服务完成、索赔 | 收入确认或售后争议 |
| 接口报文附件 | 外部系统同步文件 | 失败原因无法复盘 |

## 七、操作日志和审计追溯

高危操作日志必须优先保留。

| 操作 | 为什么重要 |
| --- | --- |
| 反审核、反结账、反过账 | 可能改变已确认业务和财务结果 |
| 删除单据 | 影响追溯 |
| 导出敏感报表 | 涉及数据泄露 |
| 修改银行账号 | 涉及付款风险 |
| 修改价格、税率、折扣 | 影响收入、成本和利润 |
| 修改权限和角色 | 涉及越权 |
| 接口账号调用 | 涉及外部系统责任 |

### 日志字段

```text
用户
角色
组织
IP / 终端
操作时间
菜单
单据类型
单据编号
操作按钮
修改前摘要
修改后摘要
是否高危
审批或申请单号
```

## 八、归档前检查表

| 检查 | 说明 |
| --- | --- |
| 业务是否完结 | 未完结流程、未结订单不能归档 |
| 财务是否结账 | 未完成月结期间不要动 |
| 是否有审计或争议 | 涉诉、审计、客户投诉数据不能清理 |
| 是否有备份 | 可恢复是底线 |
| 是否可查询 | 归档后用户怎么查历史 |
| 是否影响报表 | 历史报表是否还要重算 |
| 是否影响接口补偿 | 失败报文是否还要重试 |
| 是否有审批 | 清理归档必须有业务和技术确认 |

## 九、执行流程

```text
数据盘点
  -> 规则设计
  -> 影响评估
  -> 测试环境演练
  -> 备份
  -> 生产低峰执行
  -> 抽样验证
  -> 业务确认
  -> 归档报告
```

### 归档报告模板

| 字段 | 内容 |
| --- | --- |
| 规则名称 | 本次执行的清理或归档规则 |
| 数据对象 | 清理或归档哪些实体 |
| 条件 | 时间、状态、组织、业务范围 |
| 执行时间 | 开始和结束 |
| 执行数量 | 成功、失败、跳过 |
| 备份位置 | 备份或归档存储位置 |
| 验证结果 | 抽样查询、报表、日志 |
| 异常处理 | 失败数据和处理方式 |
| 审批记录 | 谁批准 |

## 十、常见事故

| 事故 | 原因 | 处理 |
| --- | --- | --- |
| 清理后查不到审批历史 | 流程日志保留周期太短 | 恢复备份或查归档库，调整保留期限 |
| 接口失败无法复盘 | 报文只保留当天 | 增加失败报文留存和摘要字段 |
| 附件路径失效 | 文件迁移没有更新索引 | 重建附件索引和访问测试 |
| 审计要求提供反审核记录 | 高危操作日志未分类 | 增加高危日志报表和长期留存 |
| 清理任务拖慢系统 | 单次清理量过大 | 分批、限流、低峰执行 |
