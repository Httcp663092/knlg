PLM 管产品研发和工程变更，金蝶管采购、生产、库存、成本和财务。PLM-BOM 集成最怕的不是字段传不过来，而是工程变更已经在 PLM 生效，金蝶生产订单还在用旧 BOM；采购按旧物料下单，车间按旧版本领料，成本按旧结构核算，最后质量追溯也说不清。

这篇整理 PLM 和金蝶之间的物料、BOM、工程变更、版本生效、生产订单和追溯闭环。

## 一、PLM-BOM 集成主线

```text
PLM 物料和设计 BOM
  -> 审批发布
  -> 同步金蝶物料和工程 BOM
  -> 金蝶 BOM 审核和生效
  -> MRP、采购、生产订单和领料使用
  -> 工程变更 ECN/ECO
  -> 变更同步和版本切换
  -> 生产批次、成本和质量追溯
```

必须先定边界：PLM 是工程源头，金蝶是业务执行和财务源头。PLM 负责设计结构、图纸、版本、变更原因；金蝶负责可采购、可生产、可库存、可核算。

## 二、对象边界

| 对象 | 建议主系统 | 同步到金蝶的内容 |
| --- | --- | --- |
| 设计物料 | PLM | 编码、名称、规格、版本、图号 |
| 业务物料 | 金蝶或 PLM 共同治理 | 采购/库存/生产属性、计量单位、批号序列号 |
| 设计 BOM | PLM | 父项、子项、用量、位号、替代关系 |
| 制造 BOM | 金蝶 | 发料方式、仓库、损耗、工序、成本相关属性 |
| 图纸和技术文档 | PLM | 文档编号、版本、链接或附件索引 |
| 工程变更 | PLM | 变更单号、原因、生效日期、影响物料 |
| 生产订单 | 金蝶 | 使用的 BOM 版本、批次、领料和完工 |

不要把 PLM 的设计 BOM 原样当成金蝶生产 BOM。制造 BOM 往往需要补发料方式、损耗、替代料策略、工序、仓库和成本属性。

## 三、物料同步规则

| 字段 | 风险 | 建议 |
| --- | --- | --- |
| 物料编码 | 重码、临时编码、研发编码和生产编码不一致 | 定编码规则和编码申请流程 |
| 物料名称 | PLM 名称和采购名称不一致 | 名称同步但允许业务补充规格 |
| 规格型号 | 文本不规范 | 建关键属性字段 |
| 计量单位 | PLM 件、金蝶 PCS 或套 | 同步前做单位映射 |
| 物料属性 | 自制、外购、委外、虚拟件 | 金蝶侧必须确认 |
| 批号/序列号 | 追溯要求不清 | 质量、售后和财务一起确认 |
| 默认仓库 | PLM 没有仓库概念 | 金蝶侧维护 |
| 版本 | PLM 版本和金蝶 BOM 版本关系 | 建版本映射表 |

物料同步不要只看新增。物料变更、禁用、替代、停用、规格变更都要有规则。

## 四、BOM 同步规则

```text
PLM 设计 BOM
  -> BOM 发布审批
  -> 集成平台校验
  -> 金蝶 BOM 暂存
  -> 工艺、仓库、发料方式补充
  -> 金蝶 BOM 审核生效
```

| 字段 | 说明 | 校验 |
| --- | --- | --- |
| 父项物料 | 成品或半成品 | 金蝶物料必须存在且允许生产 |
| 子项物料 | 原材料、半成品、包材 | 金蝶物料必须存在且状态有效 |
| 用量 | 单位成品耗用数量 | 不能为空或为 0 |
| 损耗率 | 正常损耗 | 超过阈值需审批 |
| 生效日期 | BOM 可用起始日期 | 不能早于当前已执行订单的限制日期 |
| 失效日期 | BOM 停用日期 | 新旧版本不能无边界重叠 |
| 替代料 | 允许替代的材料 | 替代规则要审批 |
| 位号 | 电子、装备行业常用 | 不一定参与生产领料，但要保留 |
| 工序 | 子项在哪道工序消耗 | PLM 没有时由金蝶或工艺系统补 |

## 五、工程变更分类

| 变更类型 | 示例 | 对金蝶影响 |
| --- | --- | --- |
| 新增物料 | 新零件、新包材 | 新建物料、采购属性、库存属性 |
| 替换物料 | A 材料替换为 B 材料 | BOM 子项变更、库存替代消耗 |
| 用量变更 | 用量从 2 改为 2.1 | MRP、领料、成本变化 |
| 版本升级 | V1.0 到 V2.0 | 新 BOM 版本、生效日期 |
| 图纸变更 | 图纸版本更新 | 技术文档和质量标准更新 |
| 工艺变更 | 工序、工时、工作中心调整 | 工艺路线、报工和成本 |
| 停用物料 | 旧料停用 | 采购停用、库存消耗策略 |

## 六、ECN/ECO 生效控制

工程变更不能只同步结果，还要同步生效策略。

| 生效方式 | 说明 | 风险 |
| --- | --- | --- |
| 立即生效 | 审批后新单全部用新版 | 旧库存和在制订单处理不清 |
| 指定日期生效 | 到日期后使用新版 | 跨日期订单要校验 |
| 指定批次生效 | 从某个生产批次开始 | 批次追溯要求高 |
| 指定订单生效 | 某些订单使用新版 | 操作复杂但最安全 |
| 旧料用尽生效 | 库存旧料消耗完再切新版 | MRP 和采购要配合 |

每张工程变更单必须回答：

1. 哪些物料和 BOM 受影响。
2. 哪些未下达订单受影响。
3. 哪些已下达未领料订单受影响。
4. 哪些已领料或在制订单不允许自动变更。
5. 旧库存怎么处理。
6. 供应商和采购订单是否受影响。

## 七、生产订单影响分析

工程变更同步前要跑影响分析。

| 对象 | 检查内容 |
| --- | --- |
| 未投放计划订单 | 是否重新跑 MRP |
| 已下达未开工生产订单 | 是否更新 BOM 版本 |
| 已开工未领料订单 | 是否允许变更用料 |
| 已领料在制订单 | 是否冻结旧版本 |
| 委外订单 | 供应商是否已经领料或加工 |
| 采购订单 | 旧料采购是否取消或改料 |
| 库存旧料 | 是否继续消耗、退供、报废或替代 |
| 售后备件 | 旧版本备件是否仍需保留 |

## 八、版本追溯

PLM-BOM 集成落地后，至少要能回答：

- 这张生产订单使用哪个 BOM 版本。
- 这批产品用了哪些子项批号和版本。
- 这个客户产品对应哪次工程变更。
- 这个质量问题发生时新版是否已生效。
- 这个采购订单买的是旧料还是新料。
- 这个售后备件适配哪个产品版本。

建议在金蝶生产订单、领料、完工入库、销售出库和售后单据中保留关键追溯字段：

| 字段 | 用途 |
| --- | --- |
| PLM 物料版本 | 追溯设计版本 |
| 金蝶 BOM 版本 | 追溯制造版本 |
| 工程变更单号 | 追溯变更原因 |
| 图纸版本 | 追溯技术文档 |
| 生效批次 | 判断是否适用变更 |
| 旧料处理标识 | 判断替换和消耗策略 |

## 九、接口和日志要求

| 日志字段 | 说明 |
| --- | --- |
| PLM 单号 | 物料、BOM 或变更来源 |
| 金蝶单号 | 物料编码、BOM 编码或变更记录 |
| 版本 | PLM 版本和金蝶版本 |
| 接口方向 | PLM 到金蝶、金蝶回写 PLM |
| 幂等键 | PLM 对象 + 版本 + 变更单号 |
| 校验结果 | 成功、失败、部分成功 |
| 错误原因 | 物料不存在、单位不匹配、状态不允许 |
| 处理人 | 人工补充工艺、仓库或属性 |
| 处理时间 | 用于追溯 |

## 十、常见异常排查

| 现象 | 可能原因 | 排查路径 | 处理 |
| --- | --- | --- | --- |
| PLM BOM 已发布，金蝶没有新版本 | 接口失败、BOM 校验失败、金蝶物料未建 | 查接口日志、物料同步、BOM 暂存 | 先补物料，再重试 BOM |
| 金蝶 BOM 有新版，但 MRP 仍用旧版 | 生效日期、默认版本、计划参数未更新 | 查 BOM 版本、有效期、计划取数 | 修生效规则并重跑 MRP |
| 生产订单用错版本 | 下达时未锁定版本或变更后自动覆盖 | 查生产订单 BOM 版本和变更时间 | 已开工订单冻结版本 |
| 新料已采购，旧料库存积压 | 旧料处理策略缺失 | 查库存、采购订单、变更单 | 建旧料消耗或退供计划 |
| 售后备件发错版本 | 产品版本和备件适配关系没维护 | 查客户产品序列号和备件版本 | 建适配表和售后校验 |
| 成本突然波动 | BOM 用量或替代料变更 | 查工程变更、领料、出库成本 | 将变更纳入成本分析 |

## 十二、三个典型案例

### 案例 1：工程变更已生效，车间仍按旧料领料

排查：

1. 查 PLM 变更单生效日期。
2. 查金蝶 BOM 新版本是否审核生效。
3. 查生产订单下达日期和锁定的 BOM 版本。
4. 查是否已经领料。

处理：

- 未开工订单可更新 BOM 版本。
- 已领料订单走补退料或冻结旧版本。
- 后续变更必须先跑生产订单影响分析。

### 案例 2：新 BOM 同步失败，因为子项物料不存在

排查：

1. 查 PLM 子项物料是否已发布。
2. 查金蝶物料是否已经同步。
3. 查物料属性、单位和组织分配是否完整。

处理：

- 按物料先于 BOM 的顺序重试。
- 对 BOM 接口增加前置校验。
- 失败时进入人工补齐清单，不允许静默丢弃。

### 案例 3：售后备件和产品版本不适配

排查：

1. 查客户产品序列号和生产批次。
2. 查生产批次使用的 BOM 版本。
3. 查备件适配版本和替代关系。

处理：

- 建产品版本和备件版本适配表。
- 售后发件时校验序列号适配关系。
- 老版本备件保留生命周期和替代策略。
