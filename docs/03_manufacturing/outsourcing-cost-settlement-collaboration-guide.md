这篇不是再讲一遍“委外订单怎么录”，而是把委外项目里最容易散掉的几个环节串起来：委外计划、BOM 用料、供应商领料、委外在制、收料入库、质量判定、加工费应付、材料耗用、委外成本和供应商对账。

委外业务的难点在于它同时像生产、采购、库存和成本：物料是企业自己的，生产动作发生在供应商现场，入库成品要进库存，加工费又要进入应付和成本。只盯委外订单状态，很容易漏掉供应商处材料余额、加工费到票、超耗责任和入库成本。

## 一、完整主线

```text
销售需求 / 计划需求 / 生产需求
  -> 委外申请或委外计划
  -> 委外订单
  -> 委外用料清单
  -> 委外备料和齐套分析
  -> 委外发料 / 领料
  -> 供应商加工
  -> 委外收料 / 委外入库
  -> 质量检验和不良处理
  -> 委外加工费应付
  -> 委外入库核算
  -> 存货、应付、成本和总账对账
```

项目里建议把委外拆成三本账：

| 账 | 关注对象 | 常见报表或证据 |
| --- | --- | --- |
| 材料账 | 发给供应商的材料、补料、退料、超耗 | 委外领料明细、供应商处库存、委外退补料记录 |
| 任务账 | 委外订单、用料清单、收料入库、结案 | 委外订单执行明细、未入库数量、未结案订单 |
| 成本账 | 发出材料成本、加工费、费用分摊、入库成本 | 委外入库核算、应付单、存货核算、凭证 |

## 二、角色分工

| 角色 | 负责动作 | 必须交接的信息 |
| --- | --- | --- |
| 计划员 | 判断哪些订单委外，维护交期、数量、供应商 | 需求来源、计划完工日期、BOM 版本、替代料规则 |
| 采购 / 委外专员 | 下达委外订单，维护加工价格，跟催供应商 | 加工单价、税率、交货周期、供应商产能 |
| 仓库 | 发料、补料、退料、收货、入库 | 物料批号、库位、发料数量、供应商处材料余额 |
| 质量 | 来料、委外成品、退料和返工检验 | 检验结果、不良原因、处理方式、责任归属 |
| 成本会计 | 核算发出材料、加工费、委外入库成本 | 材料成本、加工费应付、费用分摊、入库核算结果 |
| 应付会计 | 确认加工费应付、发票、付款 | 供应商、加工数量、单价、税率、到票和付款状态 |

委外专员要负责“流程闭环”，但不能替代成本会计确认成本，也不能替代质量部门判定不良。角色边界不清时，委外最容易出现“仓库说货已回，采购说供应商已交，财务说成本没出来”的断点。

## 三、委外订单下达前检查

| 检查项 | 为什么重要 | 失败表现 |
| --- | --- | --- |
| 委外物料属性 | 决定物料能否走委外流程 | 订单录入或下推失败 |
| BOM 版本 | 决定用料清单和发料数量 | 少发、多发、漏发关键料 |
| 委外供应商 | 决定加工方和应付对象 | 应付挂错供应商，供应商对账困难 |
| 发料仓库 | 决定材料从哪里出 | 库存足够但不能领料 |
| 加工价格 | 决定加工费应付和入库成本 | 入库有数量无加工费 |
| 质量方案 | 决定是否请检、检验项目和判定规则 | 不良品直接入可用库存 |
| 税率和币别 | 影响应付、发票和付款 | 到票金额和应付金额不一致 |

委外订单下达前不要只看“能不能保存”。真正的验收口径是：订单能生成用料清单，能按批号发料，供应商能按订单交货，入库后能形成完整成本，应付和供应商对账能解释清楚。

## 四、委外发料、补料和退料

### 1. 正常发料

```text
委外订单
  -> 委外用料清单
  -> 委外领料单
  -> 材料出库
  -> 供应商处材料余额增加
```

检查重点：

- 领料是否关联委外订单和用料清单。
- 发料数量是否按 BOM 用量、订单数量和损耗率计算。
- 批号、库位、辅助属性是否带出。
- 供应商处材料是否单独可查。
- 同一供应商多张委外订单合并发料时，能否追溯到具体订单。

### 2. 补料

常见补料原因：

- BOM 漏料或用量偏低。
- 加工损耗超过标准。
- 供应商操作报废。
- 客户临时变更导致加料。
- 首批试产后调整工艺。

补料必须带原因和审批。否则后续超耗会变成一笔没人负责的材料成本，供应商对账时也说不清“这批材料是企业承担还是供应商赔偿”。

### 3. 退料

退料场景：

- 发料多发。
- 订单取消。
- 加工完成后余料退回。
- 材料不合格退回。
- 供应商换料或替代料调整。

退料检查：

- 退回材料是否和原发料批号一致。
- 退料是否影响供应商处材料余额。
- 退回材料进入可用库存、待检库存还是不良库存。
- 订单结案前是否已经清理余料。

## 五、委外收料、质检和入库

委外入库不是单纯收货，它要同时解决四个问题：

| 问题 | 关键点 |
| --- | --- |
| 货回来了没有 | 收料数量、入库数量、未入库数量 |
| 质量合格没有 | 请检、检验结果、让步接收、返工、报废 |
| 材料耗用了多少 | 按订单、批号、BOM 和实际耗用核对 |
| 成本完整没有 | 发出材料成本、加工费、分摊费用是否进入入库成本 |

建议流程：

```text
供应商送货
  -> 委外收料
  -> 质量请检
  -> 检验合格 / 让步 / 返工 / 报废
  -> 委外入库
  -> 委外入库核算
```

如果质量还没判定，不要直接入可用库存。至少要用待检状态或待处理仓隔离，否则后续销售、生产领料或成本核算会把不良品当成正常库存使用。

## 六、加工费应付和到票

委外加工费通常由委外入库、采购结算或应付单确认。项目里要提前确定口径：

| 口径 | 适用场景 | 风险 |
| --- | --- | --- |
| 按委外入库数量确认加工费 | 入库即确认加工完成 | 质检不合格时要处理扣款或返工 |
| 按合格入库数量确认加工费 | 质量强控制行业 | 收料到合格之间存在暂挂量 |
| 按供应商发票确认加工费 | 财务以到票为准 | 入库成本可能先缺加工费 |
| 按合同或工序节点确认 | 长周期加工或分阶段付款 | 要管理未完工、预付和暂估 |

应付检查：

- 应付供应商是否等于委外供应商。
- 加工数量是否和合格入库数量一致。
- 加工单价是否来自价目表、合同或订单。
- 税率、币别、价税合计是否正确。
- 到票差异是否能回到委外订单或入库单。
- 付款前是否已处理质量扣款、超耗扣款和赔偿。

## 七、委外成本核算

委外成品入库成本通常由三部分组成：

```text
委外入库成本
  = 委外发出材料成本
  + 委外加工费
  + 其他可归集费用
```

成本会计月末要查：

| 检查对象 | 正常结果 | 异常信号 |
| --- | --- | --- |
| 发出材料成本 | 已按存货核算取得成本 | 领料数量有了，金额为 0 |
| 委外加工费 | 已形成应付或暂估 | 入库成本只有材料没有加工费 |
| 委外退补料 | 已反映在耗用和供应商余额中 | 材料余额为负或长期不清 |
| 委外入库核算 | 已核算并生成成本 | 入库单未核算、成本不完整 |
| 凭证 | 存货、应付、成本方向正确 | 业务账和总账不一致 |

如果加工费发票下月才到，建议先明确暂估口径：是月末暂估加工费，还是等到票再调整成本。不要让同一类业务有的暂估、有的不暂估，否则毛利和库存成本会忽高忽低。

## 八、供应商对账

委外供应商对账至少包含两张表：

| 对账表 | 对账内容 |
| --- | --- |
| 材料对账 | 期初供应商处材料 + 本期发料 + 本期补料 - 本期退料 - 本期耗用 = 期末供应商处材料 |
| 加工费对账 | 期初未结加工费 + 本期合格入库加工费 - 本期扣款 - 本期开票 - 本期付款 = 期末未结加工费 |

供应商对账常见差异：

| 现象 | 排查方向 |
| --- | --- |
| 供应商说材料已耗完，系统还有余额 | 查是否有入库耗用未反写、退料未录、订单结案未清 |
| 系统显示材料为负 | 查是否先入库倒冲、补料未录、BOM 用量错误 |
| 加工费应付比供应商发票多 | 查不合格扣款、数量差异、单价变更、税率差异 |
| 入库成本偏低 | 查加工费未确认、费用未分摊、发出材料成本为 0 |
| 入库成本偏高 | 查重复应付、重复费用分摊、超耗材料全部进成本 |

## 九、典型案例

### 案例 1：委外入库有数量但成本只有材料

现象：

- 委外成品已经入库。
- 存货收发存有数量和部分金额。
- 成本会计发现加工费没有进成品成本。

排查：

1. 查委外入库单是否已核算。
2. 查加工费应付单是否生成。
3. 查加工单价是否为空或为 0。
4. 查应付单是否关联委外入库。
5. 查费用是否需要另做分摊。

处理：

- 补维护加工价目或委外订单单价。
- 补生成加工费应付或暂估。
- 重新执行委外入库核算。
- 复核存货和总账凭证。

### 案例 2：供应商处材料长期对不上

现象：

- 委外订单已经结案。
- 系统仍显示供应商处材料余额。
- 供应商对账单认为没有剩余材料。

排查：

1. 按供应商、物料、批号导出发料、补料、退料、入库耗用。
2. 查是否存在多张订单合并发料但入库未按订单耗用。
3. 查是否有余料退回未录系统。
4. 查是否有超耗但未做超耗处理。
5. 查订单结案是否允许未清材料余额。

处理：

- 有实物的，补退料或调整供应商处库存。
- 已实际耗用的，按审批补耗用或超耗单。
- 属供应商责任的，形成扣款或赔偿记录。
- 后续结案前固定检查供应商处材料余额。

### 案例 3：委外不良返工后成本重复

现象：

- 委外入库检验不合格，发回供应商返工。
- 返工后再次入库。
- 成本中出现两次加工费或材料耗用。

排查：

1. 查首次不良是否已经正式入库。
2. 查返工是否使用返工委外订单。
3. 查返工用料清单是否只包含需要补充的材料。
4. 查加工费应付是否按一次合格入库或两次加工确认。
5. 查不合格品处理是否冲回原入库成本。

处理：

- 区分“未入库返工”和“已入库后返工”。
- 已入库再返工要明确退库、返工、再入库的成本处理。
- 供应商责任返工不应重复确认企业承担的加工费。

## 十、上线验收清单

- [ ] 委外物料、BOM、委外车间、供应商、发料仓库配置完整。
- [ ] 委外订单能生成用料清单，并能按订单数量计算用量。
- [ ] 委外齐套分析能识别缺料。
- [ ] 委外领料、补料、退料能按批号和供应商追溯。
- [ ] 委外收料、请检、合格入库、不良返工能跑通。
- [ ] 加工费能从订单、价目或结算规则带出。
- [ ] 委外加工费能形成应付、到票和付款闭环。
- [ ] 委外入库核算能同时包含材料和加工费。
- [ ] 供应商处材料余额能按供应商、物料、批号查询。
- [ ] 委外订单结案前能检查未清材料、未入库、未应付和未核算。
- [ ] 月末能输出委外材料对账表和加工费对账表。
