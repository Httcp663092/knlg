这篇是数据区的“随手查询包”。它不追求背死某个版本的物理表名，因为金蝶产品、版本、补丁、数据库类型、二开和客户化都会改变表结构。这里沉淀的是项目排查时最常用的对象、字段、过滤条件、查询结构和交付格式。

使用原则：

- 先用前台菜单、单据编号、标准报表锁定业务事实，再写 SQL。
- 表名、字段名、状态值必须以当前环境元数据、数据库字典或开发平台为准。
- 只读查询优先，生产环境不直接执行更新、删除、补状态 SQL。
- 每条 SQL 都要能解释组织、期间、状态、币别、账簿、数据来源和风险。

## 一、常见对象字典

| 对象 | 业务含义 | 常见字段线索 | 排查用途 |
| --- | --- | --- | --- |
| 组织 | 业务组织、库存组织、核算组织、结算组织 | 组织内码、组织编码、组织名称 | 判断数据属于哪个公司、工厂、库存组织或核算主体 |
| 账簿 | 会计核算口径 | 账簿内码、账簿编码、币别、期间 | 判断凭证、余额、报表是否同一核算口径 |
| 单据头 | 单据主信息 | 单据编号、单据日期、单据状态、审核状态、创建人、审核人 | 查一张单据是否存在、是否审核、期间是否正确 |
| 单据体 | 单据明细行 | 物料、数量、单价、金额、仓库、批号、税率 | 查明细金额、数量、物料、仓库和业务口径 |
| 基础资料 | 客户、供应商、物料、部门、员工、科目等 | 编码、名称、状态、使用组织、控制策略 | 查引用是否失效、重复、禁用或组织不可用 |
| 上下游关联 | 源单、目标单、转换关系 | 源单内码、源分录内码、目标单内码、目标分录内码 | 查下推断链、重复下推、数量反写异常 |
| 凭证 | 总账凭证头和分录 | 凭证号、期间、账簿、科目、辅助核算、过账状态 | 查业务单据是否入总账、凭证是否过账 |
| 核销 | 应收应付、收付款匹配关系 | 应收单、收款单、核销金额、核销日期 | 查客户或供应商余额、账龄和未核销差异 |
| 库存余额 | 即时库存或库存汇总 | 物料、仓库、库位、批号、库存状态、数量 | 查账实差异、负库存、待检库存 |
| 存货核算 | 出入库成本、成本调整、核算结果 | 入库成本、出库成本、成本期间、核算状态 | 查成本为 0、异常成本、库存金额和总账差异 |
| 接口日志 | 外部系统调用记录 | 接口名称、外部单号、请求报文、响应报文、状态 | 查重复单、失败重试、字段映射错误 |

## 二、常见字段口径

| 字段类型 | 查询时要问 |
| --- | --- |
| 日期 | 是业务日期、创建日期、审核日期、入账日期、凭证日期还是发票日期 |
| 组织 | 查的是业务组织、库存组织、核算组织、销售组织、采购组织还是结算组织 |
| 金额 | 是含税金额、不含税金额、税额、本位币金额、原币金额还是折扣后金额 |
| 数量 | 是业务单位、基本单位、库存单位、计价单位还是辅助单位 |
| 状态 | 暂存、提交、审核、关闭、作废、冻结、禁用要分开看 |
| 客商 | 客户、结算客户、收货客户、供应商、结算供应商不能混用 |
| 期间 | 财务期间、库存期间、成本期间、业务日期所在月可能不同 |
| 币别 | 外币单据要区分原币、本位币和汇率日期 |
| 来源 | 手工录入、接口导入、下推生成、系统生成、二开生成要区分 |

## 三、查询前固定参数

每次排查先写一段参数说明，避免 SQL 和业务口径脱节。

```text
产品/版本：
数据中心：
组织：
账簿：
期间：
币别：
单据类型：
单据状态：
业务日期范围：
前台报表：
用户反馈：
样例单号：
```

SQL 可以写成下面这种参数化结构，再按实际数据库语法调整：

```sql
-- 参数区，按实际数据库改写变量语法
-- :org_id       组织内码
-- :book_id      账簿内码
-- :date_from    开始日期
-- :date_to      结束日期
-- :bill_no      单据编号
-- :customer_id  客户内码
-- :supplier_id  供应商内码
-- :material_id  物料内码
```

## 四、单据状态查询包

### 1. 按单号查单据头和状态

适用：用户给出单据编号，先确认单据是否存在、是否审核、是否关闭。

```sql
select
  h.单据编号,
  h.单据日期,
  h.组织,
  h.单据类型,
  h.单据状态,
  h.审核状态,
  h.关闭状态,
  h.创建人,
  h.创建时间,
  h.审核人,
  h.审核时间
from 单据头表 h
where h.单据编号 = :bill_no;
```

检查：

- 前台单据编号和后台单据编号是否一致。
- 单据状态是否审核。
- 单据日期是否落在用户查询期间。
- 组织是否和前台过滤组织一致。

### 2. 查某期间未审核单据

适用：月末关账前找未审核入库、出库、应收、应付、费用等单据。

```sql
select
  h.组织,
  h.单据类型,
  h.单据编号,
  h.单据日期,
  h.单据状态,
  h.创建人,
  h.创建时间
from 单据头表 h
where h.单据日期 >= :date_from
  and h.单据日期 <  :date_to
  and h.组织 = :org_id
  and h.审核状态 <> '已审核'
order by h.单据日期, h.单据编号;
```

月结前建议按模块输出：采购入库、销售出库、其他出入库、应收、应付、费用报销、付款、收款、库存调整。

## 五、上下游断链查询包

### 1. 查源单是否生成下游

适用：采购订单下推不了入库、销售出库没生成应收、委外入库没生成应付。

```sql
select
  s.源单编号,
  s.源分录号,
  s.源单数量,
  s.已下推数量,
  t.目标单编号,
  t.目标分录号,
  t.目标单数量,
  t.目标单状态
from 源单分录表 s
left join 单据关联表 r
  on r.源分录内码 = s.分录内码
left join 目标单分录表 t
  on t.分录内码 = r.目标分录内码
where s.源单编号 = :bill_no
order by s.源分录号, t.目标单编号;
```

判断：

- 没有目标单：可能未下推、转换规则不适用、权限不足。
- 目标单未审核：可能已经生成但没有进入财务或库存。
- 已下推数量异常：查反写规则、关闭状态、退货或红字单据。

### 2. 查重复下推候选

适用：接口或手工重复生成下游单据。

```sql
select
  r.源分录内码,
  count(distinct r.目标单内码) as 目标单数,
  sum(t.目标单数量) as 目标数量合计
from 单据关联表 r
join 目标单分录表 t
  on t.分录内码 = r.目标分录内码
group by r.源分录内码
having count(distinct r.目标单内码) > 1;
```

这类结果必须回前台逐张确认。有些业务允许分批下推，不能只看到多张目标单就判断重复。

## 六、凭证生成查询包

### 1. 查业务单据是否生成凭证

适用：业务单据审核了，但总账没有金额。

```sql
select
  b.单据编号,
  b.单据日期,
  b.组织,
  b.单据金额,
  v.凭证号,
  v.凭证日期,
  v.账簿,
  v.凭证状态,
  v.过账状态
from 业务单据头表 b
left join 凭证生成记录表 g
  on g.源单内码 = b.单据内码
left join 凭证头表 v
  on v.凭证内码 = g.凭证内码
where b.单据编号 = :bill_no;
```

差异分类：

- 没有生成记录：凭证模板、生成条件或单据状态问题。
- 有凭证但未过账：总账余额不会体现。
- 凭证账簿不对：组织、账簿映射或生成方案错误。
- 凭证金额不对：模板取数、税额、折扣、币别或二开问题。

### 2. 查某期间未生成凭证的已审核业务单据

```sql
select
  b.组织,
  b.单据类型,
  b.单据编号,
  b.单据日期,
  b.单据金额
from 业务单据头表 b
left join 凭证生成记录表 g
  on g.源单内码 = b.单据内码
where b.单据日期 >= :date_from
  and b.单据日期 <  :date_to
  and b.审核状态 = '已审核'
  and g.凭证内码 is null
order by b.单据类型, b.单据日期;
```

常用于月结前输出“已审核未制证清单”。

## 七、应收应付查询包

### 1. 客户应收余额明细

```sql
select
  ar.组织,
  ar.客户,
  ar.结算客户,
  ar.单据编号,
  ar.业务日期,
  ar.应收金额,
  ar.已收金额,
  ar.已核销金额,
  ar.未核销金额,
  ar.到期日,
  ar.账龄天数
from 应收明细表 ar
where ar.组织 = :org_id
  and ar.客户 = :customer_id
  and ar.业务日期 < :date_to
order by ar.业务日期, ar.单据编号;
```

排查：

- 客户和结算客户是否混用。
- 红字应收是否参与核销。
- 收款单是否审核但未核销。
- 到期日和收款条件是否正确。

### 2. 供应商应付余额明细

```sql
select
  ap.组织,
  ap.供应商,
  ap.结算供应商,
  ap.单据编号,
  ap.业务日期,
  ap.应付金额,
  ap.已付金额,
  ap.已核销金额,
  ap.未核销金额,
  ap.来源单据
from 应付明细表 ap
where ap.组织 = :org_id
  and ap.供应商 = :supplier_id
  and ap.业务日期 < :date_to
order by ap.业务日期, ap.单据编号;
```

采购结算和委外加工费问题，先用这类明细固定供应商余额，再追采购入库、发票、暂估和付款。

## 八、库存和成本查询包

### 1. 即时库存按物料、仓库、批号查询

```sql
select
  inv.库存组织,
  inv.物料,
  inv.仓库,
  inv.库位,
  inv.批号,
  inv.库存状态,
  sum(inv.数量) as 即时数量
from 即时库存表 inv
where inv.库存组织 = :org_id
  and inv.物料 = :material_id
group by
  inv.库存组织,
  inv.物料,
  inv.仓库,
  inv.库位,
  inv.批号,
  inv.库存状态
order by inv.仓库, inv.批号;
```

不要只查物料总数。库存问题通常要拆到仓库、库位、批号、库存状态和货主。

### 2. 负库存候选

```sql
select
  inv.库存组织,
  inv.物料,
  inv.仓库,
  inv.批号,
  inv.库存状态,
  sum(inv.数量) as 即时数量
from 即时库存表 inv
group by
  inv.库存组织,
  inv.物料,
  inv.仓库,
  inv.批号,
  inv.库存状态
having sum(inv.数量) < 0
order by inv.库存组织, inv.物料, inv.仓库;
```

负库存要继续查出库时间、后入库时间、出库成本核算方式和库存关账期间。

### 3. 成本为 0 或异常成本候选

```sql
select
  c.核算组织,
  c.成本期间,
  c.单据编号,
  c.单据类型,
  c.物料,
  c.数量,
  c.成本金额,
  case
    when c.数量 <> 0 then c.成本金额 / c.数量
    else null
  end as 单位成本
from 存货核算明细表 c
where c.成本期间 = :period
  and c.核算组织 = :org_id
  and (
    c.成本金额 = 0
    or c.成本金额 is null
    or (c.数量 <> 0 and abs(c.成本金额 / c.数量) > :max_unit_cost)
  )
order by c.单据类型, c.单据编号;
```

常见原因：

- 入库成本未核算。
- 采购暂估价格为空。
- 负库存先出后入。
- 委外入库缺加工费。
- 成本调整单未审核或未生成凭证。

## 九、主数据质量查询包

### 1. 重复客户、供应商或物料候选

```sql
select
  m.名称,
  count(*) as 数量,
  min(m.编码) as 示例编码1,
  max(m.编码) as 示例编码2
from 基础资料表 m
where m.状态 <> '禁用'
group by m.名称
having count(*) > 1
order by count(*) desc, m.名称;
```

重复名称不一定是错，但要继续看统一社会信用代码、税号、规格型号、组织、使用状态和来源系统。

### 2. 禁用或失效基础资料仍被引用

```sql
select
  b.单据编号,
  b.单据日期,
  e.基础资料编码,
  e.基础资料名称,
  e.状态
from 单据分录表 b
join 基础资料表 e
  on e.内码 = b.基础资料内码
where b.单据日期 >= :date_from
  and e.状态 in ('禁用', '失效');
```

常用于解释为什么新单据保存失败、下推失败或接口导入失败。

## 十、接口和重复单查询包

### 1. 按外部业务号查导入记录

```sql
select
  l.接口名称,
  l.外部业务号,
  l.金蝶单据编号,
  l.请求时间,
  l.响应状态,
  l.错误信息,
  l.重试次数
from 接口日志表 l
where l.外部业务号 = :external_no
order by l.请求时间;
```

接口问题要把外部业务号、请求时间、响应状态和金蝶单据编号一起给出，不能只说“接口失败”。

### 2. 外部业务号重复生成单据

```sql
select
  l.外部业务号,
  count(distinct l.金蝶单据编号) as 单据数量,
  min(l.请求时间) as 首次请求,
  max(l.请求时间) as 最后请求
from 接口日志表 l
where l.请求时间 >= :date_from
  and l.请求时间 <  :date_to
group by l.外部业务号
having count(distinct l.金蝶单据编号) > 1
order by 单据数量 desc, 最后请求 desc;
```

如果发现重复，先冻结后续推送，再按外部业务号、接口幂等键、单据状态和下游流程判断保留哪一张。

## 十一、内部往来和合并查询包

### 1. 内部应收应付配对

```sql
select
  ar.公司 as 应收公司,
  ar.对方公司 as 应付公司,
  ar.币别,
  sum(ar.未核销金额) as 应收余额,
  sum(ap.未核销金额) as 对方应付余额,
  sum(ar.未核销金额) - sum(ap.未核销金额) as 差异
from 内部应收明细 ar
left join 内部应付明细 ap
  on ap.公司 = ar.对方公司
 and ap.对方公司 = ar.公司
 and ap.币别 = ar.币别
 and ap.期间 = ar.期间
where ar.期间 = :period
group by ar.公司, ar.对方公司, ar.币别
having abs(sum(ar.未核销金额) - sum(ap.未核销金额)) > :amount_tolerance;
```

继续拆分：

- 是否一方含税、一方不含税。
- 是否一方已入账、一方未暂估。
- 是否客商映射错。
- 是否跨期。
- 是否手工凭证影响内部往来。

## 十三、排查清单

- [ ] 是否先从前台拿到单据编号或报表条件。
- [ ] 是否写清组织、账簿、期间、币别、状态。
- [ ] 是否区分业务日期、审核日期、凭证日期和成本期间。
- [ ] 是否区分客户、结算客户、收货客户。
- [ ] 是否区分供应商、结算供应商。
- [ ] 是否区分含税金额、不含税金额、税额和本位币金额。
- [ ] 是否回前台标准报表验证汇总数。
- [ ] 是否抽样打开明细单据。
- [ ] 是否说明表名字段来自当前环境，不能跨版本照搬。
- [ ] 是否避免在生产环境执行修改类 SQL。
