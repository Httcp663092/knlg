供应链可以先理解成一句话：

```text
供应链负责把货买进来、管起来、卖出去，并把每一步变成可追踪的单据。
```

在金蝶里，供应链不是仓库一个部门的事。它会影响采购、销售、库存、成本、应收、应付、收入、毛利和月结。学供应链最好的方式不是背菜单，而是先看四条线：

| 线索 | 问题 | 金蝶里常见对象 |
| --- | --- | --- |
| 业务流 | 这笔业务走到哪一步了 | 订单、入库、出库、退货、盘点 |
| 实物流 | 货在哪里、状态是什么 | 仓库、库位、批号、库存状态 |
| 资金流 | 应收应付和收付款怎么样 | 应收、应付、收款、付款 |
| 成本流 | 货值多少钱、卖出成本是多少 | 存货核算、出库成本、价差、成本调整 |

## 一、供应链的四个基础模块

| 模块 | 管什么 | 新人先懂什么 |
| --- | --- | --- |
| 采购 | 从供应商买东西 | 申请、订单、收货、入库、到票、付款 |
| 销售 | 把东西卖给客户 | 报价、订单、发货、出库、开票、收款 |
| 库存 | 仓库里货怎么动 | 入库、出库、调拨、盘点、批号、库存状态 |
| 存货核算 | 库存金额怎么算 | 入库成本、出库成本、暂估、价差、关账 |

如果只看采购、销售、库存，不看存货核算，月底很容易出现“数量对，金额不对”。如果只看财务凭证，不看业务单据，又会不知道差异从哪里来。

## 二、先认识供应链基础资料

供应链的很多问题，其实不是单据问题，而是基础资料没维护好。

| 基础资料 | 通俗解释 | 常见影响 |
| --- | --- | --- |
| 物料 | 买卖和库存管理的对象 | 单据录入、库存、成本、BOM |
| 供应商 | 向谁买 | 采购订单、应付、付款、供应商对账 |
| 客户 | 卖给谁 | 销售订单、应收、收款、客户对账 |
| 仓库 | 货放在哪里 | 库存数量、出入库、权限 |
| 库位 | 仓库里的具体位置 | 精细化拣货、盘点 |
| 计量单位 | 个、箱、公斤、米等 | 数量换算、成本单价 |
| 批号 | 同一物料的批次 | 食品、医药、质量追溯 |
| 库存状态 | 可用、待检、冻结、报废等 | 是否能发货、是否能领用 |
| 价格资料 | 采购价、销售价 | 下单价格、毛利、价格审批 |

新人排查供应链问题时，可以先问：

1. 物料启用了吗？
2. 供应商或客户是否被禁用？
3. 物料是否分配到当前组织？
4. 仓库、库位、库存状态是否允许这类业务？
5. 单位换算是否正确？
6. 批号、保质期、序列号是否必录？
7. 价格和税率从哪里带出？

## 三、采购到付款通俗链路

采购链路可以用一句话概括：先决定买什么，再确认货到了，最后确认欠多少钱和付了多少钱。

```text
采购申请
  -> 采购订单
  -> 收料 / 采购入库
  -> 采购发票 / 应付单
  -> 付款单
  -> 付款核销
  -> 存货和总账
```

| 单据 | 业务含义 | 常见状态 |
| --- | --- | --- |
| 采购申请 | 内部部门提出需求 | 申请、审批、关闭 |
| 采购订单 | 对供应商的采购约定 | 下达、变更、关闭 |
| 收料通知 | 通知仓库准备收货 | 待收、部分收、已收 |
| 采购入库单 | 货正式进入库存 | 暂存、审核、反审核 |
| 采购发票 | 供应商到票 | 未结算、已结算 |
| 应付单 | 确认欠供应商多少钱 | 未付款、部分付款、已付款 |
| 付款单 | 付款动作 | 提交、审核、银行回写 |

### 新人容易混淆

| 混淆点 | 正确理解 |
| --- | --- |
| 下了采购订单就有库存 | 没有，只有入库才影响库存 |
| 货到了就一定有应付 | 不一定，看暂估和到票规则 |
| 付款了供应商余额就没了 | 还要看付款是否核销应付 |
| 发票金额和入库金额一定一样 | 不一定，可能有价差和费用分摊 |

## 四、销售到收款通俗链路

销售链路可以用一句话概括：先和客户约定卖什么，再把货发出去，最后确认客户欠款和回款。

```text
销售订单
  -> 发货通知
  -> 销售出库
  -> 应收单 / 销售发票
  -> 收款单
  -> 收款核销
  -> 收入、成本和总账
```

| 单据 | 业务含义 | 常见关注点 |
| --- | --- | --- |
| 销售订单 | 客户买什么、多少钱、什么时候要 | 价格、信用、交期 |
| 发货通知 | 通知仓库发货 | 是否满足库存和信用 |
| 销售出库单 | 货离开仓库 | 库存减少、成本结转 |
| 应收单 | 客户欠款确认 | 应收余额、账龄 |
| 销售发票 | 税务开票 | 销项税、红字发票 |
| 收款单 | 客户付款 | 银行、收款条件 |

### 新人容易混淆

| 混淆点 | 正确理解 |
| --- | --- |
| 销售订单就是收入 | 订单只是业务承诺 |
| 发货就一定开票 | 不一定，可能先发货后开票 |
| 收款就是收入 | 可能是预收款 |
| 销售金额就是毛利 | 毛利还要扣掉成本、折扣、退货和费用 |

## 五、库存怎么动

库存看起来只是数量，其实要同时看五个维度。

| 维度 | 例子 | 为什么重要 |
| --- | --- | --- |
| 物料 | A 零件 | 确认是什么货 |
| 仓库 | 原材料仓、成品仓 | 确认货在哪里 |
| 库位 | A01、B02 | 精细化定位 |
| 批号 | 202607-A | 质量和追溯 |
| 库存状态 | 可用、待检、冻结 | 决定能不能出库 |

常见库存动作：

| 动作 | 单据 | 说明 |
| --- | --- | --- |
| 买进来 | 采购入库 | 增加库存 |
| 卖出去 | 销售出库 | 减少库存 |
| 生产领用 | 生产领料 | 原材料减少 |
| 完工入库 | 生产入库 | 成品增加 |
| 仓库之间移动 | 调拨单 | 一个仓减少，另一个仓增加 |
| 盘点差异 | 盘盈盘亏 | 纠正账实差异 |
| 退货入库 | 销售退货 | 客户退回库存 |

## 六、库存数量和存货金额不是一回事

仓库最关心数量，财务最关心金额，管理层还关心周转和毛利。

```text
库存管理：有多少货，在哪个仓，能不能用
存货核算：这些货值多少钱，卖出去的成本是多少
总账：库存金额和财务账是否一致
```

| 问题 | 常见原因 |
| --- | --- |
| 库存数量对，金额不对 | 入库成本、暂估价、采购价差、费用分摊问题 |
| 出库有数量没成本 | 没有做存货核算或成本计算失败 |
| 存货和总账对不上 | 凭证未生成、凭证模板错、期间不一致 |
| 成本忽高忽低 | 负库存、异常入库价、计价方法影响 |

## 七、信用、价格、批号、盘点为什么重要

| 控制点 | 管什么 | 出问题会怎样 |
| --- | --- | --- |
| 价格控制 | 采购价、销售价、最低价、折扣 | 毛利失真、采购超价 |
| 信用控制 | 客户欠款额度和逾期 | 发货风险、坏账风险 |
| 批号保质期 | 每批货的质量和期限 | 发错批次、过期库存 |
| 盘点 | 账面库存和实物库存是否一致 | 库存不准、成本不准 |
| 暂估 | 货到票未到时先入账 | 应付、存货和价差不清 |

这些控制点看起来是供应链细节，但都会影响财务结果。比如信用控制不严，会形成逾期应收；批号不准，会影响召回追溯；采购暂估不准，会影响存货和利润。

## 八、供应链和财务怎么接起来

| 供应链动作 | 财务影响 |
| --- | --- |
| 采购入库 | 库存增加，可能形成暂估应付 |
| 采购发票 | 应付和进项税确认 |
| 付款核销 | 供应商欠款减少 |
| 销售出库 | 库存减少，成本结转 |
| 应收确认 | 客户欠款和收入确认 |
| 收款核销 | 客户欠款减少 |
| 库存盘亏 | 存货减少，可能形成损失 |
| 成本调整 | 存货金额和利润变化 |

所以供应链顾问不能只说“单据能走通”，还要能说明这条业务最终会不会影响应收、应付、库存金额、成本、毛利和总账。

## 九、常见状态怎么读

| 状态 | 通俗解释 | 排查提醒 |
| --- | --- | --- |
| 暂存 | 草稿，还没正式提交 | 通常不能作为正式业务结果 |
| 已提交 | 进入审批或待审核 | 看审批流和按钮权限 |
| 已审核 | 业务正式生效 | 通常影响下游或财务 |
| 已关闭 | 不再继续执行 | 看是否手工关闭或自动关闭 |
| 已下推 | 已生成下游单据 | 查源单和目标单关联 |
| 部分执行 | 只做了一部分 | 看未执行数量和反写 |
| 反审核 | 撤回审核状态 | 要看下游单据和月结期间 |

## 十、最适合新人练习的 5 条链路

| 练习 | 要追到哪里 |
| --- | --- |
| 采购订单到采购入库 | 看订单数量、入库数量、未入库数量 |
| 采购入库到应付和付款 | 看暂估、发票、应付、付款核销 |
| 销售订单到销售出库 | 看订单、发货、出库、未发数量 |
| 销售出库到应收和收款 | 看应收、发票、收款核销 |
| 库存单据到存货核算 | 看数量、金额、成本和总账凭证 |

每条链路都建议按这个格式记录：

```text
源单：
下游单据：
当前状态：
影响库存：
影响应收/应付：
影响成本：
是否生成凭证：
前台报表核对：
```

## 十一、常见误区

| 误区 | 正确理解 |
| --- | --- |
| 仓库有货就能发 | 还要看库存状态、批号、信用、锁库 |
| 单据保存就生效 | 很多业务要审核后才生效 |
| 下游单据为空就是系统错 | 可能源单状态、转换规则、未执行数量不满足 |
| 退货只要入库 | 还要处理质检、红字应收、发票、退款和成本冲回 |
| 库存数量对就可以月结 | 还要看存货金额、成本和总账 |
| 采购价差不重要 | 会影响存货成本、毛利和供应商对账 |
