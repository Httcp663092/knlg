供应链项目里，很多问题不是“不会录单”，而是价格、信用、批号、盘点、暂估这些控制点没有设计好。它们看起来分散，其实都在回答一个问题：

```text
业务能不能做，做了以后数量、金额、风险和财务结果是否可控。
```

这篇把几个常见缺口集中成一个专题，适合项目调研、蓝图设计、上线测试和月末排查使用。

## 一、供应链控制点总览

| 控制点 | 解决什么问题 | 影响 |
| --- | --- | --- |
| 采购价格 | 买贵了怎么办，价格从哪里来 | 采购成本、暂估、应付 |
| 销售价格 | 卖便宜了怎么办，折扣是否受控 | 收入、毛利、审批 |
| 信用管理 | 客户欠款太多还能不能发货 | 应收风险、发货控制 |
| 批号保质期 | 哪一批货从哪里来、到哪里去 | 追溯、先进先出、过期风险 |
| 盘点 | 系统库存和实物库存是否一致 | 库存数量、盘盈盘亏、成本 |
| 暂估应付 | 货到票未到时如何入账 | 存货、应付、月结 |

## 二、采购价格：不要让价格只停留在采购员手里

### 1. 常见取价方式

| 方式 | 适用场景 | 风险 |
| --- | --- | --- |
| 手工录价 | 低频采购、临时采购 | 容易录错，难以控制 |
| 采购价目表 | 常规物料、长期供应商 | 需要维护有效期和审批 |
| 合同价格 | 框架合同、年度协议 | 合同变更要同步系统 |
| 询比价结果 | 多供应商比价 | 要保留比价证据 |
| 历史价格 | 参考上次采购 | 市场波动时可能失真 |

### 2. 采购价格字段要看什么

| 字段 | 说明 |
| --- | --- |
| 供应商 | 不同供应商价格不同 |
| 物料 | 同名不同规格不能混价 |
| 采购组织 | 不同组织可能不同协议 |
| 币别 | 外币采购必须关注汇率 |
| 含税/不含税 | 影响应付和进项税 |
| 税率 | 税率变化会影响价税合计 |
| 有效期 | 防止旧价格继续使用 |
| 最小订货量 | 数量不同价格可能不同 |

### 3. 采购价格控制

建议至少做三层控制：

```text
价目表维护
  -> 价格审批
  -> 订单价格偏差预警
```

| 控制 | 示例 |
| --- | --- |
| 不允许无价下单 | 采购订单必须从有效价目表取价 |
| 超价审批 | 订单价高于价目表 5% 需要主管审批 |
| 低价提醒 | 价格异常低也要预警，防止单位或币别错误 |
| 价格变更留痕 | 记录原价、新价、原因、审批人 |

### 4. 采购价格问题排查

| 现象 | 先查什么 |
| --- | --- |
| 订单取不到价格 | 供应商、物料、组织、币别、有效期 |
| 价格和合同不一致 | 合同版本、价目表版本、取价优先级 |
| 入库金额不对 | 订单价、入库价、税率、暂估价 |
| 应付金额不对 | 发票价、税额、价税合计、折扣 |
| 成本异常 | 入库成本、暂估差异、成本调整 |

## 三、销售价格和信用：卖货要同时看利润和风险

### 1. 销售价格常见方式

| 方式 | 适用场景 |
| --- | --- |
| 销售价目表 | 标准报价、渠道价格 |
| 客户协议价 | 大客户、年度协议 |
| 折扣政策 | 促销、等级折扣 |
| 手工改价 | 特殊订单，必须审批 |
| 最低限价 | 防止低于成本或低于政策价 |

销售价格要同时看收入和毛利。便宜卖出去，订单能过，但利润可能已经没了。

### 2. 销售信用控制

信用管理解决的是“客户欠款太多，还能不能继续发货”。

常见信用口径：

```text
信用余额 = 信用额度 - 已占用信用
```

已占用信用可能包含：

- 未收款应收余额。
- 已发货未开票金额。
- 已下单未发货金额。
- 逾期未收款金额。

具体口径必须按企业信用政策确认。

### 3. 信用控制点

| 控制点 | 说明 |
| --- | --- |
| 下单控制 | 超信用不允许保存或提交订单 |
| 发货控制 | 超信用不允许出库 |
| 审批放行 | 特殊客户可走信用放行 |
| 逾期控制 | 有逾期款时禁止新增发货 |
| 临时额度 | 大促或项目临时放大额度 |

### 4. 销售价格和信用排查

| 现象 | 先查什么 |
| --- | --- |
| 销售订单不能提交 | 信用额度、价格审批、客户状态 |
| 明明有额度却提示超信用 | 信用占用口径、已下单未发货、逾期款 |
| 客户余额不准 | 应收单、收款核销、结算客户 |
| 价格取错 | 价目表、客户等级、币别、有效期 |
| 毛利异常低 | 销售价、折扣、出库成本、退货 |

## 四、批号和保质期：追溯不是事后才想起来

批号管理适合食品、医药、电子、化工、原材料等需要追溯的物料。保质期管理适合有过期风险的物料。

### 1. 批号从哪里来

| 来源 | 说明 |
| --- | --- |
| 供应商批号 | 供应商送货时提供 |
| 系统自动生成 | 按日期、供应商、流水号生成 |
| 生产批号 | 完工入库时生成 |
| 手工录入 | 特殊场景，风险较高 |

### 2. 批号必须贯穿的单据

```text
采购入库
  -> 库存调拨
  -> 生产领料
  -> 销售出库
  -> 退货
  -> 盘点
  -> 追溯查询
```

如果入库没有批号，后面出库、追溯、召回都会困难。

### 3. 保质期关注点

| 字段 | 用途 |
| --- | --- |
| 生产日期 | 计算有效期 |
| 有效期天数 | 计算到期日 |
| 到期日 | 出库和预警 |
| 近效期天数 | 提前预警 |
| 失效处理 | 冻结、报废、降级 |

### 4. 批号保质期问题排查

| 现象 | 先查什么 |
| --- | --- |
| 入库保存失败 | 物料是否启用批号/保质期，批号规则是否完整 |
| 出库找不到批号 | 仓库、库存状态、批号、可用量 |
| 系统有库存但不能发 | 批号过期、冻结、待检、被预留 |
| 追溯断链 | 中间单据是否丢了批号 |
| 近效期预警不准 | 生产日期、有效期、预警规则 |

## 五、盘点：把系统库存和实物库存重新对齐

盘点不是简单数一数，而是一次库存治理。

### 1. 盘点前

- 明确盘点范围：全仓、部分仓库、物料类别、批号。
- 冻结或控制盘点期间出入库。
- 处理未审核入库、出库、调拨单。
- 打印或下发盘点表。
- 明确盲盘还是带账盘点。

### 2. 盘点中

| 动作 | 说明 |
| --- | --- |
| 初盘 | 仓库第一次盘点 |
| 复盘 | 对差异或重点物料复核 |
| 抽盘 | 财务或审计抽查 |
| 差异确认 | 仓库、财务、业务共同确认 |

### 3. 盘点后

```text
盘点差异
  -> 差异原因分析
  -> 审批
  -> 盘盈盘亏单
  -> 成本处理
  -> 凭证
  -> 改进措施
```

### 4. 盘点差异原因

| 原因 | 示例 |
| --- | --- |
| 单据延迟 | 实物已出库，系统单据未审核 |
| 漏扫漏录 | 条码作业遗漏 |
| 批号错 | 物料对，总批号错 |
| 库位错 | 库存还在仓库，但位置不对 |
| 损耗报废 | 实物损坏但未及时处理 |
| 计量单位错 | 箱、件、公斤换算错误 |

### 5. 盘点和财务

盘盈盘亏最终会影响存货金额和损益。财务要关注：

- 差异是否审批。
- 差异是否有原因。
- 盘盈盘亏科目是否正确。
- 是否生成凭证。
- 是否影响成本和报表。

## 六、暂估应付：货到了，票没到，账怎么做

暂估应付是采购、仓库、财务三方交叉最多的地方。

### 1. 为什么要暂估

货已经入库，企业已经拥有库存或使用了材料，但供应商发票还没到。如果不暂估，月末存货和成本可能少记，应付也不完整。

```text
采购入库
  -> 暂估应付
  -> 暂估凭证
  -> 发票到达
  -> 冲暂估
  -> 正式应付
```

### 2. 暂估金额从哪里来

| 取价 | 说明 |
| --- | --- |
| 采购订单价 | 最常见，按约定价暂估 |
| 入库价 | 入库时确认的价格 |
| 最近采购价 | 没有订单价格时参考 |
| 标准成本 | 制造企业或成本管理场景 |
| 手工暂估价 | 临时处理，要有审批 |

### 3. 到票后的处理

| 情况 | 处理 |
| --- | --- |
| 发票价等于暂估价 | 冲暂估后形成正式应付 |
| 发票价高于暂估价 | 产生差异，调整存货或成本 |
| 发票价低于暂估价 | 冲减差异 |
| 部分到票 | 部分冲暂估，剩余继续挂账 |
| 长期未到票 | 输出长期暂估清单，采购跟进 |

### 4. 暂估问题排查

| 现象 | 先查什么 |
| --- | --- |
| 暂估没生成 | 入库单状态、暂估规则、供应商、价格 |
| 暂估金额不对 | 订单价、税率、币别、数量、折扣 |
| 发票到后没冲暂估 | 发票匹配、采购入库来源、期间 |
| 暂估长期挂账 | 未到票、匹配失败、冲回失败 |
| 存货和总账差异 | 暂估凭证、冲回凭证、成本调整 |

## 七、综合案例：从采购到月结

场景：6 月采购原材料 100 件，每件 50 元，税率 13%。6 月 28 日货到入库，发票 7 月 5 日才到。

### 6 月处理

1. 采购订单审核。
2. 采购入库单审核，库存数量增加。
3. 月末生成暂估应付。
4. 生成暂估凭证。
5. 存货和应付暂估进入 6 月报表。

### 7 月处理

1. 收到发票。
2. 生成正式应付。
3. 冲回 6 月暂估或按系统规则处理暂估差异。
4. 如果发票价格不同，确认差异处理。
5. 付款并核销。

### 检查表

| 检查 | 说明 |
| --- | --- |
| 入库数量 | 是否 100 件 |
| 暂估单 | 是否按 50 元暂估 |
| 发票金额 | 是否和暂估一致 |
| 暂估余额 | 7 月到票后是否清掉 |
| 凭证 | 暂估、冲回、正式应付是否完整 |

## 八、上线测试清单

- [ ] 采购价目表能按供应商、物料、组织、有效期取价。
- [ ] 采购订单超价能预警或审批。
- [ ] 销售价目表和客户协议价能正确带出。
- [ ] 销售订单超信用能被控制或审批放行。
- [ ] 批号物料采购入库、销售出库、退货、盘点能贯通。
- [ ] 保质期物料能计算到期日并预警。
- [ ] 盘点能生成差异并形成盘盈盘亏处理。
- [ ] 暂估应付能生成、到票能冲回。
- [ ] 价格、信用、批号、盘点、暂估都能生成必要报表或清单。
- [ ] 财务能从存货核算和总账验证金额。
