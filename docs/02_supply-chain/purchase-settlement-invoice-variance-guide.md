采购结算是采购业务从“货到了”走向“账确认、票匹配、款可付、成本可入账”的关键环节。很多企业采购流程看起来顺畅，月末却卡在暂估未冲回、发票价差、费用分摊、应付和总账不一致，根源往往就是采购结算口径没有打通。

这篇专题把采购入库、采购发票、应付单、暂估冲回、价差处理和付款对账放在一条线上讲。

## 一、完整闭环

```text
采购订单
  -> 收料 / 检验
  -> 采购入库
  -> 暂估入账
  -> 采购发票到达
  -> 采购结算 / 发票匹配
  -> 应付单确认
  -> 暂估冲回 / 价差调整 / 费用分摊
  -> 付款申请 / 付款单
  -> 应付核销
  -> 存货、应付、总账对账
```

采购结算要同时回答四个问题：

1. 货：入库数量和质量是否确认。
2. 票：发票数量、金额、税额是否和入库匹配。
3. 账：应付和暂估是否正确。
4. 成本：价差和采购费用最终进库存、成本还是损益。

## 二、关键对象

| 对象 | 作用 | 常见风险 |
| --- | --- | --- |
| 采购订单 | 采购合同和价格来源 | 订单价和发票价不一致 |
| 收料通知 / 检验单 | 到货和质量确认 | 检验未完成就入库或结算 |
| 采购入库单 | 库存增加和暂估依据 | 数量、仓库、批号、单价错误 |
| 采购发票 | 供应商开票依据 | 发票数量、税率、价税合计不一致 |
| 采购结算 | 入库和发票匹配 | 少结、多结、跨期结算 |
| 应付单 | 确认供应商债务 | 应付金额和发票或入库不一致 |
| 暂估应付 | 货到票未到的过渡 | 长期挂账、冲回失败 |
| 采购费用分配 | 运费、关税、保险等分摊 | 分摊对象错误，成本失真 |
| 付款单 | 实际付款 | 未核销导致供应商账龄不变 |
| 存货凭证 / 应付凭证 | 进入总账 | 模板取数错误、期间不一致 |

## 三、三种常见结算模式

| 模式 | 业务特点 | 管理重点 |
| --- | --- | --- |
| 货到票到 | 入库和发票基本同月 | 重点看发票匹配和应付确认 |
| 货到票未到 | 先入库，后到票 | 重点看暂估入账、后续冲回 |
| 票到货未到 | 发票先到，货后到 | 重点看是否允许提前确认应付或进项 |

多数制造和贸易企业都会遇到“货到票未到”。这时不要等发票才入账，否则库存已经增加但财务没有成本；也不能只做手工凭证，后续会和采购入库、应付、存货核算断开。

## 四、暂估处理

### 1. 入库暂估

```text
采购入库
  -> 按订单价、暂估价或历史价确认入库成本
  -> 生成暂估应付
  -> 存货金额进入存货核算
```

常见分录：

```text
借：原材料 / 库存商品
  贷：应付暂估
```

### 2. 发票到达

```text
采购发票
  -> 和采购入库匹配
  -> 确认正式应付和进项税
  -> 冲回暂估
  -> 处理价差
```

常见分录：

```text
借：应付暂估
借：原材料 / 库存商品 / 主营业务成本    （价差，可能借或贷）
借：应交税费-进项税额
  贷：应付账款-供应商
```

如果入库物料还在库存，价差通常调整存货成本；如果已经销售或领用，价差可能影响主营业务成本、生产成本或相关成本对象。

## 五、采购价差怎么判断

| 场景 | 例子 | 处理方向 |
| --- | --- | --- |
| 发票价高于暂估价 | 暂估 100，发票 105 | 增加存货或已出库成本 |
| 发票价低于暂估价 | 暂估 100，发票 96 | 冲减存货或已出库成本 |
| 发票税率不同 | 暂估按 13%，发票按 9% | 调整税额和不含税成本 |
| 数量差异 | 入库 100，发票 98 | 查短装、退货、折让或后续补票 |
| 费用后到 | 运费、保险、关税晚于入库 | 做采购费用分摊或成本调整 |
| 跨月到票 | 6 月入库，7 月发票 | 6 月暂估，7 月冲回和价差调整 |

不要把所有差异都扔进“管理费用”或“营业外”。差异跟采购物料直接相关时，优先判断是否应该进入存货成本或已售成本。

## 六、采购费用分配

采购费用包括运费、装卸费、保险费、关税、代理费等。它们是否进入存货成本，要看企业会计政策和费用性质。

常见分摊依据：

| 分摊依据 | 适用场景 | 风险 |
| --- | --- | --- |
| 按金额 | 运费和货值相关 | 高价低重物料承担更多费用 |
| 按数量 | 单位成本近似 | 价格差异大时不合理 |
| 按重量 / 体积 | 物流费用 | 需要维护重量体积 |
| 手工指定 | 特殊费用 | 依赖人工判断，需审批 |

检查点：

- 费用单据是否关联采购入库或发票。
- 分摊对象是否只包含应承担费用的物料。
- 税额是否可抵扣，是否进入成本。
- 分摊后是否重新核算存货成本。
- 已出库部分是否调整已售成本。

## 七、供应商对账

采购结算后还要和供应商对账。

对账口径：

```text
供应商送货 / 发票 / 付款记录
  vs
金蝶采购入库 / 应付单 / 付款单 / 核销记录
```

对账表建议字段：

| 字段 | 说明 |
| --- | --- |
| 供应商 | 债务对象 |
| 采购订单号 | 合同或订单依据 |
| 入库单号 | 收货依据 |
| 发票号 | 开票依据 |
| 应付单号 | 财务债务 |
| 入库数量 / 发票数量 | 判断是否少票、多票 |
| 不含税金额 / 税额 / 价税合计 | 对金额 |
| 已付金额 | 已付款 |
| 未付金额 | 应付余额 |
| 核销状态 | 付款是否冲应付 |
| 差异原因 | 未到票、价差、费用、退货、扣款 |

## 八、常见案例

### 案例 1：供应商发票到了，但暂估没有冲回

排查：

1. 发票是否录入或同步到金蝶。
2. 发票是否和采购入库单匹配。
3. 应付单是否审核。
4. 暂估冲回凭证是否生成。
5. 入库单和发票是否跨组织、跨币别或跨期间。

处理：

- 补做采购结算或发票匹配。
- 补生成应付和暂估冲回凭证。
- 输出暂估余额明细，确认该笔是否已清。

### 案例 2：应付余额和供应商对账单不一致

排查：

1. 供应商是否按发票口径对账，企业是否按入库口径对账。
2. 是否存在未到票暂估。
3. 付款单是否未核销。
4. 是否存在采购退货、扣款、折让。
5. 是否有同一集团供应商多个结算主体。

处理：

- 先统一对账口径：按入库、按发票还是按应付。
- 把暂估、已到票、已付款、未核销分列。
- 对集团供应商按结算供应商汇总。

### 案例 3：采购价差导致本月毛利异常

排查：

1. 哪些物料本月到票价差大。
2. 这些物料是否已经销售或领用。
3. 价差进入库存还是已售成本。
4. 是否存在跨月补发票集中冲回。

处理：

- 用物料收发存和发票价差清单解释毛利波动。
- 大额价差要求采购确认原因。
- 月结报告单独列示跨期到票影响。

### 案例 4：采购费用分配后库存成本异常

排查：

1. 分摊依据是否选错。
2. 是否把不该承担费用的物料纳入分摊。
3. 费用金额是否含税。
4. 是否重复分摊。
5. 分摊后是否生成成本调整凭证。

处理：

- 更正费用分配单。
- 重算存货成本。
- 补充费用分配审批和附件。

## 九、月末检查清单

- [ ] 本月采购入库全部审核。
- [ ] 未到票入库已经形成暂估。
- [ ] 采购发票全部录入或有未到票清单。
- [ ] 发票和入库匹配完成。
- [ ] 暂估冲回凭证生成并过账。
- [ ] 发票价差有处理口径。
- [ ] 采购费用分配完成并有依据。
- [ ] 应付单和采购发票金额一致或差异有说明。
- [ ] 付款单已核销，应付账龄正确。
- [ ] 暂估余额清单、供应商对账单已归档。
- [ ] 存货、应付、总账三方一致。

## 十、学习练习

1. 做一笔货到票未到采购：入库、暂估、月末凭证。
2. 下月录入采购发票：匹配入库、确认应付、暂估冲回。
3. 做一笔发票价差：判断差异进入库存还是已售成本。
4. 做一笔采购费用分摊：按金额或重量分配，观察物料成本变化。
5. 输出供应商对账单：分清入库未到票、已到票未付款、已付款未核销。

学会的标准：

- 能解释暂估不是错误，而是货票时间差的会计处理。
- 能从采购入库追到采购发票、应付单、付款单和凭证。
- 能判断采购价差影响库存、成本还是损益。
- 能用供应商对账表说清每一笔差异。
