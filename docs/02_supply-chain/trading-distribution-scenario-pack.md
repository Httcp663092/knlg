商贸和分销企业看起来只是“买进来、卖出去”，但系统落地时最容易乱在价格、信用、发货、回款、返利、渠道库存和对账。销售部门关心订单和客户，仓库关心能不能发货，财务关心应收和利润，老板关心毛利、周转和回款。金蝶项目要把这些口径串成一条能追溯的链。

一句话主线：

```text
客户分层和价格政策
  -> 销售订单和信用占用
  -> 库存可用量和发货
  -> 出库、开票、应收、回款
  -> 退货、折让、返利、费用
  -> 渠道库存和客户对账
  -> 毛利、周转、回款和风险分析
```

## 一、商贸分销最常见的业务形态

| 形态 | 业务特征 | 系统关注点 |
| --- | --- | --- |
| 批发贸易 | 大客户、大订单、价格谈判多 | 客户价格、信用额度、合同价、应收账龄 |
| 经销分销 | 多级渠道、区域保护、返利政策多 | 经销商层级、渠道价、返利、渠道库存 |
| 电商零售 | 订单量大、退换货多、平台对账复杂 | 订单接口、发货、退款、平台佣金 |
| 进口贸易 | 外币采购、关税、报关、在途时间长 | 外币、进口税费、在途库存、采购成本 |
| 备件耗材 | SKU 多、周转差异大、呆滞风险高 | 批号、库龄、补货、呆滞分析 |
| 项目供货 | 按项目交付、分批发货、验收回款 | 项目维度、合同履约、阶段收款 |

不要把所有商贸业务都按普通销售处理。分销行业的难点不在单张销售出库单，而在“价格为什么是这个、能不能赊销、货在哪、钱什么时候回来、返利怎么结、利润到底剩多少”。

## 二、主数据先分层

### 2.1 客户分层

| 维度 | 示例 | 用途 |
| --- | --- | --- |
| 客户类型 | 终端客户、经销商、代理商、电商平台、内部公司 | 价格、信用、返利、报表 |
| 客户等级 | A/B/C、战略客户、普通客户、黑名单 | 信用额度、审批流、价格权限 |
| 区域 | 华东、华南、海外、城市、省份 | 区域销售分析、渠道保护 |
| 行业 | 制造、医疗、教育、政府、零售 | 销售策略和毛利分析 |
| 回款方式 | 现款、月结、账期、预收、票据 | 信用控制和账龄 |
| 关联方 | 集团内部客户、外部客户 | 内部交易和合并抵消 |

关键建议：

1. 客户编码不要随便按销售员或区域重建，区域变化时会带来历史数据割裂。
2. 客户等级、账期、信用额度和价格政策要有审批，不要只靠销售口头通知。
3. 经销商和终端客户要分清，否则渠道库存、返利和客户贡献会混在一起。

### 2.2 物料和商品分层

| 维度 | 示例 | 用途 |
| --- | --- | --- |
| 品类 | 主机、配件、耗材、服务、赠品 | 毛利、库存周转、补货 |
| 品牌 | 自有品牌、代理品牌、进口品牌 | 价格政策和供应商返利 |
| 生命周期 | 新品、成熟品、清仓品、停产品 | 促销、呆滞、备货 |
| 批号管理 | 食品、医药、化工、电子批次 | 追溯、保质期、退货 |
| 库存策略 | 常备、按单采购、寄售、VMI | 补货和资金占用 |
| 价格属性 | 标准价、协议价、促销价、限价 | 销售价格控制 |

商贸企业最怕 SKU 越建越多，但品类、品牌、生命周期和库存策略没有维护。这样报表只能看到“卖了什么物料”，看不到“哪些商品赚钱、哪些商品压库、哪些商品该清仓”。

### 2.3 渠道和销售组织

| 对象 | 要表达什么 | 常见错误 |
| --- | --- | --- |
| 销售组织 | 哪个主体对外销售 | 销售组织和财务组织混乱 |
| 销售部门 | 哪个团队负责 | 只记销售员，不记部门 |
| 销售员 | 业绩归属和客户维护 | 离职后历史客户没人接 |
| 经销商层级 | 一级、二级、门店、服务站 | 返利和渠道库存无法归属 |
| 区域 | 省区、大区、城市 | 区域保护和窜货分析缺口 |
| 仓库 | 总仓、区域仓、门店仓、经销商仓 | 库存地点和所有权混淆 |

## 三、价格政策

商贸分销项目里，价格不是一个字段，而是一套规则。

### 3.1 常见价格类型

| 价格 | 说明 | 控制点 |
| --- | --- | --- |
| 标准价 | 面向普通客户的基准价格 | 定期维护，不能随意改历史 |
| 客户协议价 | 某客户或合同约定价格 | 生效日期、失效日期、审批 |
| 经销价 | 经销商采购价 | 渠道等级和区域 |
| 促销价 | 活动期间特价 | 活动编码、时间、库存限制 |
| 阶梯价 | 按数量或金额分档 | 数量区间和最小起订量 |
| 最低限价 | 销售不能低于的红线 | 超限价审批 |
| 内部转移价 | 集团内部销售价格 | 内部交易和管理利润 |

### 3.2 价格优先级

建议在蓝图阶段写清价格优先级，例如：

```text
客户协议价
  > 活动促销价
  > 经销商等级价
  > 区域价
  > 标准价
```

同时要写清例外：

- 低于最低限价时是否禁止保存、禁止审核，还是走特批。
- 赠品是否按 0 价出库，是否影响销售成本。
- 组合销售时主商品和赠品如何分摊收入。
- 退货时按原单价退，还是按当前价退。
- 返利是冲收入、记销售费用，还是生成应付。

### 3.3 价格风险清单

| 风险 | 表现 | 处理 |
| --- | --- | --- |
| 销售手工改价太自由 | 同一客户同一商品价格波动大 | 增加限价和改价审批 |
| 促销价未到期关闭 | 活动结束后仍按低价销售 | 维护生效/失效日期 |
| 协议价没有版本 | 客户争议无法追溯 | 保留价格版本和审批记录 |
| 返利口径不清 | 销售觉得有利润，财务扣完返利后亏损 | 订单阶段预估返利 |
| 赠品成本被忽略 | 毛利虚高 | 赠品出库纳入销售成本分析 |

## 四、信用控制和应收风险

商贸企业利润可能在订单上，现金却卡在应收里。信用控制要从销售订单阶段开始。

### 4.1 信用对象

| 对象 | 适用情况 |
| --- | --- |
| 客户信用 | 大多数 B2B 批发和经销业务 |
| 集团客户信用 | 一个集团多个法人统一授信 |
| 经销商信用 | 渠道商有账期、返利和担保 |
| 订单信用 | 大额项目订单单独控制 |
| 业务员信用责任 | 销售员负责催收和逾期说明 |

### 4.2 信用占用口径

| 占用项 | 是否建议纳入 | 说明 |
| --- | --- | --- |
| 未发货销售订单 | 视业务决定 | 防止接太多赊销订单 |
| 已发货未开票 | 建议纳入 | 实物已出，风险已发生 |
| 已开票未收款 | 必须纳入 | 应收核心风险 |
| 逾期应收 | 必须重点控制 | 需要限制新订单或发货 |
| 未核销收款 | 可抵减 | 要确认收款可用 |
| 应收票据 | 视票据风险 | 商票和银票风险不同 |

### 4.3 信用控制动作

| 场景 | 建议动作 |
| --- | --- |
| 超信用额度 | 禁止审核或走信用特批 |
| 逾期超过天数 | 禁止发货，要求财务确认 |
| 黑名单客户 | 禁止下单或禁止发货 |
| 临时提额 | 有金额、期限、审批人和原因 |
| 预收款客户 | 先收款后发货，订单占用预收 |
| 大客户长期账期 | 用账龄报表和催收计划跟踪 |

## 五、销售到收款主流程

```text
客户/价格/信用准备
  -> 销售报价
  -> 销售订单
  -> 信用检查
  -> 库存可用量检查
  -> 发货通知
  -> 销售出库
  -> 销售发票/应收确认
  -> 收款
  -> 核销
  -> 账龄和毛利分析
```

### 5.1 关键单据和控制点

| 环节 | 单据 | 控制点 |
| --- | --- | --- |
| 报价 | 报价单 | 价格来源、有效期、客户等级 |
| 下单 | 销售订单 | 客户、商品、价格、交期、信用 |
| 发货 | 发货通知/拣货单 | 可用量、批号、仓库、物流 |
| 出库 | 销售出库单 | 实物出库、成本、库存减少 |
| 开票 | 销售发票/应收单 | 收入、税额、应收 |
| 收款 | 收款单 | 银行流水、客户、币别 |
| 核销 | 核销记录 | 应收余额和账龄 |

### 5.2 常见断点

| 断点 | 后果 | 排查 |
| --- | --- | --- |
| 销售订单改价无审批 | 毛利失真 | 查价格来源和审批记录 |
| 出库后未开票 | 库存减少但收入/应收未确认 | 查已出库未开票清单 |
| 收款未核销 | 客户账龄虚高 | 查未核销收款 |
| 退货未红冲 | 应收和收入虚高 | 查退货入库、红字应收、红字发票 |
| 赠品未标识 | 毛利分析不准 | 查 0 价出库和促销活动 |

## 六、库存和发货

商贸分销的库存管理核心是“可卖库存”和“资金占用”。

### 6.1 可用量要扣哪些东西

| 项目 | 是否影响可用量 | 说明 |
| --- | --- | --- |
| 现存量 | 增加可用基础 | 当前仓库实物 |
| 已分配订单 | 减少可用 | 已承诺给客户 |
| 待检库存 | 通常不可用 | 质检未完成 |
| 冻结库存 | 不可用 | 盘点、质量、争议 |
| 在途采购 | 可做预计可用 | 要区分到货日期 |
| 寄售库存 | 看所有权 | 不一定可销售 |
| 服务站库存 | 看业务规则 | 可能只能售后使用 |

### 6.2 发货策略

| 策略 | 适用情况 | 风险 |
| --- | --- | --- |
| 先款后货 | 小客户、新客户、高风险客户 | 订单交付速度慢 |
| 信用发货 | 老客户和经销商 | 逾期风险 |
| 分批发货 | 库存不足或项目交付 | 对账复杂 |
| 先进先出 | 有批号、保质期或库龄要求 | 批号维护要准确 |
| 指定批号发货 | 医药、食品、客户指定 | 仓库执行要求高 |
| 区域仓发货 | 全国分销 | 调拨和库存平衡复杂 |

## 七、退货、折让和返利

### 7.1 退货分类

| 类型 | 业务含义 | 系统处理 |
| --- | --- | --- |
| 质量退货 | 商品有质量问题 | 退货申请、质检、退货入库、红冲 |
| 商务退货 | 客户取消、滞销、协议退货 | 审批、退货入库、红字应收 |
| 换货 | 退旧发新 | 退货和新销售要能关联 |
| 折让 | 不退货但降价 | 红字应收或折让单 |
| 退款 | 已收款后退客户 | 退款单和核销 |

### 7.2 返利类型

| 返利 | 计算依据 | 财务影响 |
| --- | --- | --- |
| 销量返利 | 销售数量或金额达标 | 冲收入或销售费用 |
| 回款返利 | 按及时回款奖励 | 应付返利或费用 |
| 陈列返利 | 渠道展示或促销支持 | 销售费用 |
| 价格保护 | 降价后补偿渠道库存 | 冲收入或补差 |
| 市场费用 | 广告、活动、推广 | 销售费用和预算 |

返利一定要有期间、客户、商品范围、计算口径和审批。否则年底财务会发现“销售毛利很好看，扣完返利才知道利润被吃掉了”。

### 7.3 返利闭环

```text
返利政策
  -> 销售订单/出库/回款数据
  -> 达成计算
  -> 经销商确认
  -> 返利审批
  -> 应付/费用/冲收入
  -> 后续核销或抵货款
```

## 八、渠道库存和经销商对账

分销业务如果只看到“总部已经卖给经销商”，看不到“经销商卖给终端多少、库存还压多少”，经营分析会滞后。

### 8.1 渠道库存要收什么

| 数据 | 用途 |
| --- | --- |
| 经销商期初库存 | 计算渠道库存变化 |
| 本期进货 | 总部销售给经销商 |
| 本期终端销售 | Sell-out 数据 |
| 本期退货 | 渠道退回总部或终端退货 |
| 期末库存 | 判断压货和补货 |
| 价格保护库存 | 降价补偿依据 |
| 批号/效期 | 食品、医药、备件追溯 |

### 8.2 经销商对账

| 对账项 | 金蝶侧 | 经销商侧 |
| --- | --- | --- |
| 发货数量 | 销售出库 | 收货确认 |
| 应收金额 | 应收单/发票 | 应付账款 |
| 收款金额 | 收款单 | 付款记录 |
| 返利金额 | 返利结算 | 返利确认 |
| 退货金额 | 退货入库/红字应收 | 退货申请 |
| 渠道库存 | 经销商库存上报 | 经销商库存台账 |

## 九、经营指标

商贸分销 BI 不要只看销售额。至少要同时看利润、回款、库存和渠道健康。

| 指标 | 公式思路 | 说明 |
| --- | --- | --- |
| 销售收入 | 已确认收入 | 和订单额区分 |
| 销售毛利 | 收入 - 销售成本 - 返利/折让影响 | 要考虑赠品和返利 |
| 毛利率 | 毛利 / 收入 | 按客户、商品、区域拆 |
| 回款率 | 回款金额 / 应收金额 | 按期间和客户 |
| 逾期应收 | 超账期未回款 | 信用风险核心 |
| 库存周转天数 | 平均库存 / 销售成本 * 天数 | 看资金占用 |
| 呆滞库存 | 超过周转阈值未动销 | 清仓和备货决策 |
| 订单满足率 | 按期足量发货订单 / 总订单 | 交付能力 |
| 渠道库存周转 | 经销商库存 / 终端销售 | 判断压货 |
| 退货率 | 退货金额 / 销售金额 | 质量和商务风险 |
| 价格偏离率 | 实际价与标准价差异 | 检查低价销售 |

## 十一、UAT 场景

| 场景 | 必测点 |
| --- | --- |
| 普通客户现款销售 | 下单、收款、发货、出库、应收核销 |
| 账期客户赊销 | 信用占用、发货、应收、账龄 |
| 超信用订单 | 禁止或特批流程 |
| 客户协议价销售 | 价格带出、审批、毛利 |
| 促销赠品 | 0 价出库、成本、毛利 |
| 分批发货 | 订单未完成数量、应收开票 |
| 销售退货 | 退货入库、红字应收、退款 |
| 折让不退货 | 折让单、红字应收、毛利影响 |
| 经销商返利 | 返利计算、确认、财务处理 |
| 渠道库存上报 | 进销存上报、渠道周转 |
| 逾期客户再下单 | 信用拦截和特批 |
| 低于限价销售 | 改价审批和原因留痕 |

## 十二、常见问题

| 问题 | 常见原因 | 处理 |
| --- | --- | --- |
| 销售额高但利润低 | 低价、返利、赠品、物流费未纳入 | 按客户和商品重算毛利 |
| 库存很多但订单发不了 | 库存被冻结、已分配、批号不符、区域仓不对 | 查可用量构成 |
| 客户说已付款但账龄还逾期 | 收款未核销或核销到错客户 | 查未核销收款和客户编码 |
| 经销商返利争议 | 政策版本、达成口径、退货扣减不清 | 固定返利政策和计算底稿 |
| 退货后应收没降 | 红字应收或退款未处理 | 串查退货、红冲、退款 |
| 渠道压货严重 | 只看 sell-in，不看 sell-out 和渠道库存 | 建经销商库存上报 |
| 毛利报表和财务不一致 | 订单口径、出库成本、返利口径不同 | 建指标字典和对账表 |
| 价格乱 | 协议价、促销价、手工改价无版本 | 建价格优先级和审批 |
