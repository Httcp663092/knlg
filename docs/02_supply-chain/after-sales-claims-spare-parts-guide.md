客户退货质检解决的是“货退回来后怎么判定和处理”。这篇继续补售后闭环：客户不一定退货，可能要求赔偿、免费维修、收费维修、寄送备件、现场服务、换新、延保或质量索赔。售后业务如果不进系统，销售说客户已经安抚，仓库说备件已经发出，财务却不知道该冲收入、确认维修收入、挂索赔还是计入售后成本。

这类业务最容易乱在三件事上：

- 售后动作和库存动作脱节：备件发出了，但没有售后单据、成本归集和客户确认。
- 售后责任和财务动作脱节：质量责任是企业、供应商、物流还是客户使用问题，没有形成扣款、索赔或费用。
- 保内保外口径不清：同样是维修，有的免费、有的收费、有的只收材料、有的只收工时，最后收入和成本都说不清。

## 一、完整售后主线

```text
客户反馈 / 客诉 / 售后申请
  -> 判断是否关联原销售、批号、序列号、质保期
  -> 售后受理和责任初判
  -> 处理方式：备件、维修、换货、赔偿、退货、退回客户
  -> 备件出库 / 维修工单 / 上门服务 / 供应商索赔
  -> 客户确认或服务结案
  -> 财务处理：免费成本、收费收入、折让、退款、索赔、扣款
  -> 售后成本分析和质量改进
```

不要把售后当成“销售退货的补充说明”。售后是独立闭环，至少要能追踪客户、产品、服务动作、实物、费用、收入和责任。

## 二、先分清八类售后场景

| 场景 | 是否退货 | 是否收费 | 常见单据或动作 | 财务影响 |
| --- | --- | --- | --- | --- |
| 保内免费维修 | 不一定 | 否 | 售后申请、维修工单、备件出库 | 售后成本或质量费用 |
| 保外收费维修 | 不一定 | 是 | 维修报价、应收、发票、备件出库 | 维修收入、备件成本 |
| 免费寄送备件 | 否 | 否 | 售后备件出库、客户签收 | 售后成本 |
| 收费销售备件 | 否 | 是 | 销售订单或售后收费单、出库、应收 | 备件销售收入和成本 |
| 质量赔偿 | 不一定 | 企业赔客户 | 赔偿申请、红字应收、退款或折让 | 冲收入、费用或赔款 |
| 供应商索赔 | 不一定 | 供应商赔企业 | 索赔单、扣款、应收供应商 | 赔偿收入或冲成本 |
| 物流索赔 | 不一定 | 物流赔企业或客户 | 物流异常、索赔资料 | 其他应收或费用冲减 |
| 延保服务 | 否 | 是 | 延保订单、合同、收入递延 | 服务收入或合同负债 |

项目上线时要把每类场景的“单据链、库存链、财务链、责任链”写清楚。否则售后会大量线下处理，最后只能靠 Excel 对账。

## 三、售后申请要记录什么

| 字段 | 用途 |
| --- | --- |
| 客户、结算客户、联系人 | 确认服务对象、收费对象和对账对象 |
| 原销售订单、出库单、发票 | 判断来源、价格、税率、销售日期和责任 |
| 产品、批号、序列号 | 追溯生产批次、质保期和唯一件 |
| 故障描述 | 判断质量问题、使用问题、运输问题还是安装问题 |
| 质保状态 | 决定保内免费、保外收费或特殊审批 |
| 处理方式 | 维修、备件、换货、赔偿、退货、拒保 |
| 责任归属 | 企业、客户、供应商、物流、安装服务商 |
| 费用项目 | 备件、人工、上门、运费、检测费、赔偿 |
| 附件 | 照片、检测报告、客户确认、物流单、聊天记录 |

售后申请不是越复杂越好，但必须能回答四个问题：为什么处理、谁负责、花了多少钱、客户是否确认。

## 四、保内和保外口径

### 1. 保内免费维修

```text
售后申请
  -> 核验质保期
  -> 维修工单
  -> 备件出库 / 维修工时
  -> 客户确认
  -> 售后成本归集
```

检查点：

- 是否在质保期内。
- 是否属于保修范围。
- 是否人为损坏、耗材损耗或外部原因。
- 备件是否按售后成本出库。
- 工时、差旅和物流费用是否归集。

保内免费不代表没有成本。备件、人工、物流和外协服务都要沉淀到售后成本或质量成本，后续才能分析产品质量和客户成本。

### 2. 保外收费维修

```text
售后申请
  -> 检测和报价
  -> 客户确认
  -> 维修工单
  -> 备件出库和服务完成
  -> 应收 / 发票 / 收款
  -> 维修收入和成本结转
```

检查点：

- 报价是否区分材料、工时、上门、运费和税额。
- 客户是否确认报价。
- 应收金额是否和报价一致。
- 发票项目是否和服务内容一致。
- 备件出库成本是否结转。
- 收款是否核销。

保外维修最怕“修了但没收费”。如果业务允许先修后收，要有信用控制或审批。

## 五、备件管理

售后备件既像库存物料，又像服务资源。常见管理方式：

| 方式 | 适用场景 | 风险 |
| --- | --- | --- |
| 作为普通物料管理 | 备件和销售件一致 | 免费售后和销售出库容易混在一起 |
| 单独备件仓 | 售后专用库存 | 需要调拨、盘点和安全库存 |
| 服务站寄存备件 | 外地服务网点 | 需要服务站库存对账 |
| 客户现场备件 | 大客户驻场服务 | 需要客户签收、消耗确认 |
| 供应商直发备件 | 原厂或供应商代发 | 需要物流回单和供应商结算 |

备件出库类型要区分：

- 免费保内备件出库。
- 保外收费备件销售。
- 换货备件出库。
- 试用或临时借件。
- 供应商责任替换件。
- 报废拆件再利用。

每种类型都要有不同的成本和收入处理口径。

## 六、索赔和扣款

### 1. 客户向企业索赔

常见原因：

- 产品质量问题导致客户停线。
- 延迟交付导致客户罚款。
- 错发、漏发、包装破损。
- 售后处理超时。
- 批量质量事故。

处理方式：

| 方式 | 财务影响 | 检查点 |
| --- | --- | --- |
| 现金赔偿 | 付款或其他应付 | 是否有客户确认和审批 |
| 应收冲抵 | 冲客户应收 | 是否影响账龄和核销 |
| 销售折让 | 红字应收或折让单 | 是否需要红字发票 |
| 免费备件 | 售后成本 | 是否有备件出库和客户签收 |
| 延保或服务补偿 | 服务义务 | 是否形成后续履约责任 |

### 2. 企业向供应商索赔

```text
客户投诉 / 售后问题
  -> 质量判定为供应商责任
  -> 供应商索赔申请
  -> 供应商确认
  -> 扣款、红字应付、赔偿收入或补发备件
  -> 供应商绩效记录
```

检查点：

- 是否能追溯到采购批次或供应商。
- 是否有检测报告和不良照片。
- 是否有供应商确认或合同条款。
- 扣款是否进入应付对账。
- 供应商赔偿是否冲成本、计收入还是挂其他应收。

不要只在采购群里说“供应商认了”。系统里要有索赔单、扣款单、红字应付或其他可对账证据。

## 七、售后收入和成本

| 业务 | 收入 | 成本 |
| --- | --- | --- |
| 保内免费维修 | 无收入 | 备件、人工、外协、运费进入售后成本或质量成本 |
| 保外收费维修 | 维修收入或服务收入 | 备件成本、人工、外协、运费 |
| 收费备件销售 | 商品销售收入或备件收入 | 备件出库成本 |
| 延保服务 | 可能递延确认服务收入 | 后续服务成本 |
| 赔偿客户 | 冲收入、费用或营业外支出，按财务政策确认 | 相关备件或退款成本 |
| 供应商索赔 | 冲减采购成本、质量成本或确认赔偿收入 | 与原质量问题关联 |

会计科目要由财务确认。实施时至少要明确：

- 免费售后成本进销售费用、质量成本还是制造费用。
- 收费维修收入进主营业务收入、其他业务收入还是服务收入。
- 备件销售是否和普通销售同税率。
- 赔偿和索赔是否需要发票或红字发票。
- 延保是否需要按服务期分期确认。

## 八、对账表

售后业务建议固定四张对账表。

| 对账表 | 核对内容 |
| --- | --- |
| 售后工单台账 | 客户、产品、问题、处理方式、状态、责任、结案日期 |
| 备件出库对账 | 备件申请、出库单、客户签收、成本金额 |
| 售后收费对账 | 报价、应收、发票、收款、核销 |
| 索赔扣款对账 | 客户赔偿、供应商索赔、物流索赔、扣款和付款 |

月末要看：

- 已结案未出库。
- 已出库未签收。
- 已收费维修未开票。
- 已开票未收款。
- 已确认供应商责任未扣款。
- 已赔偿客户但未形成审批或财务处理。

## 九、典型案例

### 案例 1：售后免费发备件，库存少了但成本没归集

现象：

- 客户收到免费备件。
- 仓库做了其他出库。
- 财务不知道这笔成本属于哪个客户、哪个产品、哪个质量问题。

排查：

1. 查是否有售后申请或 RMA。
2. 查备件出库是否关联客户和售后单。
3. 查出库类型是销售、其他出库还是售后出库。
4. 查成本是否进入售后成本或质量成本。
5. 查客户是否签收。

处理：

- 补售后单据关联。
- 调整出库类型或成本归集维度。
- 后续免费备件必须由售后申请触发，不能线下领料。

### 案例 2：保外维修已经完成，但应收没有形成

现象：

- 服务人员完成维修。
- 客户确认了报价。
- 财务应收没有记录，客户也没有付款。

排查：

1. 查售后工单是否标记保外收费。
2. 查维修报价是否审核。
3. 查是否生成应收或销售服务单。
4. 查发票是否开具。
5. 查收款是否核销。

处理：

- 补生成维修应收。
- 若先修后收，建立保外维修信用或审批控制。
- 售后结案前检查“收费项目是否已进入应收”。

### 案例 3：供应商责任已确认，但一直没有扣款

现象：

- 质量部门确认来料问题导致客户投诉。
- 企业免费给客户换件。
- 供应商责任没有进入应付扣款。

排查：

1. 查质量判定是否写明供应商责任。
2. 查是否有供应商索赔申请。
3. 查是否有关联采购批次和供应商。
4. 查应付对账是否包含扣款。
5. 查供应商是否已确认索赔金额。

处理：

- 补供应商索赔单或扣款单。
- 在供应商对账时冲减应付或形成其他应收。
- 后续质量判定为供应商责任时，自动推送采购或应付处理。

### 案例 4：客户赔偿冲了应收，但账龄还是异常

现象：

- 客户投诉后，销售承诺赔偿并抵扣货款。
- 财务做了红字应收或折让。
- 客户账龄仍显示逾期。

排查：

1. 查红字应收是否和原应收核销。
2. 查赔偿对象是否和原结算客户一致。
3. 查币别和组织是否一致。
4. 查是否只是做了手工凭证，没有进入应收模块。
5. 查客户对账单是否能解释抵扣关系。

处理：

- 在应收模块完成核销或冲抵。
- 不要只做总账手工凭证。
- 输出客户对账单给销售和客户确认。

## 十、实施和上线检查清单

- [ ] 售后申请能关联客户、原销售、物料、批号、序列号和质保期。
- [ ] 售后类型能区分保内免费、保外收费、免费备件、收费备件、赔偿、索赔和延保。
- [ ] 备件出库能关联售后单，并能区分免费和收费。
- [ ] 售后备件仓、服务站库存、客户现场备件有对账机制。
- [ ] 维修工单能记录材料、工时、外协、运费和服务人员。
- [ ] 保外维修能生成应收、发票和收款核销。
- [ ] 客户赔偿能形成审批、红字应收、退款或应收冲抵。
- [ ] 供应商责任能形成索赔、扣款、红字应付或其他应收。
- [ ] 售后成本能按客户、产品、原因、责任和批次分析。
- [ ] 售后结案前检查实物、财务、客户确认和责任处理是否闭环。
