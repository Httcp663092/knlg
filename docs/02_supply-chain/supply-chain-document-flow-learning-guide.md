供应链学习最怕一上来背菜单。更好的办法是先抓住一句话：

```text
供应链管“货怎么流动”，财务管“货和钱怎么入账”，金蝶把两件事用单据串起来。
```

这篇用通俗语言讲采购、销售、库存、存货核算和财务衔接。适合供应链新人、仓库人员、采购销售人员、财务成本会计、实施顾问一起学习。目标不是只会点按钮，而是能知道每张单据为什么存在、下一张单据从哪里来、出了差异先查哪里。

## 一、先看懂供应链的四条流

| 流 | 通俗解释 | 金蝶里常见表现 |
| --- | --- | --- |
| 业务流 | 谁向谁买，谁向谁卖，流程走到哪一步 | 采购订单、销售订单、审批状态 |
| 物流 | 货从哪里进、从哪里出、放在哪个仓库 | 入库单、出库单、调拨单、即时库存 |
| 资金流 | 什么时候该收钱、该付款 | 应收单、应付单、收款单、付款单 |
| 财务流 | 最后怎么形成凭证和报表 | 凭证模板、生成凭证、总账、存货核算 |

学习供应链时不要只看“库存数量”。一个完整问题通常要同时看：

```text
订单有没有
  -> 货有没有进出
  -> 应收应付有没有形成
  -> 成本有没有核算
  -> 凭证有没有生成
```

## 二、单据流入门：每张单据问 6 个问题

看到任何一张供应链单据，先问：

1. 这张单据是谁发起的？
2. 这张单据从哪张上游单据下推来？
3. 它会不会改变库存数量？
4. 它会不会影响应收、应付或成本？
5. 它审核后会生成什么下游单据？
6. 如果要反审核或删除，会影响哪些后续单据？

### 常见单据速查

| 单据 | 通俗解释 | 是否影响库存 | 是否影响财务 |
| --- | --- | --- | --- |
| 采购申请 | 内部部门提出购买需求 | 不直接影响 | 不直接影响 |
| 采购订单 | 公司确认向供应商买什么 | 不直接影响 | 后续影响应付和存货 |
| 采购入库单 | 仓库确认货进来了 | 影响库存数量 | 后续影响存货和应付 |
| 销售订单 | 客户确认要买什么 | 不直接影响 | 后续影响应收和收入 |
| 销售出库单 | 仓库确认货发出去了 | 影响库存数量 | 后续影响应收、收入、成本 |
| 调拨单 | 货从一个仓库或组织转到另一个仓库或组织 | 影响库存位置 | 可能影响内部结算 |
| 盘点单 | 盘实物库存和系统库存差异 | 影响库存数量 | 可能形成盘盈盘亏 |
| 应收单 | 财务确认客户欠款 | 不影响库存 | 影响客户往来 |
| 应付单 | 财务确认欠供应商款 | 不影响库存 | 影响供应商往来 |

## 三、采购到付款：从“我要买”到“我付钱”

### 1. 标准单据流

```text
采购申请
  -> 采购订单
  -> 到货/收料
  -> 采购入库
  -> 应付单
  -> 付款单
  -> 应付核销
  -> 凭证
```

可以把它理解成：

```text
提出需求
  -> 跟供应商约定
  -> 仓库收货
  -> 财务确认欠款
  -> 出纳付款
  -> 财务把欠款冲掉
```

### 2. 每一步学什么

| 步骤 | 学习重点 | 常见错误 |
| --- | --- | --- |
| 采购申请 | 谁要买、为什么买、预算或审批 | 需求不清，后续订单频繁改 |
| 采购订单 | 供应商、价格、税率、交期、付款条件 | 价格或税率错，后续应付错 |
| 到货/收料 | 到了多少，是否需要质检 | 到货不等于入库 |
| 采购入库 | 仓库、批号、数量、实收 | 仓库错、批号漏、超收不受控 |
| 应付单 | 供应商、金额、税额、结算口径 | 入库和发票口径不一致 |
| 付款单 | 付款账户、金额、付款用途 | 付了款但没核销 |
| 核销 | 付款和应付匹配 | 账龄仍挂账 |

### 3. 采购学习案例

案例：采购 10 件物料，每件 100 元，税率 13%，供应商送货 10 件，发票后到。

学习时按下面顺序记录：

| 问题 | 你要查的地方 | 说明 |
| --- | --- | --- |
| 订单是否有效 | 采购订单 | 是否审核，价格税率是否正确 |
| 货是否进仓库 | 采购入库单、即时库存 | 仓库和数量是否正确 |
| 是否需要暂估 | 应付或暂估应付 | 货到票未到时月末怎么处理 |
| 发票到后怎么处理 | 应付单、发票匹配 | 正式应付金额是否正确 |
| 付款后余额是否减少 | 付款单、核销记录、供应商余额 | 核销是否完成 |
| 总账有没有记录 | 凭证生成情况、科目余额 | 存货、进项税、应付、银行 |

### 4. 采购常见问题

| 现象 | 通俗解释 | 先查什么 |
| --- | --- | --- |
| 采购订单不能下推入库 | 上游条件不满足 | 订单状态、关闭状态、剩余数量、权限 |
| 入库数量不对 | 收货和系统录入不一致 | 实收数量、计量单位、换算率 |
| 即时库存没增加 | 入库没有正式生效 | 入库单审核状态、库存组织、仓库 |
| 应付生成不了 | 财务确认规则没满足 | 入库单状态、供应商、结算组织、发票口径 |
| 应付金额和订单不同 | 价格、税率或发票差异 | 采购价、税率、折扣、暂估 |
| 付款后还有余额 | 没核销或核销错对象 | 付款单核销状态、应付单余额 |

## 四、销售到收款：从“客户要买”到“客户付款”

### 1. 标准单据流

```text
销售订单
  -> 发货通知
  -> 销售出库
  -> 应收单
  -> 收款单
  -> 应收核销
  -> 凭证
```

可以把它理解成：

```text
客户下单
  -> 公司安排发货
  -> 仓库发出商品
  -> 财务确认客户欠款
  -> 客户打款
  -> 财务把欠款冲掉
```

### 2. 每一步学什么

| 步骤 | 学习重点 | 常见错误 |
| --- | --- | --- |
| 销售订单 | 客户、结算客户、价格、信用、交期 | 客户和结算客户混淆 |
| 发货通知 | 发货计划、仓库准备 | 通知发货不等于库存减少 |
| 销售出库 | 仓库、批号、可用库存、实际出库 | 超库存、批号错、仓库错 |
| 应收单 | 收入确认口径、税率、客户余额 | 出库了但未形成应收 |
| 收款单 | 到账账户、客户、金额 | 收款客户和应收客户不一致 |
| 核销 | 收款对应哪笔应收 | 收款挂预收或未核销 |

### 3. 销售学习案例

案例：卖给客户 5 件商品，每件 200 元，税率 13%，客户先发货后付款。

记录下面这些东西：

| 问题 | 查哪里 | 学到什么 |
| --- | --- | --- |
| 订单是否通过 | 销售订单 | 价格、信用、交期、审批 |
| 库存是否够 | 即时库存、可用量 | 发货前要检查可用库存 |
| 货是否发出 | 销售出库单 | 出库后库存数量减少 |
| 客户是否欠款 | 应收单、客户余额 | 应收不是库存单，而是财务确认 |
| 客户是否付款 | 收款单、银行日记账 | 收到钱后银行增加 |
| 欠款是否冲掉 | 核销记录、账龄 | 不核销就可能一直显示逾期 |
| 成本是否结转 | 存货核算、成本凭证 | 卖货不只看收入，还要看成本 |

### 4. 销售常见问题

| 现象 | 通俗解释 | 先查什么 |
| --- | --- | --- |
| 销售订单不能下推出库 | 订单不可执行 | 审核状态、关闭状态、剩余数量、信用控制 |
| 出库失败提示库存不足 | 系统可用库存不够 | 仓库、批号、库存状态、预留 |
| 出库了但客户余额没增加 | 应收还没形成 | 应收生成规则、发票或出库来源 |
| 收款后客户账龄没变 | 收款未核销 | 收款单用途、核销记录 |
| 退货后库存回来了但应收没冲 | 物流和财务没有联动完整 | 退货单、红字应收、退款单 |
| 收入和成本不匹配 | 成本结转没完成或口径不同 | 存货核算、出库成本、期间 |

## 五、库存管理：仓库每天要盯什么

### 1. 库存不是一个数字

库存至少要看 7 个维度：

| 维度 | 说明 |
| --- | --- |
| 物料 | 是什么东西 |
| 仓库 | 放在哪里 |
| 库位 | 仓库里的具体位置 |
| 批号 | 哪一批 |
| 库存状态 | 可用、冻结、待检、不合格 |
| 组织 | 属于哪个库存组织 |
| 数量和单位 | 件、箱、公斤等，注意换算 |

### 2. 仓库日常单据

| 单据 | 通俗解释 | 学习重点 |
| --- | --- | --- |
| 采购入库 | 采购货物进仓 | 收货数量、批号、仓库 |
| 销售出库 | 商品发给客户 | 可用库存、批号、出库数量 |
| 其他入库 | 非采购来源入库 | 入库原因、成本口径 |
| 其他出库 | 非销售用途出库 | 用途、部门、成本承担 |
| 调拨单 | 仓库之间转移 | 调出仓、调入仓、在途 |
| 盘点单 | 盘实物和系统差异 | 盘盈、盘亏、审批 |
| 组装/拆卸 | 套件或组合物料处理 | 子件、父件、成本 |

### 3. 库存常见问题

| 现象 | 通俗解释 | 先查什么 |
| --- | --- | --- |
| 账上有库存但不能出库 | 不是可用库存 | 库存状态、冻结、预留、批号 |
| 仓库数量和实物不同 | 系统记录和现场不一致 | 未审核单据、漏扫、盘点差异 |
| 批号找不到 | 批次规则或录入错误 | 入库批号、出库批号、保质期 |
| 调拨后库存少了 | 在途或单据未完成 | 调出、调入、在途状态 |
| 盘点差异大 | 日常出入库不及时 | 未审核单据、手工账、条码流程 |
| 负库存 | 先出后入或日期错 | 单据日期、仓库、批号、系统参数 |

## 六、存货核算：从数量走向金额

仓库关心“有多少件”，财务还要知道“值多少钱”。这就是存货核算要解决的问题。

```text
入库数量和金额
  -> 出库数量
  -> 出库成本
  -> 存货余额
  -> 成本凭证
```

### 1. 存货核算看什么

| 对象 | 通俗解释 |
| --- | --- |
| 入库成本 | 货进来时按多少钱入账 |
| 出库成本 | 货发出去时成本是多少 |
| 计价方法 | 先进先出、加权平均、移动平均等口径 |
| 成本调整 | 发票差异、暂估差异、盘点差异等调整 |
| 存货收发存 | 一段期间库存金额的增加、减少和余额 |

### 2. 学习存货核算的简单例子

1. 第一次采购入库 10 件，每件 100 元。
2. 第二次采购入库 10 件，每件 120 元。
3. 销售出库 5 件。

如果按不同计价方法，出库成本可能不同。学习时不用先背公式，先理解：

- 入库价格会影响库存价值。
- 出库成本不是销售价格。
- 成本口径决定利润。
- 存货核算没完成，利润表成本可能不准。

### 3. 存货核算常见问题

| 现象 | 通俗解释 | 先查什么 |
| --- | --- | --- |
| 出库成本为 0 | 系统没找到成本 | 入库成本、计价方法、核算顺序 |
| 存货金额和总账不一致 | 业务账和总账断开 | 成本凭证、手工凭证、期间 |
| 暂估差异很大 | 入库估价和发票价格差异 | 暂估单、发票匹配、成本调整 |
| 盘点后金额异常 | 数量差异影响金额 | 盘盈盘亏单、成本调整 |
| 月末不能关账 | 业务单据或核算未完成 | 未审核单据、未核算单据、负库存 |

## 七、供应链和财务怎么对账

### 1. 采购链路对账

| 对账对象 | 应该对上什么 |
| --- | --- |
| 采购入库 | 仓库库存数量 |
| 采购入库金额 | 存货核算入库金额 |
| 应付单 | 供应商往来余额 |
| 付款单 | 银行流水和付款凭证 |
| 应付模块余额 | 总账应付账款科目余额 |

### 2. 销售链路对账

| 对账对象 | 应该对上什么 |
| --- | --- |
| 销售出库 | 库存减少数量 |
| 应收单 | 客户往来余额 |
| 收款单 | 银行流水和收款凭证 |
| 出库成本 | 主营业务成本凭证 |
| 应收模块余额 | 总账应收账款科目余额 |

### 3. 库存和总账对账

```text
即时库存数量
  -> 库存台账数量
  -> 存货收发存金额
  -> 总账存货科目余额
```

如果对不上，按顺序查：

1. 是否有未审核库存单据。
2. 是否有单据日期跨期。
3. 是否存在负库存或异常批号。
4. 是否完成入库核算和出库核算。
5. 是否生成成本凭证。
6. 是否有人手工做了存货科目凭证。

## 八、给供应链新人的 10 天学习计划

| 天数 | 主题 | 动手任务 | 学会什么 |
| --- | --- | --- | --- |
| 第 1 天 | 单据流总览 | 画采购、销售、库存、财务四条流 | 知道每张单据为什么存在 |
| 第 2 天 | 物料和仓库 | 建物料、仓库、批号规则 | 理解库存维度 |
| 第 3 天 | 采购订单 | 做采购订单和采购入库 | 理解采购到入库 |
| 第 4 天 | 应付和付款 | 从入库生成应付和付款 | 理解采购到付款 |
| 第 5 天 | 销售订单 | 做销售订单和出库 | 理解销售到出库 |
| 第 6 天 | 应收和收款 | 从出库生成应收和收款 | 理解销售到收款 |
| 第 7 天 | 库存单据 | 做调拨、其他出入库、盘点 | 理解仓库日常 |
| 第 8 天 | 存货核算 | 做入库核算、出库核算 | 理解数量到金额 |
| 第 9 天 | 对账 | 对库存、应收、应付和总账 | 理解差异来源 |
| 第 10 天 | 问题复盘 | 写 3 个问题处理案例 | 形成排查能力 |

## 九、练习题

### 练习 1：采购入库后为什么应付没有生成

按顺序查：

1. 采购入库单是否审核。
2. 入库单供应商、结算组织是否完整。
3. 是否要求发票到达后才生成应付。
4. 是否已生成过应付。
5. 当前用户是否有生成权限。
6. 单据日期和期间是否允许。

把结果写成：

```text
现象：
涉及单据：
已查证据：
根因：
处理：
预防：
```

### 练习 2：销售出库后为什么客户余额没有增加

按顺序查：

1. 销售出库单是否审核。
2. 企业收入确认口径是出库、发票、签收还是其他。
3. 应收单是否已生成。
4. 应收单客户和结算客户是否正确。
5. 应收单是否生成凭证。
6. 查询期间是否正确。

### 练习 3：仓库说有货，系统说不能出库

按顺序查：

1. 是否在同一个仓库。
2. 是否同一个批号。
3. 库存状态是否可用。
4. 是否被销售订单、生产订单或调拨预留。
5. 是否有未审核入库单。
6. 是否单位换算导致数量不够。

### 练习 4：存货和总账对不上

按顺序查：

1. 存货核算期间和总账期间是否一致。
2. 是否有未生成凭证的存货单据。
3. 是否有手工凭证进了存货科目。
4. 是否有成本调整未入账。
5. 是否新增物料或科目没有配置完整。
6. 是否按组织、仓库、物料过滤口径不一致。

## 十、供应链学习口诀

```text
先看订单，确定业务来源；
再看入库出库，确定货物流动；
再看应收应付，确定债权债务；
再看核销收付，确定钱是否结清；
再看存货核算，确定成本金额；
最后看凭证报表，确定财务入账。
```

## 十一、检查清单

- [ ] 能说清采购订单、采购入库、应付单、付款单之间的关系。
- [ ] 能说清销售订单、销售出库、应收单、收款单之间的关系。
- [ ] 能解释库存数量、可用库存、库存状态、批号的区别。
- [ ] 能解释库存数量和存货金额为什么不是同一件事。
- [ ] 能从一张入库单追到应付和凭证。
- [ ] 能从一张出库单追到应收、成本和凭证。
- [ ] 能排查“不能下推、不能出库、不能生成应收应付”的常见原因。
- [ ] 能做一份供应链月结前检查表。
