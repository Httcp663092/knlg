库存管理回答“东西有多少”，存货核算回答“这些东西值多少钱”。库存数量错，业务发不出去；存货金额错，财务报表、毛利、成本和税务都会被带歪。

金蝶项目里，月结最常见的卡点之一就是：库存单据都做了，但成本不对；存货报表有数，总账没有数；总账有手工凭证，业务账对不上；出库成本为 0；发票到票后暂估没冲；库存关账关不上。

这篇专题把存货成本差异、异常成本和库存关账放在一条线上讲。

## 一、先看完整闭环

```text
库存单据审核
  -> 检查负库存、无价入库、异常单据
  -> 入库成本确认
  -> 出库成本核算
  -> 暂估冲回、发票价差、费用分摊
  -> 成本调整
  -> 生成存货凭证
  -> 存货报表和总账对账
  -> 库存关账 / 存货关账
```

一个健康的月末存货流程，要能回答 5 个问题：

1. 数量：库存数量是否和库存明细账一致。
2. 单价：入库、出库、退货、调整的成本是否有来源。
3. 金额：存货核算余额是否等于存货报表。
4. 凭证：存货业务是否全部生成凭证并过账。
5. 期间：库存期间、存货期间、总账期间是否一致。

## 二、关键对象

| 对象 | 作用 | 常见风险 |
| --- | --- | --- |
| 库存组织 | 管库存数量的主体 | 和核算组织不一致，查询口径混乱 |
| 存货组织 / 核算组织 | 管存货金额的主体 | 多组织汇总时金额串组织 |
| 物料 | 成本核算对象 | 物料类别、计价方法、科目映射错误 |
| 仓库 | 库存地点 | 良品、不良品、委外仓、寄售仓混用 |
| 批号 / 序列号 | 成本和追溯维度 | 批次成本和实物批号不一致 |
| 库存单据 | 成本来源或消耗 | 未审核、跨期、反审核造成差异 |
| 计价方法 | 出库成本计算规则 | 移动平均、月加权、先进先出混用理解错误 |
| 成本调整单 | 修正成本 | 无依据调整导致审计风险 |
| 存货凭证 | 进入总账 | 未生成、未过账、模板取数错误 |
| 库存关账 | 锁定库存期间 | 关账前异常未清理，后续反复返工 |

## 三、月末标准顺序

| 步骤 | 责任角色 | 检查内容 | 输出 |
| --- | --- | --- | --- |
| 1. 清单据 | 仓库 / 供应链 | 入库、出库、退货、调拨、盘点是否审核 | 未审核单据清单 |
| 2. 查负库存 | 仓库 / 成本会计 | 是否存在负数量、负批号、负库存金额 | 负库存处理表 |
| 3. 查无价入库 | 采购 / 成本会计 | 入库单价、暂估价、费用分摊是否完整 | 无价入库清单 |
| 4. 入库核算 | 成本会计 | 采购、完工、其他入库成本是否确认 | 入库成本结果 |
| 5. 出库核算 | 成本会计 | 销售出库、领料、其他出库成本是否计算 | 出库成本结果 |
| 6. 差异调整 | 成本会计 | 发票价差、暂估冲回、费用分摊、异常成本 | 成本调整单 |
| 7. 生成凭证 | 财务 | 存货、成本、暂估、差异凭证 | 存货凭证清单 |
| 8. 对账 | 财务 / 成本 | 存货核算、库存账、总账、报表一致 | 对账表 |
| 9. 关账 | 仓库 / 财务 | 期间锁定，防止历史业务被改 | 关账记录 |

顺序不要乱。还没清库存单据就算成本，后面一张补录出库就可能把成本重新打乱；还没生成凭证就查总账，看到的差异只是“没入账”，不是业务差异。

## 四、差异类型总表

| 差异类型 | 表现 | 常见原因 | 处理方向 |
| --- | --- | --- | --- |
| 数量差异 | 即时库存和库存明细不一致 | 未审核单据、盘点未完成、批号错误 | 先清数量，再谈金额 |
| 金额差异 | 存货报表和总账不同 | 凭证未生成、未过账、手工凭证 | 查凭证链路和总账明细 |
| 成本为 0 | 出库单有数量但无成本 | 无价入库、负库存、计价未完成 | 补入库成本并重算出库 |
| 成本突然变大 | 某月毛利异常 | 低价/高价入库、负库存回补、费用分摊异常 | 查物料收发存和成本计算过程 |
| 暂估未冲回 | 暂估科目长期挂账 | 发票未到、到票未匹配、冲回凭证未生成 | 查采购入库、发票、应付和凭证 |
| 期间差异 | 业务在库存期间，凭证在总账期间 | 跨期单据、总账期间未开、补录历史单 | 固定期间口径并说明跨期 |
| 组织差异 | 分组织对，汇总不对 | 库存组织、核算组织、财务组织映射不清 | 按组织逐层核对 |
| 科目差异 | 总账科目金额不对 | 科目映射、物料类别、凭证模板错误 | 查科目来源和模板条件 |
| 手工调整差异 | 总账有，业务账没有 | 手工凭证直接影响存货科目 | 限制手工制证或补业务调整依据 |

## 五、成本为 0 怎么查

成本为 0 是最常见也最危险的问题。它会让销售毛利虚高、库存金额偏低，后续再补成本时又可能把当月毛利打乱。

排查顺序：

1. 查出库单是否审核。
2. 查出库日期前是否有可用库存。
3. 查对应物料是否有入库成本。
4. 查是否发生负库存出库。
5. 查计价方法是否需要月末统一出库核算。
6. 查入库成本是否来自暂估、发票或成本计算。
7. 查出库核算是否已经执行。
8. 查成本计算日志或异常清单。

常见处理：

- 补维护入库暂估价或采购价。
- 处理负库存，必要时调整业务顺序。
- 重新执行入库核算和出库核算。
- 生成或重生成成本凭证。
- 在月结报告说明补算成本对毛利的影响。

## 六、暂估和价差

采购业务经常出现“货到了，票没到”。这时存货已经入库，成本不能一直空着，通常先按暂估价入账；后续发票到了，再冲回暂估并确认正式应付和进项税。

```text
采购入库
  -> 暂估入账
  -> 发票到达
  -> 入库和发票匹配
  -> 暂估冲回
  -> 发票价差 / 成本调整
  -> 应付和存货凭证
```

常见场景：

| 场景 | 处理重点 |
| --- | --- |
| 发票价格 = 暂估价格 | 暂估冲回后正式应付入账即可 |
| 发票价格 > 暂估价格 | 差额增加存货成本或影响已售成本 |
| 发票价格 < 暂估价格 | 差额冲减存货成本或已售成本 |
| 货已消耗，票后到 | 差异可能进入主营业务成本或生产成本 |
| 采购费用后到 | 运费、关税、保险等要按规则分摊 |

学习重点：差异不一定还在库存里。如果物料已经销售或领用，价差可能要分摊到已出库成本，而不是只调库存余额。

## 七、负库存为什么会扭曲成本

负库存的本质是“先出库，后入库”。系统在出库时没有真实入库成本，只能用估计或暂时成本；后续入库后再回补，可能导致某个期间成本突然变化。

例子：

```text
6 月 3 日销售出库 100 件，库存不足，形成负库存
6 月 10 日采购入库 100 件，单价 50
6 月 30 日出库核算时，系统回补出库成本
```

风险：

- 销售当天看毛利不准。
- 月末补成本导致毛利波动。
- 如果跨月回补，可能影响两个期间的成本分析。
- 批号管理物料会出现批次追溯不清。

管理建议：

- 关键物料禁止负库存。
- 月末关账前必须清理负库存。
- 对允许负库存的业务，月结报告单独列示影响。
- 不要用手工凭证掩盖负库存造成的成本差异。

## 八、存货与总账对账

存货对账不是只看一个总数，要分层。

```text
库存数量
  -> 存货核算数量和金额
  -> 存货凭证
  -> 总账科目余额
  -> 报表存货项目
```

对账表建议列这些字段：

| 字段 | 说明 |
| --- | --- |
| 组织 | 库存组织 / 核算组织 / 财务组织 |
| 期间 | 库存期间、存货期间、总账期间 |
| 科目 | 原材料、库存商品、委托加工物资等 |
| 物料类别 | 用于定位科目映射 |
| 存货核算金额 | 来自存货报表 |
| 总账金额 | 来自科目余额或辅助明细 |
| 差异 | 存货核算金额 - 总账金额 |
| 差异原因 | 未生成凭证、手工凭证、跨期、科目错误等 |
| 处理人 | 成本会计、总账会计、供应链顾问 |
| 状态 | 待处理、已处理、有说明 |

## 九、常见案例

### 案例 1：存货报表 500 万，总账只有 480 万

排查：

1. 存货凭证是否全部生成。
2. 凭证是否审核、过账。
3. 是否存在凭证生成失败。
4. 是否有手工凭证直接调整存货科目。
5. 查询条件组织、期间、币别是否一致。

常见根因：

- 本月部分销售出库成本凭证未生成。
- 存货凭证生成了但未过账。
- 总账有人手工冲减库存商品科目。

处理：

- 补生成凭证并过账。
- 对手工凭证补业务依据或冲回。
- 将“存货科目手工凭证”加入月结检查。

### 案例 2：某个物料本月毛利突然为负

排查：

1. 查该物料本月入库单价。
2. 查是否有大额费用分摊。
3. 查是否有负库存回补。
4. 查是否有退货、红冲、成本调整。
5. 查销售出库成本是否取到异常批次。

处理：

- 用收发存明细还原物料成本变化。
- 对异常入库价或费用分摊做审批确认。
- 必要时做成本调整并留存说明。

### 案例 3：发票到票后暂估没有冲回

排查：

1. 采购入库是否形成暂估。
2. 发票是否和入库单匹配。
3. 应付单是否审核。
4. 暂估冲回凭证是否生成。
5. 暂估科目是否和正式应付科目区分。

处理：

- 补做发票匹配和应付确认。
- 补生成暂估冲回凭证。
- 月末输出暂估余额清单，逐笔说明。

### 案例 4：库存关账关不上

排查：

1. 是否存在未审核库存单据。
2. 是否存在未完成盘点。
3. 是否存在负库存或异常库存状态。
4. 是否存在未完成出库核算。
5. 是否有期间内单据被反审核。

处理：

- 先让仓库清单据，再让成本会计核算。
- 对确实跨期未完业务做说明，不随意改历史期间。
- 关账后限制普通用户反审核历史单据。

## 十、凭证方向

实际科目以企业配置为准，下面用于理解。

采购入库暂估：

```text
借：原材料 / 库存商品
  贷：应付暂估
```

发票到票冲回暂估并确认应付：

```text
借：应付暂估
借：原材料 / 库存商品    （价差，可能借或贷）
借：应交税费-进项税额
  贷：应付账款
```

销售出库结转成本：

```text
借：主营业务成本
  贷：库存商品
```

生产领料：

```text
借：生产成本-直接材料
  贷：原材料
```

成本调整：

```text
借：库存商品 / 主营业务成本 / 生产成本
  贷：成本调整相关科目
```

成本调整的对方科目要按企业会计政策和调整原因确定，不能为了让差异为 0 随便找科目。

## 十一、月结清单

- [ ] 库存单据全部审核或有未完说明。
- [ ] 盘点业务处理完成。
- [ ] 负库存清理完成。
- [ ] 无价入库、零成本入库已处理。
- [ ] 采购暂估价维护完成。
- [ ] 入库核算完成。
- [ ] 出库核算完成。
- [ ] 发票价差、费用分摊、成本调整有依据。
- [ ] 销售出库成本无 0 成本异常。
- [ ] 存货凭证全部生成、审核、过账。
- [ ] 存货核算余额和总账存货科目一致。
- [ ] 暂估科目余额有明细清单。
- [ ] 库存关账完成。
- [ ] 月结报告列示重大成本波动原因。

## 十二、学习练习

建议在测试环境做 4 组练习：

1. 做一笔采购入库暂估，再做发票到票和暂估冲回。
2. 做一笔销售出库，执行出库成本核算并生成成本凭证。
3. 人为制造一笔无价入库或 0 成本出库，按排查路径修复。
4. 做一轮月末存货对账，列出存货核算金额、总账金额和差异原因。

学会的标准：

- 能说清“库存数量对了”为什么不等于“存货金额对了”。
- 能区分未生成凭证、未过账、手工凭证、暂估未冲回造成的差异。
- 能用一张物料收发存明细解释成本波动。
- 能在关账前列出必须清理的异常清单。
