销售退货、红冲、退款和折让，都是销售业务的“反向处理”。正向销售看起来是一条线：订单、出库、应收、开票、收款、结转成本；反向业务则要把这条线上的库存、收入、应收、税额、成本、资金和凭证逐项处理回来。

这类业务最容易出错的原因是：销售、仓库、财务、税务各自只做了自己那一步。例如仓库已经收回货，财务没有冲应收；财务已经红冲了收入，库存没有入库；发票已经开红字，客户退款还挂在预收或其他往来里。系统里只要有一环没闭合，月末对账就会留下差异。

## 一、先分清五类业务

| 场景 | 是否退货 | 是否退钱 | 是否影响发票 | 典型处理 |
| --- | --- | --- | --- | --- |
| 纯销售退货 | 是 | 可能不退，直接抵后续货款 | 可能需要红字发票 | 销售退货单、退货入库、红字应收、成本冲回 |
| 退货加退款 | 是 | 是 | 多数需要红字发票或应收冲减 | 退货入库、红字应收、收款退款单、核销调整 |
| 价格折让 | 否 | 可能退差价或抵扣 | 通常需要红字发票或折扣处理 | 红字应收、折扣折让、应收调整 |
| 开票红冲 | 不一定 | 不一定 | 是 | 红字发票、红字应收或税额调整 |
| 换货 | 是，同时再发货 | 可能不退 | 看发票是否重开 | 退货入库、重新出库、差额应收或退款 |

通俗理解：

- 退货处理的是“货回来了没有”。
- 红冲处理的是“收入、税额和应收要不要反方向冲掉”。
- 退款处理的是“钱要不要还给客户”。
- 折让处理的是“货不退，但价格或服务补偿要调整”。
- 换货处理的是“一退一出，数量和金额可能同时变化”。

## 二、完整业务主线

```text
原销售订单 / 原销售出库 / 原应收
  -> 客户提出退货、退款或折让
  -> 销售或客服确认责任和处理方式
  -> 销售退货申请或退货单
  -> 仓库收货、质检、退货入库
  -> 红字应收或应收调整
  -> 红字发票或发票红冲
  -> 收款退款、预收抵扣或核销调整
  -> 存货核算冲回销售成本
  -> 生成凭证并完成对账
```

不要把退货单看成一个孤立单据。它至少要回答四个问题：

1. 货：库存数量是否回来了，回到哪个仓库、哪个批号、哪个库存状态。
2. 钱：应收余额是否减少，客户是否需要退款。
3. 税：蓝字发票是否已经开具，是否需要红字发票。
4. 成本：原销售出库成本是否冲回，冲回期间是否正确。

## 三、角色分工

| 角色 | 负责动作 | 关键检查 |
| --- | --- | --- |
| 销售 / 客服 | 确认客户退货、折让、退款原因 | 是否关联原订单、原出库、原客户、原价格 |
| 仓库 | 收回实物并办理退货入库 | 数量、批号、仓库、库存状态、是否需质检 |
| 质检 | 判定可再售、返修、报废或待处理 | 不合格品不要直接进入可用库存 |
| 应收会计 | 处理红字应收、核销和客户余额 | 客户、结算客户、币别、金额方向 |
| 税务会计 | 处理红字发票或折扣发票 | 红蓝字关系、税率、价税合计 |
| 成本会计 | 处理销售成本冲回和存货核算 | 原出库成本、退货成本、跨期影响 |
| 出纳 | 办理客户退款或收款调整 | 银行账号、退款审批、资金流水 |

如果企业分工不清，建议把“退货审批”设计成跨部门节点：销售确认业务原因，仓库确认实物，财务确认应收和发票，成本确认存货影响。

## 四、单据和系统对象

| 对象 | 作用 | 学习重点 |
| --- | --- | --- |
| 原销售订单 | 找到客户、价格、交付约定 | 退货最好保留原单关联，便于追溯 |
| 销售出库单 | 原库存出库依据 | 退货数量不能随意超过原出库数量 |
| 销售退货单 | 退货业务核心单据 | 数量、仓库、批号、库存状态、原出库关联 |
| 退货入库 | 库存回增 | 要区分良品仓、不良品仓、待检仓 |
| 应收单 / 红字应收 | 调整客户债权 | 金额方向、税额、客户维度、核销状态 |
| 销售发票 / 红字发票 | 调整开票和税务口径 | 红蓝字关系和税率要一致 |
| 收款退款单 | 把已收款退给客户 | 需要和红字应收或原收款核销 |
| 成本核算单据 | 冲回销售成本 | 跨期时要看会计期间和成本期间 |
| 凭证 | 进入总账 | 业务凭证和手工凭证不能互相打架 |

## 五、不同场景怎么处理

### 1. 未开票、未收款的退货

这种最简单，核心是把库存和应收冲掉。

```text
销售出库
  -> 应收单
  -> 客户退货
  -> 销售退货单
  -> 退货入库
  -> 红字应收
  -> 成本冲回
```

检查点：

- 退货单是否关联原销售出库。
- 红字应收是否关联原应收。
- 退货入库是否进入正确仓库。
- 存货核算是否按退货入库生成成本冲回。
- 客户应收余额是否减少。

### 2. 已开票、未收款的退货

这类业务要同时关注应收和发票。

```text
原销售出库 / 原应收 / 蓝字发票
  -> 销售退货
  -> 退货入库
  -> 红字应收
  -> 红字发票
  -> 应收核销或冲减
```

检查点：

- 红字发票是否关联原蓝字发票。
- 红字应收金额和红字发票价税合计是否一致。
- 应收账龄是否不再显示原应收逾期。
- 税额方向是否正确。
- 当月税务申报口径是否和发票系统一致。

### 3. 已收款、已开票的退货退款

这类业务最容易留下“账上冲了收入，但钱没退；钱退了，但应收没核销”的问题。

```text
原销售出库 / 原应收 / 蓝字发票 / 收款核销
  -> 销售退货
  -> 退货入库
  -> 红字应收 / 红字发票
  -> 收款退款单
  -> 红字应收和退款单核销
  -> 成本冲回
```

检查点：

- 原收款是否已经核销。如果已核销，退款时要看系统是否需要反核销或红字核销。
- 退款单是否走审批，是否有客户收款账户。
- 红字应收是否和退款单核销，避免客户余额一正一负长期挂账。
- 银行流水、出纳日记账、应收明细和总账是否一致。

### 4. 不退货，只做销售折让

客户不退货，但因为质量瑕疵、延迟交付、价格保护、售后补偿等原因要求降价或返差价。

常见处理：

- 做红字应收，冲减客户应收。
- 做折扣折让单据，按配置传递到应收或发票。
- 做红字发票或折扣发票。
- 已收款的，做退款或抵扣后续货款。

学习重点：

- 折让不影响库存数量，但会影响收入、税额和应收。
- 如果把折让做成费用，要确认企业会计政策是否允许。
- 如果客户后续还会继续采购，折让可以设计成预收抵扣或应收冲抵，但要让账龄和客户对账单看得懂。

### 5. 换货

换货本质上是“退旧货 + 发新货”，不要只做一张模糊的调整单。

```text
客户退回旧货
  -> 销售退货单 / 退货入库
  -> 质检判定
  -> 新货销售出库
  -> 差额应收、退款或补收款
```

如果新旧货价格不同，要单独处理差价。不要把差价藏在库存单据里，否则财务和销售后续很难对账。

### 6. 跨月或跨年退货

跨期退货要特别小心，因为原收入和成本可能已经结账、报税或出报表。

重点判断：

- 原销售期间是否已经关账。
- 原销售成本是否已经结转。
- 是否需要在当前期间做红字业务，而不是回到历史期间直接改单。
- 管理报表是否需要按原销售月份重分类。
- 税务红冲所属期间是否和财务处理一致。

建议做法：

1. 不轻易反结账修改历史单据。
2. 在当前期间做退货、红字应收、红字发票和成本冲回。
3. 在月结说明里记录跨期原因、金额、客户和原单号。
4. 管理报表如需还原原销售月份，单独做分析口径，不随意改总账。

## 六、常见凭证方向

实际科目以企业科目表和凭证模板为准，下面只用于理解方向。

### 原销售确认

```text
借：应收账款-客户
  贷：主营业务收入
  贷：应交税费-销项税额
```

### 原销售成本结转

```text
借：主营业务成本
  贷：库存商品
```

### 销售退货冲收入和应收

```text
借：主营业务收入
借：应交税费-销项税额
  贷：应收账款-客户
```

有些系统会用红字金额表示，凭证方向看起来和原销售相同但金额为负。判断时不要只看借贷方向，还要看金额方向。

### 销售退货冲成本

```text
借：库存商品
  贷：主营业务成本
```

### 客户退款

```text
借：应收账款-客户
  贷：银行存款
```

如果红字应收已经把客户余额冲成贷方或负数，退款后必须核销，否则客户对账单会同时出现负应收和退款记录。

## 七、对账检查表

| 检查对象 | 应该看到什么 | 异常信号 |
| --- | --- | --- |
| 原销售出库 | 有退货关联或被退货数量 | 退货没有原单，难以控制超退 |
| 库存余额 | 退货数量回到指定仓库 | 库存回来了，但状态是可用还是待检不清楚 |
| 应收明细 | 红字应收冲减原客户 | 客户余额没变，或挂到错误结算客户 |
| 发票记录 | 红字发票关联蓝字发票 | 税务已红冲，系统应收没冲 |
| 收款核销 | 红字应收、退款、原收款关系清楚 | 已退款但客户账龄仍逾期 |
| 成本核算 | 销售成本被冲回 | 库存数量回来了，成本没回来 |
| 总账凭证 | 收入、税额、应收、库存、成本方向正确 | 业务账和总账金额不一致 |
| 客户对账单 | 客户能看懂原销售、退货、退款关系 | 正负单据都在，但没有核销 |

## 八、排查案例

### 案例 1：货已经退回，客户应收余额没有减少

现象：

- 仓库能看到退货入库。
- 客户仍显示欠款。
- 应收账龄仍显示逾期。

排查：

1. 查销售退货单是否审核。
2. 查退货单是否生成红字应收或应收调整。
3. 查红字应收客户和原应收客户是否一致。
4. 查红字应收是否参与核销。
5. 查红字应收凭证是否生成并过账。

常见根因：

- 只做了库存退货，没有生成应收冲减。
- 红字应收挂到了收货客户，原应收挂在结算客户。
- 退货在供应链期间完成，但财务期间还没处理。

处理：

- 补生成或补录红字应收。
- 按同一结算客户进行核销。
- 重新输出客户余额、账龄和总账辅助明细核对。

### 案例 2：红字发票已经开了，但销售收入没有冲掉

现象：

- 税务系统已有红字发票。
- 总账收入仍是原金额。
- 应收和发票金额不一致。

排查：

1. 红字发票是否回写或同步到金蝶。
2. 红字发票是否生成红字应收。
3. 红字应收是否生成凭证。
4. 凭证模板是否对红字单据启用。
5. 税额和价税合计是否方向正确。

常见根因：

- 发票系统和金蝶没有完整集成。
- 只做了发票红冲，没有做应收红冲。
- 凭证模板排除了红字单据或负数金额。

处理：

- 补齐红字发票和红字应收的关联。
- 补生成凭证。
- 固化红字业务的凭证模板测试用例。

### 案例 3：客户退款已经打款，但客户对账单仍有负数

现象：

- 银行已经退款。
- 客户对账单有一笔红字应收和一笔退款。
- 客户余额看起来不为 0，或账龄仍异常。

排查：

1. 收款退款单是否审核。
2. 退款单是否和红字应收核销。
3. 退款客户、结算客户、币别是否一致。
4. 是否存在预收款抵扣逻辑。

处理：

- 做退款单与红字应收核销。
- 若核销错对象，按权限反核销后重做。
- 输出客户对账单给业务确认。

### 案例 4：跨月退货导致本月毛利异常

现象：

- 本月销售收入为负或毛利率异常。
- 退货对应的是上月或去年销售。
- 成本冲回和收入红冲不在同一期间。

排查：

1. 原销售日期、退货日期、发票红冲日期。
2. 退货成本取原出库成本还是当前成本。
3. 存货核算期间和总账期间。
4. 管理报表是否按销售归属期重分类。

处理：

- 财务账按当前期间真实发生记录。
- 管理分析可单独列示“跨期退货影响”。
- 月结报告说明客户、原单、金额和毛利影响。

## 九、上线和测试清单

- [ ] 正向销售到应收、开票、收款、成本全部跑通。
- [ ] 未开票退货能生成退货入库、红字应收和成本冲回。
- [ ] 已开票退货能生成或关联红字发票。
- [ ] 已收款退货能完成退款和核销。
- [ ] 折让不退货时，库存数量不被误调。
- [ ] 换货能清楚区分退货和重新发货。
- [ ] 跨期退货不需要随意反结账即可处理。
- [ ] 销售退货不能超过原出库数量，或超退有审批。
- [ ] 退货入库能区分良品、不良品、待检品。
- [ ] 红字应收、红字发票、退款单能在客户对账单中解释清楚。
- [ ] 红字业务可以生成凭证，且总账和业务账一致。
- [ ] 月结检查包含退货未生成应收、红字发票未生成凭证、退款未核销。

## 十、学习建议

学习这块不要只背“退货单怎么做”。建议按下面顺序练习：

1. 先做一笔最简单销售：出库、应收、发票、收款、成本。
2. 对这笔销售做全额退货，看每张单据如何反向产生。
3. 再做部分退货，观察原单数量、应收余额和成本如何变化。
4. 再做已收款退款，理解为什么核销会影响账龄。
5. 最后做跨月退货，观察本月收入、成本和毛利的影响。

学会的标准不是“会点按钮”，而是能拿一张客户对账单解释：客户买了什么、退了什么、红冲了什么、退了多少钱、现在还欠不欠钱。
