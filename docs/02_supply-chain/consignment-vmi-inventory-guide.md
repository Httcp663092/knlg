寄售和 VMI 的难点不在“库存放在哪里”，而在“东西归谁、什么时候算买卖、什么时候确认应收应付和成本”。如果只把它当普通入库或普通出库处理，库存数量看起来可能对，但所有权、结算、收入、成本和对账都会出问题。

这篇专题把供应商寄售、客户寄售和 VMI 放在一起讲，重点讲库存地点、所有权、消耗结算、对账和财务影响。

## 一、先分清三种模式

| 模式 | 货在哪里 | 所有权通常归谁 | 什么时候结算 |
| --- | --- | --- | --- |
| 供应商寄售 | 放在本企业仓库 | 供应商 | 本企业领用或消耗时 |
| 客户寄售 | 放在客户仓库 | 本企业 | 客户消耗或确认销售时 |
| VMI | 供应商管理本企业库存 | 视协议而定 | 按消耗、补货或结算周期 |

通俗理解：

- 普通采购：货入库后通常就是我的库存。
- 供应商寄售：货在我仓库，但还可能不是我的资产。
- 客户寄售：货在客户仓库，但还可能是我的资产。
- VMI：供应商参与库存管理，补货和结算要按协议控制。

## 二、完整业务链路

### 供应商寄售

```text
寄售协议
  -> 供应商送货到寄售仓
  -> 寄售入库
  -> 本企业领用 / 消耗 / 转正式库存
  -> 生成采购结算或应付
  -> 存货成本确认
  -> 付款
```

### 客户寄售

```text
寄售协议 / 销售订单
  -> 发货到客户寄售仓
  -> 寄售出库 / 移库
  -> 客户消耗或确认结算
  -> 销售确认 / 应收
  -> 开票和收款
  -> 成本结转
```

### VMI

```text
需求预测 / 安全库存协议
  -> 供应商补货
  -> 库存监控
  -> 消耗确认
  -> 周期结算
  -> 应付确认
  -> 供应商绩效和库存对账
```

## 三、关键配置和对象

| 对象 | 作用 | 检查点 |
| --- | --- | --- |
| 寄售供应商 / 客户 | 确认寄售关系 | 是否和普通客户供应商区分 |
| 寄售仓 / VMI 仓 | 区分库存地点 | 是否和自有库存混放 |
| 库存状态 | 区分寄售、可用、待结算 | 是否允许普通出库 |
| 物料库存信息 | 批号、保质期、单位 | 寄售物料是否同样受批号控制 |
| 寄售协议 | 所有权、价格、结算周期 | 消耗结算规则是否明确 |
| 消耗单 / 结算单 | 触发结算 | 是否按实际消耗确认 |
| 应收 / 应付 | 财务债权债务 | 是否只在结算时确认 |
| 存货核算 | 成本确认 | 所有权转移前是否进入本企业存货 |

## 四、所有权和财务口径

这是寄售/VMI 最关键的一点。

| 场景 | 库存数量 | 财务存货 | 应收应付 |
| --- | --- | --- | --- |
| 供应商寄售货入本企业仓 | 系统可记录数量 | 通常不计入本企业存货资产，按协议判断 | 暂不确认应付 |
| 本企业消耗供应商寄售货 | 数量减少或转正式库存 | 确认存货或成本 | 确认应付 |
| 本企业发货到客户寄售仓 | 本企业库存地点变化 | 仍可能是本企业存货 | 暂不确认收入或应收 |
| 客户消耗寄售货 | 客户寄售库存减少 | 本企业存货减少并结转成本 | 确认收入和应收 |
| VMI 周期结算 | 按消耗或周期汇总 | 按协议确认 | 生成应付或应收 |

如果企业会计政策不同，要以合同和财务政策为准。系统配置要服务于这个口径，而不是反过来让系统默认流程决定会计处理。

## 五、库存管理检查

寄售/VMI 库存要重点看：

- 是否有独立仓库或库存状态。
- 是否允许普通销售出库或生产领料直接使用。
- 是否需要批号、序列号、保质期管理。
- 是否有寄售库存余额表。
- 是否能按供应商、客户、物料、批号、库龄查询。
- 是否有定期盘点机制。
- 是否有超期、呆滞、临期预警。

建议不要让寄售库存和自有库存完全混在一个仓库、一个状态里。短期省事，后面对账会很痛。

## 六、结算和对账

### 供应商寄售对账

```text
期初寄售库存
  + 本期供应商送货
  - 本期消耗 / 退回
  = 期末寄售库存
```

对账字段：

| 字段 | 说明 |
| --- | --- |
| 供应商 | 寄售货归属 |
| 物料 / 批号 | 追溯对象 |
| 期初数量 | 上期结存 |
| 本期送货 | 供应商补货 |
| 本期消耗 | 本企业实际使用 |
| 本期退回 | 退供应商 |
| 期末数量 | 应有库存 |
| 结算数量 | 本期应付依据 |
| 结算金额 | 应付金额 |

### 客户寄售对账

```text
期初客户寄售库存
  + 本期发往客户
  - 客户本期消耗 / 退回
  = 期末客户寄售库存
```

客户寄售对账最重要的是客户消耗确认。没有客户确认，就很难判断什么时候确认收入。

## 七、常见凭证方向

供应商寄售入库，如果所有权未转移，通常不直接确认本企业存货资产。消耗或转正式采购时：

```text
借：原材料 / 生产成本 / 主营业务成本
  贷：应付账款-供应商
```

客户寄售发货，如果所有权未转移，通常不确认收入，只做库存地点或状态变化。客户消耗确认后：

```text
借：应收账款-客户
  贷：主营业务收入
  贷：应交税费-销项税额

借：主营业务成本
  贷：库存商品
```

实际科目和时点必须按企业会计政策、合同条款和系统配置确定。

## 八、常见案例

### 案例 1：供应商寄售库存被当作自有库存

现象：

- 仓库可以看到寄售货。
- 财务存货余额也包含这批货。
- 供应商还没有结算，企业却已经把货计入资产。

排查：

1. 寄售仓是否映射到正常存货科目。
2. 寄售入库是否生成存货凭证。
3. 是否区分寄售状态和自有状态。
4. 合同是否约定消耗时所有权转移。

处理：

- 调整寄售库存状态或仓库科目映射。
- 消耗时再确认应付和成本。
- 对历史误入账金额做调整并留说明。

### 案例 2：客户寄售发货后提前确认收入

现象：

- 货发到客户仓库。
- 客户尚未消耗或签收结算。
- 财务已经确认收入和应收。

排查：

1. 销售出库是否被配置为自动确认收入。
2. 客户寄售仓是否和普通客户发货区分。
3. 合同约定收入时点是发货还是客户消耗。
4. 是否有客户消耗确认单。

处理：

- 客户寄售发货先做寄售库存转移。
- 客户消耗后再确认收入、应收和成本。
- 调整收入确认规则或增加审批控制。

### 案例 3：VMI 供应商对账数量不一致

排查：

1. 期初库存是否双方一致。
2. 本期送货是否全部入账。
3. 本期消耗是否及时回传。
4. 退货、报废、盘亏是否双方都确认。
5. 批号和单位换算是否一致。

处理：

- 按期初 + 送货 - 消耗 - 退回 = 期末重建对账表。
- 对差异按单据逐笔确认。
- 固化供应商对账周期和数据格式。

### 案例 4：寄售货过期或呆滞无人处理

排查：

1. 是否维护批号和保质期。
2. 是否有寄售库存库龄报表。
3. 合同约定呆滞或过期责任归谁。
4. 是否可以退供应商或客户。

处理：

- 建立寄售库存库龄预警。
- 临期提前通知业务和供应商。
- 按合同处理退回、折价、报废或赔偿。

## 九、上线测试清单

- [ ] 寄售仓、VMI 仓和普通仓区分清楚。
- [ ] 寄售库存状态不允许被普通流程误用。
- [ ] 供应商寄售入库不错误确认应付。
- [ ] 供应商寄售消耗能生成结算或应付。
- [ ] 客户寄售发货不错误确认收入。
- [ ] 客户消耗能确认应收、收入和成本。
- [ ] 批号、保质期、序列号在寄售流程中可追踪。
- [ ] 寄售库存可以按客户、供应商、物料查询余额。
- [ ] 寄售对账表可以解释期初、发生、结存。
- [ ] VMI 补货、消耗、退回、结算都有单据依据。
- [ ] 寄售/VMI 凭证和总账口径通过财务确认。

## 十、学习练习

1. 做一笔供应商寄售入库，不确认应付；再做消耗结算，确认应付。
2. 做一笔客户寄售发货，不确认收入；再做客户消耗，确认收入和成本。
3. 做一次 VMI 周期对账，用期初、本期送货、本期消耗、期末库存解释差异。
4. 做一次寄售库存盘点，处理盘盈、盘亏、临期和退回。

学会的标准：

- 能说清寄售货“在谁仓库”和“归谁所有”不是一回事。
- 能判断什么时候确认应收、应付、收入和成本。
- 能用寄售对账表解释供应商或客户库存差异。
- 能设计寄售仓库、库存状态和结算规则，避免普通库存流程误用。
