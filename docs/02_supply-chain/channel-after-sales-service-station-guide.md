客户索赔和售后备件专题解决的是企业内部怎么受理、怎么发备件、怎么确认维修收入和售后成本。这篇继续补渠道售后：备件放在经销商、服务站、工程师车载库或客户现场，维修可能由经销商代修，结算可能是免费保内、保外收费、服务商工时、备件补货或质量扣款。

渠道售后最容易乱在四件事上：

- 备件在外面，系统库存还在总部仓或没有独立库存账。
- 经销商代修，服务动作有了，但原厂不知道用了什么件、修了多久、责任是谁。
- 保内免费和保外收费混在一起，财务不知道确认售后成本、维修收入还是渠道费用。
- 服务站月底报表靠 Excel，和金蝶库存、应收、应付、费用结算对不上。

这篇的目标是把服务站库存、经销商代修、备件补货、旧件返还、服务费结算和财务对账串起来。

## 一、完整业务主线

```text
客户报修 / 渠道报修
  -> 售后受理和质保判断
  -> 指派服务站 / 经销商 / 工程师
  -> 服务站备件领用或申请补货
  -> 维修、换件、旧件返还、客户确认
  -> 服务结果回传总部
  -> 备件库存核销 / 补货 / 调拨
  -> 保内成本、保外收入、服务费、供应商索赔
  -> 服务绩效和渠道对账
```

不要把服务站当成普通客户，也不要把服务站库存简单当成普通仓库。项目里要先确定所有权、结算关系和库存责任。

## 二、先分清五类库存

| 库存类型 | 所有权 | 存放地点 | 典型用途 | 财务影响 |
| --- | --- | --- | --- | --- |
| 总部售后备件仓 | 企业 | 总部仓库 | 对服务站补货、直接发客户 | 企业存货 |
| 服务站寄售备件 | 企业 | 服务站 | 保内维修、临时换件 | 企业存货，需定期盘点 |
| 服务站买断备件 | 服务站或经销商 | 服务站 | 保外维修、渠道自营维修 | 企业销售收入和成本 |
| 工程师周转备件 | 企业 | 工程师车载库或个人库 | 现场服务快速响应 | 企业存货，需领退核销 |
| 客户现场备件 | 视合同而定 | 客户现场 | 大客户备机、驻场维护 | 可能是寄售、借用或已销售 |

所有权不清时，后面一定会对不上：仓库说货已经发走，财务说还在账上，服务站说已经用掉，客户说没有收到。

## 三、基础资料设计

| 对象 | 建议记录 | 用途 |
| --- | --- | --- |
| 服务站 | 编码、区域、负责客户、结算主体、联系人 | 分配服务、统计绩效、对账 |
| 经销商 | 客户身份、服务商身份、供应商身份 | 区分销售、代修和服务费结算 |
| 售后仓库 | 总部备件仓、服务站仓、工程师库、客户现场库 | 区分实物地点和所有权 |
| 备件物料 | 是否备件、是否序列号、是否关键件、保质期 | 控制发放、追溯和旧件返还 |
| 产品序列号 | 出厂日期、销售客户、质保期、维修历史 | 判断保内保外和责任归属 |
| 服务项目 | 检测、维修、上门、安装、延保 | 支持收费和绩效 |
| 旧件状态 | 待返还、已返还、待检测、报废、供应商索赔 | 防止免费备件被滥用 |

## 四、服务站备件补货流程

```text
服务站安全库存 / 维修需求
  -> 备件申请
  -> 总部审核
  -> 调拨出库 / 销售出库 / 其他出库
  -> 服务站确认收货
  -> 服务站库存台账更新
  -> 月末盘点和对账
```

| 补货方式 | 适用场景 | 控制重点 |
| --- | --- | --- |
| 调拨到服务站仓 | 服务站库存仍属于企业 | 调拨在途、服务站确认、盘点责任 |
| 销售给经销商 | 服务站买断备件 | 销售价格、信用、开票、应收 |
| 寄售补货 | 先放服务站，用后结算或核销 | 消耗确认、所有权、账龄 |
| 借用备件 | 临时应急，要求退回 | 借用期限、押金、归还状态 |
| 直发客户 | 服务站不入库 | 客户签收、售后单号、责任归属 |

项目蓝图里要明确：服务站申请补货时，是自动按安全库存生成，还是人工申请；总部是按库存满足率发货，还是按服务工单逐单发货。

## 五、经销商代修流程

```text
客户报修
  -> 经销商受理
  -> 总部授权或自动派工
  -> 经销商检测和维修
  -> 备件领用 / 旧件返还
  -> 客户确认
  -> 经销商提交服务结算
  -> 总部审核
  -> 服务费、备件、索赔和绩效结算
```

| 环节 | 必填证据 | 常见风险 |
| --- | --- | --- |
| 报修 | 客户、产品、序列号、故障描述 | 没有关联原销售和质保 |
| 派工 | 服务站、工程师、预计到场时间 | 重复派工或跨区域派工 |
| 检测 | 故障原因、责任归属、照片 | 质量问题和使用问题混淆 |
| 维修 | 处理方式、备件、工时 | 免费和收费口径不清 |
| 旧件 | 旧件序列号、返还状态、检测结论 | 免费换件但旧件不回收 |
| 客户确认 | 签字、照片、服务评价 | 后续客户否认服务完成 |
| 结算 | 服务费、备件费、差旅费、扣款 | 经销商报账和系统单据不一致 |

## 六、保内、保外和渠道结算

| 场景 | 客户是否收费 | 服务站是否结算 | 备件处理 | 财务处理 |
| --- | --- | --- | --- | --- |
| 保内原厂责任 | 否 | 是，按服务政策给服务费 | 企业备件消耗 | 售后成本、服务费应付 |
| 保内供应商责任 | 否 | 是 | 企业先换件，旧件向供应商索赔 | 售后成本或供应商索赔冲减 |
| 保外收费维修 | 是 | 可能给服务站服务费 | 可销售备件或服务站自有备件 | 维修收入、备件成本、服务费 |
| 客户使用不当拒保 | 是或客户自理 | 视服务政策 | 备件可收费 | 维修收入或不处理 |
| 经销商自营维修 | 经销商收费 | 原厂不一定结算 | 买断备件 | 原厂只确认备件销售 |
| 大客户驻场服务 | 视合同 | 按合同结算 | 客户现场备件 | 合同服务收入或售后成本 |

最关键的是：一张服务单要能看出客户收费、服务站结算、备件所有权和责任归属。否则月底售后成本和渠道费用一定会失真。

## 七、旧件返还和质量追溯

免费备件如果没有旧件返还控制，很容易形成两类漏洞：一是实际没有更换却领了备件，二是换下来的旧件被二次使用或流失。

| 控制点 | 建议做法 |
| --- | --- |
| 哪些备件必须返旧 | 关键件、高价值件、序列号件、供应商索赔件 |
| 返旧期限 | 按服务完成后 N 天内返还 |
| 返旧状态 | 待返还、运输中、已入库、待检测、报废、可维修 |
| 未返旧处理 | 暂停服务费结算、扣备件费、进入异常清单 |
| 质量检测 | 判断企业责任、供应商责任、客户使用问题 |
| 供应商索赔 | 关联供应商、采购批次、旧件检测报告 |

## 八、对账模型

渠道售后对账要同时对五张账。

| 账 | 来源 | 对账问题 |
| --- | --- | --- |
| 服务单账 | 售后系统、CRM 或金蝶售后单 | 本月服务完成了哪些 |
| 备件库存账 | 金蝶库存、服务站库存台账、WMS | 备件在哪里、还剩多少 |
| 旧件账 | 旧件返还、检测、报废、索赔 | 免费换件是否闭环 |
| 往来账 | 应收客户、应付服务商、供应商扣款 | 谁欠谁钱 |
| 绩效账 | 响应时效、一次修复率、客户评分 | 服务质量和渠道考核 |

### 月末对账清单

| 检查项 | 异常信号 | 处理建议 |
| --- | --- | --- |
| 服务完成但未领料 | 工单完成，备件没有出库 | 补领料或确认未用件 |
| 备件已出库但服务未完成 | 备件长期在工程师或服务站 | 催办服务或退回备件 |
| 服务站库存为负 | 先用后补、单据滞后 | 补录消耗或调整库存 |
| 旧件未返还 | 免费换件但无旧件 | 暂缓结算或扣款 |
| 保外维修无应收 | 客户收费维修但没有应收 | 补收费单、应收和发票 |
| 服务费无工单依据 | 经销商报账大于服务单 | 按服务单审核结算 |
| 供应商索赔未跟进 | 质量责任已判供应商，但没有扣款 | 补索赔单或采购扣款 |

## 九、系统落地方案

| 方案 | 适用场景 | 优点 | 风险 |
| --- | --- | --- | --- |
| 金蝶内建服务站仓库 | 服务站数量不多，企业要管库存所有权 | 库存清楚，月末易对账 | 服务站操作习惯要培训 |
| 外部售后系统 + 金蝶库存 | 售后系统成熟，金蝶负责库存财务 | 保留前端服务体验 | 接口和对账要求高 |
| WMS / 条码管理服务站库存 | 备件多、序列号强、出入库频繁 | 实物准确率高 | 需要移动端和盘点流程 |
| 经销商买断模式 | 渠道自营售后为主 | 企业库存压力小 | 服务质量和客户体验要管控 |
| 寄售模式 | 备件放在服务站但企业保留所有权 | 响应快，控制所有权 | 消耗确认和盘点必须严格 |

## 十、接口和数据要求

如果售后系统、CRM、WMS、经销商门户和金蝶分开部署，至少要保证这些字段能打通：

| 字段 | 为什么重要 |
| --- | --- |
| 外部服务单号 | 幂等、防重复、对账 |
| 金蝶售后单号或出库单号 | 追到库存和财务 |
| 客户、产品、序列号 | 判断质保和责任 |
| 服务站、工程师 | 绩效和结算 |
| 备件编码、批号、序列号 | 库存追溯 |
| 旧件编码、序列号、返还状态 | 免费换件闭环 |
| 保内保外标识 | 收费和成本口径 |
| 费用项目 | 维修收入、服务费、差旅费、赔偿 |
| 状态 | 待受理、已派工、维修中、完成、结算中、关闭 |

## 十一、常见问题处理

| 问题 | 可能原因 | 排查路径 | 处理 |
| --- | --- | --- | --- |
| 服务站说有库存，金蝶没有 | 服务站未入库、寄售未建仓、外部台账未同步 | 查补货单、签收单、服务站台账 | 补入库或建立服务站仓 |
| 金蝶有库存，服务站实物没有 | 已维修消耗但未回传 | 查服务单、领料、旧件返还 | 补消耗单据并追责 |
| 免费备件成本异常高 | 保内口径过宽、旧件未返还、重复领件 | 查故障类型、序列号、旧件状态 | 收紧审批和旧件控制 |
| 经销商服务费对不上 | 经销商报表和系统服务单口径不同 | 按服务单、客户确认、区域政策核对 | 统一结算规则 |
| 保外维修没有收入 | 维修由服务站完成但未回传收费 | 查服务结果、客户付款和发票 | 补应收或明确经销商自营 |
| 客户投诉重复维修 | 故障未根除、备件质量问题、服务记录缺失 | 查产品维修历史和批次 | 建立重复故障预警 |

## 十二、三个落地案例

### 案例 1：服务站先换件，月底才报消耗

现象：服务站为了快速响应客户，先从备件架拿件维修，月底统一报 Excel。金蝶库存长期不准。

处理：

1. 为服务站建立独立仓或寄售库存台账。
2. 服务单完成时必须选择备件和数量。
3. 每周回传消耗，月底盘点。
4. 旧件未返还的服务单不允许结算服务费。

### 案例 2：经销商代修既有保内也有保外

现象：经销商本月提交 100 单服务费，其中 60 单保内、30 单保外、10 单拒保，财务不知道哪些要确认应付。

处理：

1. 服务单必须标记保内、保外、拒保和特殊审批。
2. 保外收费由经销商自营时，原厂只处理备件销售或服务政策补贴。
3. 原厂承担的保内服务按政策生成服务费结算。
4. 拒保和客户自费维修不进入原厂售后成本，除非合同另有约定。

### 案例 3：免费换件后旧件不返还

现象：关键备件免费发出，服务站迟迟不返旧件，供应商索赔无法发起。

处理：

1. 将关键件设置为必须返旧。
2. 服务完成后生成旧件返还任务。
3. 超期未返旧进入异常清单。
4. 未返旧服务单暂缓服务费结算或扣备件成本。
5. 旧件入库检测后再判断报废、返修或供应商索赔。
