连锁零售和普通批发分销不一样。批发分销重点看客户、价格、信用、发货和回款；连锁零售重点看门店、POS、收银、会员、促销、门店库存、补货、退换货和日结对账。项目里如果只按普通销售订单处理门店零售，会很快卡在收款方式、促销折扣、库存同步和门店日结。

一句话主线：

```text
门店和商品基础资料
  -> 会员、价格和促销
  -> POS 销售和收款
  -> 门店库存和补货
  -> 退换货和售后
  -> 日结、收银对账、平台对账
  -> 门店经营分析
```

## 一、连锁零售最常见的场景

| 场景 | 业务特点 | 系统关注点 |
| --- | --- | --- |
| 直营门店 | 公司自营，销售和库存都归总部 | 门店库存、POS 日结、收银对账、门店损益 |
| 加盟门店 | 门店独立经营，向总部进货或结算 | 加盟商往来、供货价、返利、渠道库存 |
| 商超/便利店 | SKU 多、日销量大、促销频繁 | 条码、价格、补货、盘点、收银差异 |
| 专卖店 | 品牌控制强，会员和导购重要 | 会员、导购业绩、陈列、区域库存 |
| 电商门店融合 | 线上下单、门店发货或自提 | 订单接口、库存锁定、履约方式 |
| 生鲜/食品 | 保质期、称重、损耗、报废敏感 | 批号效期、称重条码、损耗、盘点 |
| 医药/美妆 | 批号、效期、监管和会员营销 | 批号追溯、效期预警、会员权益 |

连锁零售的难点不是“卖一件商品”，而是“几百家门店每天卖很多笔、收很多种款、做很多促销，系统还能在第二天告诉你钱、货、会员权益和利润有没有对上”。

## 二、门店主数据

### 2.1 门店档案

| 字段 | 用途 | 常见问题 |
| --- | --- | --- |
| 门店编码 | POS、库存、报表统一识别 | 编码和旧系统/电商平台不一致 |
| 门店类型 | 直营、加盟、联营、临时店 | 财务结算和库存所有权不同 |
| 所属区域 | 大区、省区、城市、商圈 | 区域经营分析 |
| 门店仓库 | 每店一个仓或多门店共仓 | POS 扣库存找不到仓库 |
| 开业/闭店日期 | 报表期间和对比口径 | 闭店后仍有交易或库存 |
| 收款账户 | 现金、银行卡、微信、支付宝、平台账户 | 收银对账和资金归集 |
| 税务主体 | 哪个法人开票或确认收入 | 直营和加盟混用税务口径 |
| 店长/导购 | 门店责任人和业绩归属 | 离职后业绩和权限未交接 |

### 2.2 商品零售属性

| 属性 | 说明 |
| --- | --- |
| 零售价 | 面向消费者的标价 |
| 会员价 | 会员等级或活动价格 |
| 条码 | POS 扫码和库存识别 |
| 规格 | 颜色、尺码、容量、型号 |
| 单位 | 件、盒、瓶、公斤、克 |
| 是否称重 | 生鲜、散装商品需要称重条码 |
| 是否批号效期 | 食品、药品、化妆品、耗材 |
| 是否允许退货 | 特价品、易耗品、定制品可能限制 |
| 是否参与促销 | 促销活动过滤条件 |
| 是否赠品 | 赠品出库和成本分析 |

### 2.3 门店库存组织方式

| 方式 | 适用情况 | 风险 |
| --- | --- | --- |
| 每店一个仓 | 多门店、库存独立 | 仓库数量多，主数据维护压力大 |
| 区域仓 + 门店库存 | 总仓补货到门店 | 调拨和在途要清楚 |
| 前店后仓 | 门店销售和店内仓分开 | POS 扣减仓库要准确 |
| 加盟商仓 | 货权可能属于加盟商 | 总部库存和渠道库存要区分 |
| 线上履约仓 | 门店也承接线上订单 | 线上库存锁定和门店销售冲突 |

## 三、价格、会员和促销

### 3.1 价格层级

| 价格 | 使用场景 |
| --- | --- |
| 标准零售价 | 门店正常销售 |
| 会员价 | 按会员等级或会员活动 |
| 门店区域价 | 不同城市或门店价格不同 |
| 促销价 | 活动期间特价 |
| 组合价 | 套餐、买赠、组合销售 |
| 员工价 | 内购或员工福利 |
| 清仓价 | 临期、滞销、换季清货 |

价格优先级建议写清，例如：

```text
清仓价 / 特批价
  > 促销价
  > 会员价
  > 区域价
  > 标准零售价
```

### 3.2 会员资料

| 字段 | 用途 |
| --- | --- |
| 会员编号 | 唯一识别会员 |
| 手机号 | 登录、短信、去重 |
| 会员等级 | 折扣、积分、权益 |
| 积分余额 | 积分抵扣和兑换 |
| 储值余额 | 预收款和消费 |
| 生日/标签 | 营销活动 |
| 所属门店 | 拉新归属和门店业绩 |
| 最近消费 | 复购分析 |

会员最容易乱在三件事上：

1. 会员权益在 POS 用掉了，但后台没有同步。
2. 储值余额收了钱，但财务没有作为预收或负债管理。
3. 积分抵扣影响收入和费用，但毛利报表没有体现。

### 3.3 促销类型

| 促销 | 系统要点 |
| --- | --- |
| 直接折扣 | 折扣率、折扣额、最低价 |
| 满减 | 门槛金额、减免金额、是否可叠加 |
| 买赠 | 主商品、赠品、赠品库存和成本 |
| 第二件半价 | 组合规则和退货重算 |
| 积分抵扣 | 积分扣减、财务处理 |
| 储值赠送 | 储值本金和赠送金额分开 |
| 券码核销 | 券发放、使用、作废、退款 |
| 套餐销售 | 收入和成本分摊 |

促销规则必须提前设计“退货时怎么算”。如果顾客买二送一后退一件，是按原价退、折后退，还是重算整单优惠？这个问题不在 UAT 里测，上线后门店一定会吵起来。

## 四、POS 销售和收款

### 4.1 POS 小票到后台单据

```text
POS 小票
  -> 零售销售记录
  -> 门店销售出库
  -> 收款记录
  -> 发票/收入确认
  -> 库存减少
  -> 成本结转
```

### 4.2 小票字段

| 字段 | 用途 |
| --- | --- |
| 门店 | 销售和库存归属 |
| POS 机号 | 收银设备追踪 |
| 收银员 | 收银责任 |
| 导购 | 业绩归属 |
| 小票号 | 唯一交易凭据 |
| 交易时间 | 日结和班次 |
| 商品条码 | 商品识别 |
| 数量 | 销售数量 |
| 原价 | 标价 |
| 折扣 | 促销和会员优惠 |
| 实收金额 | 实际收款 |
| 收款方式 | 现金、银行卡、微信、支付宝、储值、券 |
| 会员 | 积分、权益、复购 |
| 发票状态 | 是否开票 |

### 4.3 收款方式

| 收款方式 | 对账重点 |
| --- | --- |
| 现金 | 收银员交款、长短款 |
| 银行卡 | 银行入账、手续费 |
| 微信/支付宝 | 平台流水、到账周期、手续费 |
| 储值卡 | 储值余额、消费扣减、预收负债 |
| 会员积分 | 积分扣减和费用/折扣处理 |
| 优惠券 | 券核销、发行方承担、退款 |
| 平台支付 | 电商平台账单、佣金、退款 |

## 五、门店日结

门店日结是连锁零售的“月结小版本”。每天不对，月底一定乱。

### 5.1 日结步骤

| 步骤 | 做什么 | 责任人 |
| --- | --- | --- |
| 关收银班次 | 停止当日交易或切换班次 | 收银员/店长 |
| 核对小票 | 小票数量、作废、退货、异常交易 | 店长 |
| 核对收款 | 现金、银行卡、移动支付、储值、券 | 收银员/财务 |
| 上传 POS 数据 | 销售、退货、收款、会员权益 | 门店/系统 |
| 生成后台单据 | 销售出库、收款、收入或应收 | 系统/财务 |
| 核对库存 | POS 销售扣减、退货入库、差异 | 店长/仓管 |
| 处理长短款 | 现金差异、平台差异、手续费 | 财务 |
| 锁定日结 | 当日数据不再随意改 | 店长/财务 |

### 5.2 日结对账表

| 对账项 | POS | 后台/金蝶 | 差异常见原因 |
| --- | --- | --- | --- |
| 销售金额 | POS 小票金额 | 零售销售单/收入 | 小票未上传、重复上传 |
| 收款金额 | POS 收款方式 | 收款单/资金流水 | 平台到账周期、手续费 |
| 商品数量 | POS 销售数量 | 门店出库数量 | 库存扣减失败、条码错误 |
| 退货金额 | POS 退货小票 | 退货单/退款单 | 原单匹配失败 |
| 储值消费 | 储值扣减 | 预收余额减少 | 会员账户同步失败 |
| 优惠券 | 券核销 | 促销费用/折扣 | 券状态未同步 |
| 长短款 | 实收和应收差 | 长短款处理单 | 现金盘点或收银误差 |

## 六、补货、调拨和门店库存

### 6.1 补货逻辑

| 依据 | 说明 |
| --- | --- |
| 安全库存 | 低于安全库存补货 |
| 销售预测 | 根据近期销量和活动预估 |
| 门店等级 | A 类店多备，C 类店少备 |
| 陈列要求 | 最低陈列数量 |
| 保质期 | 临期商品谨慎补货 |
| 在途库存 | 调拨途中数量要纳入 |
| 促销计划 | 活动前提前铺货 |

### 6.2 门店调拨

| 调拨类型 | 适用场景 | 控制点 |
| --- | --- | --- |
| 总仓到门店 | 常规补货 | 出库、在途、门店入库 |
| 门店到门店 | 调剂库存 | 调出店和调入店确认 |
| 门店退仓 | 清仓、退季、质量问题 | 退回原因和质检 |
| 门店报废 | 损耗、过期、破损 | 审批和成本归集 |
| 门店盘盈盘亏 | 盘点差异 | 差异原因和责任 |

### 6.3 库存风险

| 风险 | 表现 | 处理 |
| --- | --- | --- |
| POS 卖了后台没扣库存 | 门店库存虚高 | 查 POS 上传和出库生成 |
| 门店收货未确认 | 总仓已出，门店未入 | 查在途和收货差异 |
| 临期商品积压 | 食品/药品/美妆风险 | 效期预警和清仓 |
| 门店盘点差异大 | 盗损、漏扫、错码 | 固定盘点频率和责任 |
| 线上订单锁库存 | 门店无法销售 | 统一可用量和释放规则 |

## 七、退换货和退款

### 7.1 退货分类

| 类型 | 处理 |
| --- | --- |
| 原单退货 | 按原小票、原价格、原促销重算 |
| 无小票退货 | 需要特批，按规则判断价格 |
| 换货 | 旧品退回、新品销售，差额收退 |
| 质量退货 | 进入待检、返厂或报废 |
| 会员退货 | 积分、券、储值权益回滚 |
| 线上退门店 | 订单来源和退款渠道要一致 |

### 7.2 退款对账

| 场景 | 重点 |
| --- | --- |
| 现金退款 | 门店现金长短款 |
| 原路退回 | 支付平台退款状态 |
| 储值卡退回 | 储值余额恢复 |
| 券抵扣退货 | 券是否恢复、是否过期 |
| 组合促销退货 | 是否重算整单优惠 |
| 跨店退货 | 原销售门店和退货门店业绩归属 |

## 八、加盟和联营

连锁零售不一定全是直营。加盟和联营要单独设计。

| 模式 | 货权 | 收入确认 | 库存管理 | 对账重点 |
| --- | --- | --- | --- | --- |
| 直营 | 总部/公司 | 门店销售即公司收入 | 公司库存 | POS 日结和收款 |
| 加盟进货 | 加盟商 | 总部卖给加盟商时确认 | 加盟商库存 | 应收、返利、渠道库存 |
| 加盟代销 | 可能仍属总部 | 终端销售后结算 | 门店代销库存 | 消耗结算和对账 |
| 联营扣点 | 商场或合作方收款 | 按扣点后结算 | 专柜库存 | 商场账单和扣点 |

如果直营、加盟、联营混在一套销售流程里，财务会很难解释“同样一笔 POS 销售，为什么有的是收入，有的是应收加盟商，有的是商场扣点后结算”。

## 九、门店经营指标

| 指标 | 说明 |
| --- | --- |
| 门店销售额 | 按门店、导购、品类、时段 |
| 客单价 | 销售额 / 小票数 |
| 连带率 | 销售件数 / 小票数 |
| 毛利率 | 毛利 / 销售收入 |
| 折扣率 | 折扣金额 / 原价金额 |
| 会员销售占比 | 会员销售 / 总销售 |
| 复购率 | 复购会员 / 活跃会员 |
| 库存周转天数 | 平均库存 / 销售成本 * 天数 |
| 动销率 | 有销售 SKU / 在售 SKU |
| 缺货率 | 缺货 SKU / 应备 SKU |
| 退货率 | 退货金额 / 销售金额 |
| 长短款金额 | 实收和应收差额 |
| 门店坪效 | 销售额 / 营业面积 |
| 人效 | 销售额 / 员工人数 |

门店经营分析不要只看销售额。一个门店销售额高，但折扣率高、退货率高、库存周转慢、长短款多，实际经营质量可能并不好。

## 十一、常见问题

| 问题 | 常见原因 | 处理 |
| --- | --- | --- |
| POS 销售和后台销售不一致 | 小票未上传、重复上传、接口失败 | 按门店、日期、小票号对账 |
| 收款和销售不一致 | 多收款方式、手续费、退款、储值 | 按收款方式做日结表 |
| 门店库存不准 | POS 未扣库存、调拨未确认、盘点差异 | 查库存流水和在途 |
| 会员积分不对 | 积分规则、退货回滚、接口延迟 | 查会员权益流水 |
| 促销退货争议 | 退货时未重算整单优惠 | UAT 固定促销退货规则 |
| 储值余额和财务不一致 | 充值、赠送、消费、退款没分开 | 区分本金、赠送和消费 |
| 门店长短款多 | 现金盘点、扫码支付漏单、退款异常 | 日结后锁定并登记差异 |
| 加盟商对账不清 | 直营、加盟、代销模式混用 | 按模式分流程和结算 |
| 临期商品积压 | 效期没有进入补货和促销 | 建效期预警和清仓策略 |
