销售退货页面已经说明了退货、红冲、退款和折让的财务闭环。这篇继续往下钻：客户退回来的货到底是良品、不良品、可返修、可报废、可再销售，还是需要赔偿或索赔。项目里如果只做销售退货单，不做质量判定和库存状态隔离，最后会出现“货回来了，但不能卖；账冲了，但责任没清；仓库入了，但成本不知道怎么处理”的问题。

这里把 RMA 当成客户退货授权和售后处理闭环来理解，不强依赖某一个固定单据名称。不同版本或客户化环境可能叫退货申请、售后申请、质量反馈、客诉单、维修单或 RMA 单，关键是要保留客户、原销售、退货原因、质量判定、处理结论和财务影响。

## 一、完整流程

```text
客户反馈 / 售后申请
  -> RMA 或退货授权
  -> 关联原销售订单、出库、发票、客户和批号
  -> 客户退回实物
  -> 仓库收货到待检或退货待处理
  -> 质量检验和责任判定
  -> 良品入库 / 返修 / 报废 / 让步接收 / 退回客户
  -> 红字应收、红字发票、退款或补发
  -> 成本冲回、维修成本、报废损失或索赔
  -> 客诉复盘和预防措施
```

不要让客户退货直接进入可用库存。正确做法是先进入“待检、冻结、退货待处理、不良品”等状态，质量判定后再决定去向。

## 二、先分清六类场景

| 场景 | 实物去向 | 财务影响 | 质量动作 |
| --- | --- | --- | --- |
| 良品退货再销售 | 入良品仓或可用库存 | 冲收入、应收、成本，后续可再销售 | 确认可再销售 |
| 质量不良返修 | 返修仓或维修流程 | 可能冲收入，也可能形成维修成本 | 判定返修方案和责任 |
| 质量不良报废 | 不良品仓转报废 | 冲收入和成本，确认报废损失或索赔 | 出具报废原因 |
| 客户误退或无责任 | 退回客户 | 通常不冲收入或只做物流处理 | 判定不成立 |
| 换货 | 旧货退回，新货发出 | 原单冲回，新单出库或差额处理 | 判定旧货状态 |
| 只赔偿不退货 | 无实物入库 | 折让、赔款、红字发票或费用 | 客诉证据和责任判定 |

关键不是名称，而是四个结果要一致：库存状态、客户余额、税务发票、成本毛利。

## 三、RMA 或退货授权需要记录什么

| 字段 | 用途 |
| --- | --- |
| 客户和结算客户 | 决定应收、退款和客户对账 |
| 原销售订单、销售出库、发票 | 控制超退、追溯价格、税率和成本 |
| 物料、规格、批号、序列号 | 支持质量追溯和库存状态控制 |
| 退货原因 | 区分质量、错发、客户取消、运输损坏 |
| 退货责任 | 决定赔偿、扣款、维修成本和内部考核 |
| 处理方式 | 退货退款、换货、返修、报废、折让 |
| 预计收货日期 | 便于仓库和售后跟进 |
| 附件 | 照片、检测报告、客户沟通记录 |

没有原单关联时，至少要记录客户、物料、批号、销售日期、发票号或外部订单号。否则后面很难判断是否超退、是否保内、是否重复退货。

## 四、收货和库存隔离

仓库收到退货时，不要只做“入库”。建议固定三步：

1. 核对 RMA 或退货授权是否存在。
2. 点收数量、批号、外观、附件和客户退回资料。
3. 入待检仓、冻结仓或退货待处理库存状态。

库存隔离口径：

| 状态 | 可否销售 | 用途 |
| --- | --- | --- |
| 待检 | 否 | 等质量判定 |
| 良品 | 是 | 可再销售或补发 |
| 返修 | 否 | 进入维修或返工流程 |
| 不良 | 否 | 等报废、索赔或拆件 |
| 报废 | 否 | 进入报废审批和损失确认 |

退货收货时就要记录批号和序列号。等到质量追溯时再补，往往已经无法证明这件货是否就是原出库那一件。

## 五、质量检验和责任判定

质量检验要回答：

- 是否是本公司销售的产品。
- 是否在质保期内。
- 是否能关联原批号、序列号或销售出库。
- 缺陷是否存在。
- 缺陷是制造原因、运输原因、客户使用原因还是无法判定。
- 处理方式是良品入库、返修、报废、换货、退回客户还是折让。

常见检验结论：

| 结论 | 后续动作 |
| --- | --- |
| 合格 | 转良品库存，可再销售或补发 |
| 让步接收 | 转可用但加标识，保留审批 |
| 返修 | 转返修仓或维修单，记录维修材料和工时 |
| 报废 | 走报废审批，确认损失或索赔 |
| 退回客户 | 不冲财务或只记录物流 |
| 待供应商判定 | 暂挂不良库存，后续供应商索赔 |

如果质量检验和销售退货割裂，财务只看到红字应收和库存入库，却不知道这批货能不能再次销售、是否需要报废、是否应该向供应商或物流索赔。

## 六、返修、换货和报废

### 1. 返修

```text
退货待检
  -> 质量判定为可返修
  -> 返修单 / 维修工单
  -> 领用维修材料和工时
  -> 返修完成
  -> 复检
  -> 良品入库 / 再次返修 / 报废
```

返修要记录：

- 维修材料。
- 维修工时。
- 是否供应商责任。
- 是否向客户收费。
- 是否影响质保期。
- 返修后是否重新赋码或保留原序列号。

### 2. 换货

换货是“退旧货 + 发新货”，不要只做一张模糊调整单。

```text
旧货退回待检
  -> 质量判定
  -> 新货销售出库或换货出库
  -> 差价、税额、运费、退款或补款处理
```

检查：

- 新旧物料是否相同。
- 新旧价格是否相同。
- 是否需要新开发票。
- 旧货成本是否冲回。
- 新货成本是否重新结转。

### 3. 报废

报废不是简单把库存数量清掉。要形成审批和财务证据：

- 报废原因。
- 责任归属。
- 报废数量和金额。
- 是否可回收残值。
- 是否向供应商、物流或客户索赔。
- 是否影响质量改进。

## 七、财务、税务和成本处理

客户退货质检的财务影响通常有四类：

| 处理 | 影响 |
| --- | --- |
| 红字应收 / 红字发票 | 冲客户应收、收入和销项税 |
| 退款 / 抵扣 | 处理客户资金或后续货款抵扣 |
| 成本冲回 | 原销售成本冲回，库存金额回到存货 |
| 维修或报废成本 | 形成维修费用、报废损失或索赔 |

跨期退货要特别谨慎：原销售可能已经结账、报税和出报表。一般不建议随意反结账改历史单据，而是在当前期间按退货、红字、成本冲回和质量损失处理，同时在月结说明里披露对收入和毛利的影响。

## 八、常见异常

| 异常 | 常见原因 | 处理方向 |
| --- | --- | --- |
| 退货入库后库存可用，但质量未判定 | 入库状态配置错误 | 改成待检或冻结状态，补质量流程 |
| 客户已退款但退货还没收到 | 先财务后实物 | 设退款审批前置条件或临时挂账 |
| 红字发票已开，系统应收没冲 | 发票和应收没有联动 | 补红字应收并核销 |
| 货已报废但库存仍在 | 报废审批未生成库存处理 | 补报废出库或库存状态处理 |
| 换货后新货成本漏结转 | 只做退货，没做新发货 | 补新货出库和成本核算 |
| 退货没有原单 | 客户线下退回或历史单据缺失 | 建立无源退货审批和人工追溯证据 |

## 九、典型案例

### 案例 1：退货直接进良品仓，后续又被销售

现象：

- 客户退回有质量争议的货。
- 仓库做了退货入库，库存状态为可用。
- 货物再次被销售，客户再次投诉。

排查：

1. 查销售退货单入库仓库和库存状态。
2. 查是否生成质量请检或检验单。
3. 查物料是否启用退货检验。
4. 查仓库是否有待检仓或退货待处理仓。
5. 查销售出库是否允许占用待检库存。

处理：

- 调整退货入库默认仓库或库存状态。
- 对未判定的退货批次做冻结。
- 补质量检验和责任判定。
- 后续退货必须先入待检，再转良品或不良。

### 案例 2：客户换货完成，但客户余额一直不对

现象：

- 客户退回旧货，企业发出新货。
- 销售说已经换完。
- 财务客户对账单还有负数或欠款。

排查：

1. 查旧货是否生成红字应收。
2. 查新货是否生成蓝字应收。
3. 查红字应收和蓝字应收是否核销。
4. 查差价是否收款或退款。
5. 查发票是否重开或红冲。

处理：

- 把换货拆成退旧和发新两条业务。
- 对红蓝应收做核销或差额收退。
- 输出客户对账单给销售和客户确认。

### 案例 3：退货报废影响毛利但没人说明

现象：

- 月度毛利突然下降。
- 查到一批客户退货已经报废。
- 销售收入冲回了，成本和报废损失也进了当月。

排查：

1. 查原销售期间和退货期间。
2. 查报废审批和质量判定。
3. 查是否供应商或物流责任。
4. 查是否有索赔单或扣款。
5. 查管理报表是否单列退货报废影响。

处理：

- 月结报告单列“跨期退货报废影响”。
- 能索赔的形成应收索赔或扣款。
- 质量部门输出预防措施。
- 销售和客户服务复盘退货原因。

## 十、上线和培训检查清单

- [ ] 退货申请或 RMA 能关联原销售订单、出库、发票和客户。
- [ ] 退货收货默认进入待检、冻结或退货待处理状态。
- [ ] 质量检验能区分良品、返修、报废、让步、退回客户。
- [ ] 批号、序列号、生产日期、质保期能追溯。
- [ ] 返修能记录材料、工时、责任和复检结果。
- [ ] 报废有审批、库存处理、金额和责任归属。
- [ ] 红字应收、红字发票、退款、核销能和实物处理关联。
- [ ] 换货能拆分为旧货退回和新货发出。
- [ ] 跨期退货能在当前期间处理并输出月结说明。
- [ ] 客户对账单能解释原销售、退货、红冲、退款、换货差额。
