推荐学习路线

不确定从哪里开始时，先按岗位走一遍，再回到模块目录补细节。

财务新人到金蝶财务主办

从会计循环、科目维度、凭证、往来、资金、资产、月结和报表开始，建立完整财务闭环。

  1. 读财务基础和系统映射
  2. 练采购到付款、销售到收款
  3. 做月结证据包和对账表

实施顾问从调研到验收

把需求拆成流程、配置、数据、权限、接口、报表、测试和交付物，形成项目推进能力。

  1. 调研现状和痛点
  2. 落蓝图、配置和测试
  3. 完成上线、验收和移交

数据、BI 与报表排查

从业务对象追到数据表和 BI 指标，写清取数口径，减少“看板好看但数字说不清”的情况。

  1. 先确认组织、期间和状态
  2. 再查标准报表和明细账
  3. 最后用 SQL 和指标字典定位差异

接口、运维与问题处理

按影响范围、复现路径、日志证据、根因处理和预防机制记录问题，让经验可复用。

  1. 保留报错原文和日志
  2. 拆分配置、数据、权限、二开、环境
  3. 沉淀案例并反哺模块文档
